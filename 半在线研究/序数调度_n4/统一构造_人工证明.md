# 统一显式构造的人工证明：对所有 m ≥ 4，序列 (1×(m−1), r×(m−1), s×(m−1)) 的博弈值 ≥ c

**定理**。设 c = (1+√37)/6，r = (2+√37)/11，s = (1+r)/3 = (13+√37)/33。对任意 m ≥ 4，在 m 台机器的递减半在线调度中，对抗序列

$$S_m = (\underbrace{1,\dots,1}_{m-1},\ \underbrace{r,\dots,r}_{m-1},\ \underbrace{s,\dots,s}_{m-1})$$

保证任何确定性算法的竞争比 ≥ c。即：存在对手策略，使无论算法如何放置，都能在某一前缀处收手，达到 makespan ≥ c · OPT(前缀)。

（数值核验：m = 4, 5, 6 的精确博弈值与 c 之差在浮点噪声级 ≈ 2×10⁻¹⁰；本文给出对一切 m ≥ 4 的统一人工证明。）

---

## 0. 常数从哪里来

r 和 s 不是猜的，是被两个"配平方程"唯一确定的：

- **方程一**（r 与 1 配对的收手点恰好等于 c）：(1+r)/(2r) = c ⟺ r = 1/(2c−1) = (2+√37)/11；
- **方程二**（s 尾主攻收手点恰好等于 c）：(2r+s)/(1+r) = c ⟺ s = c(1+r) − 2r = (13+√37)/33。

外加一个"天降"恒等式（它不来自配平，是额外的好运，后面填充引理也靠它）：

- **恒等式三**：3s = 1+r，即 s = (1+r)/3。

**常用数值**：c ≈ 1.180460，r ≈ 0.734797，s ≈ 0.578266，1+r ≈ 1.734797，2r ≈ 1.469594，3r ≈ 2.204391，2r+s ≈ 2.047859，1+2r ≈ 2.469594，1+r+s ≈ 2.313063，1+s ≈ 1.578266，1+2s ≈ 2.156531。

**递减序合法性**：1 > r > s，因为 r < 1 ⟺ √37 < 9 ✓，s ≤ r ⟺ 1+r ≤ 3r ⟺ 1 ≤ 2r ⟺ 2√37 ≥ 7 ⟺ 148 ≥ 49 ✓（事实上 2r ≈ 1.47 > 1）。

**关键观察**：c·(1+r) = 2r + s（即方程二的改写）。这把"算法机器的负载上限"翻译成一个具体数字：**在 OPT = 1+r 的前缀上，任何机器负载达到 2r+s ≈ 2.0479，对手就能以 ≥ c 收手**。

## 1. 前缀 OPT 引理

**引理**（已数值核验 m=4,5,6 全部吻合）。对 m ≥ 4：

- (a) OPT(1^j) = 1（j ≤ m−1）；
- (b) OPT(1^{m−1}, r) = 1；
- (c) OPT(1^{m−1}, r²) = 2r；
- (d) OPT(1^{m−1}, r^j) = 1+r（j ≥ 3）；
- (e) OPT(1^{m−1}, r^{m−1}, s^k) = 1+r（k ≤ 3）。

**证明**。
(a)(b)：任务数 ≤ m，每个独占一台，最大任务为 1。∎

(c) 上界：{r,r} 一台、其余 m−1 个任务各独占一台，共 m 台，makespan = max(2r, 1) = 2r（2r ≈ 1.47 > 1）。下界：共 m+1 个任务、m 台机器，必有一对同机；最便宜的配对是 {r,r} = 2r（其余 {1,r} = 1+r、{1,1} = 2 都更贵），故 OPT ≥ 2r。∎

(d) 上界：{1,r}×j 占 j 台、其余 m−1−j 个 1 各独占一台，共 m−1 台，makespan = 1+r。下界：反设存在全部负载 < 1+r 的划分。则任何机器不能含 {1,1}、{1,r}，也不能含三个 r（3r > 1+r）。于是：每个 1 独占一台（不能配 1 也不能配 r），m−1 个 1 占满 m−1 台；j ≥ 3 个 r 每台至多 2 个，至少再占 2 台。合计 ≥ m+1 台 > m 台，矛盾。∎

(e) 上界：{1,r}×(m−1) 占 m−1 台、k 个 s 全放第 m 台，负载 ks ≤ 3s = 1+r（恒等式三；k ≤ 3）。下界：同 (d) 的反设。全部负载 < 1+r 时，除 (d) 的禁令外，s 也救不了场：s 只能挂在 {1} 或单个 {r} 的机器上（{r,r,s} = 2r+s > 1+r ✗，{1,s,s} = 1+2s > 1+r ✗），不能改变"1 占 m−1 台、r 至少占 2 台"的计数。合计 ≥ m+1 > m，矛盾。∎

**一句话**：在对手可能收手的所有前缀上，OPT 只有三个值——1（纯 1 或一个 r）、2r（两个 r）、1+r（其余一切）。

## 2. 对手策略（三阶段）

对手按序打出 S_m，停止规则如下。

### 阶段一：m−1 个 1

**规则**：若某台机器装入第二个 1（负载 2），立即收手。

- 收手比值：前缀为 (1^j)（j ≤ m−1），OPT = 1（引理 a），比值 = 2/1 = **2 > c** ✓。

此后可设：m−1 个 1 分占 m−1 台机器 A₁,…,A_{m−1}（负载各为 1），剩一台空机 M\*。

### 阶段二：m−1 个 r

**第 1 个 r**：若放上某台 1-机器（负载 1+r），立即收手：前缀 (1^{m−1}, r)，OPT = 1（引理 b），比值 = 1+r ≈ **1.7348 > c** ✓。
故算法被迫：r₁ → M\*（负载 r）。

**第 2 个 r**：若放上某台 1-机器（负载 1+r），立即收手：前缀 (1^{m−1}, r²)，OPT = 2r（引理 c），比值 = (1+r)/(2r) = **c**（方程一，恰等）✓。
故算法被迫：r₂ → M\*（负载 2r）。

**第 j 个 r（j = 3, …, m−1）**：此时 OPT 已涨到 1+r（引理 d），收手线变为"任何机器负载 ≥ c·(1+r) = 2r+s"。算法的选择：
- 放上 M\*（现有 2r）：负载 ≥ 3r ≈ 2.204 ≥ 2r+s ✓，收手，比值 ≥ 3r/(1+r) = (√37−1)/4 ≈ **1.2707 > c** ✓；
- 放上已含 r 的 1-机器（现有 1+r 或更高）：负载 ≥ 1+2r ≈ 2.470 ≥ 2r+s ✓，收手，比值 ≥ (1+2r)/(1+r) = (11+√37)/12 ≈ **1.4236 > c** ✓；
- 放上一台尚空的 1-机器：负载 1+r < 2r+s，**安全**，继续。

故算法被迫：r₃, …, r_{m−1} 各占一台不同的 1-机器。

**阶段二结束时的被迫格局**（m−3 个 r 填满 m−3 台 1-机器后）：

| 机器 | 数量 | 负载 |
|---|---|---|
| M\* | 1 | 2r ≈ 1.4696 |
| 1-机器 | m−3 | 1+r ≈ 1.7348 |
| 尚空的 1-机器 | **恰好 2 台** | 1 |

（台数核验：(m−1) − (m−3) = 2。）

### 阶段三：m−1 个 s（决胜）

收手线不变：任何机器达到 2r+s 即收手（前缀 (1^{m−1}, r^{m−1}, s^k)，k ≤ 3，OPT = 1+r，引理 e）。逐台检查算法的放法：

| s 放到哪类机器 | 新负载 | 是否触线 | 收手比值 |
|---|---|---|---|
| M\*（2r） | 2r+s | 触线 | (2r+s)/(1+r) = **c**（方程二，恰等）✓ |
| 1+r 机器 | 1+r+s | 触线 | (1+r+s)/(1+r) = 1 + s/(1+r) = **4/3 > c**（恒等式三）✓ |
| 空 1-机器（1） | 1+s ≈ 1.5783 | **不触线** | ——唯一安全位 |
| 已含 s 的机器（1+s） | 1+2s ≈ 2.1565 | 触线 | (1+2s)/(1+r) = (21−√37)/12 ≈ **1.2431 > c** ✓ |

于是：s₁、s₂ 被迫分别占掉那**仅有的两台**安全机器（各变为 1+s）；**第 3 个 s 到达时，全场机器负载 ∈ {2r, 1+r, 1+s}，每一种放法都触线**——对手收手，比值 ≥ c。而 m−1 ≥ 3 保证第 3 个 s 存在（这正是 m ≥ 4 的地方）。∎

## 3. 完备性与收手比值汇总

算法的每个决策点只有上表所列的放法（机器按负载分类，同类无区别），每一类都被核算，无一例外。所有收手点：

| 收手时机 | 负载 | OPT | 比值 | 精确余量 |
|---|---|---|---|---|
| 两个 1 同机 | 2 | 1 | 2 | 2−c ≈ 0.82 |
| r₁ 上 1-机器 | 1+r | 1 | 1+r ≈ 1.7348 | — |
| r₂ 上 1-机器 | 1+r | 2r | **= c** | 0（方程一） |
| M\* 达 3r | ≥ 3r | 1+r | ≥ (√37−1)/4 ≈ 1.2707 | (√37−5)/12 > 0 |
| 1-机器达 1+2r | ≥ 1+2r | 1+r | ≥ (11+√37)/12 ≈ 1.4236 | (9−√37)/12 > 0 |
| s 上 M\* | ≥ 2r+s | 1+r | ≥ **c** | 0（方程二） |
| s 上 1+r 机器 | ≥ 1+r+s | 1+r | ≥ 4/3 ≈ 1.3333 | (7−√37)/6 > 0 |
| s 上 1+s 机器 | ≥ 1+2s | 1+r | ≥ (21−√37)/12 ≈ 1.2431 | (19−3√37)/12 > 0 |

（负载更大的同类放法——如 M\* 收到第四个 r、s 叠到 1+2s 的机器——比值只会更大。）所有分支 ≥ c，其中两支恰等于 c。**定理证毕。** ∎

## 4. 博弈值恰好等于 c（不是更大）

**m = 4（手工）**：LPT 在此序列上：1 分三台；r₁, r₂ 依次进当时最轻的空机（r, 2r）；r₃ 起进 1-机器（1+r）；s₁, s₂ 进两台负载 1 的机器（1+s）；s₃ 进 M\*（2r+s）。最终 makespan = 2r+s = c·(1+r) = c·OPT，且此前每个前缀比值 ≤ 1。故 LPT 达到恰好 c，博弈值 = c。

**m = 5, 6（数值）**：精确博弈求解器给出与 c 之差 ≈ 2×10⁻¹⁰（浮点噪声）。

**一般 m ≥ 4（猜想）**：博弈值恰为 c。下界由本文定理给出；上界需一般 m 的 s-重前缀 OPT 通式（如 OPT(1^{m−1} r^{m−1} s⁴) ≤ 2r+s 型划分），留待补全。

## 5. 两个备注

**备注 1（更正）**：早前摘要中"m ≥ 5 时第 4 个 r 到达即锁死、s 尾用不上"的说法**不正确**：第 4 个 r 放上空的 1-机器时负载 1+r，而前缀 OPT 已是 1+r，比值仅 1，对手无法收手。真相更简洁——**本证明对所有 m ≥ 4 逐字相同，对手一律在第 3 个 s 处锁死算法**；m = 4 并非特例，而是同一个证明的最小情形。

**备注 2（恒等式三的双重角色）**：3s = 1+r 在本证明中做两件事：让 s-前缀的 OPT 恰好仍是 1+r（引理 e 的上界），让"s 上 1+r 机器"的收手比值恰为 4/3。缩放实例 S_m/(1+r) 后，最小任务 s/(1+r) = 1/3、最大任务 1/(1+r) = x（恰等于 SSW m=3 的 x！）——这正是填充提升引理的不变量 (I2)，两条证明路径在此交汇。
