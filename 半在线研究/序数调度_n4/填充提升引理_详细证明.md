# 填充提升引理（Padding Lemma）详细证明

**结论先行**：若 m 台机器上存在满足四个不变量的递减对抗实例（保证比值 ≥ c = (1+√37)/6），则在实例前插入一个大小为 G = (√37−1)/6 的任务，即得 m+1 台机器上同样保证 ≥ c 的递减对抗实例，且四个不变量全部保持，可无限迭代。结合 SSW 的 m=3 基例，即得：**对所有 m ≥ 3，任何确定性算法的竞争比 ≥ c**。

---

## 0. 模型、记号与两个辅助事实

**模型（SOSDP）**。任务按非增序 p₁ ≥ p₂ ≥ … ≥ pₙ 逐个到达；每个任务到达时大小已知，算法须立即将其不可撤销地分配到 m 台相同机器之一。对手（adversary）可在任意前缀之后宣布"停止"；设停止时已到达的任务多重集为 P，算法在 P 上的最大负载（makespan）记为 L_alg(P)，最优离线 makespan 记为 OPT_m(P)。算法 A 的竞争比为

R(A) = sup { L_alg(P) / OPT_m(P) : 对手打出的所有停止前缀 P }。

**对抗策略** = 一个递减序列 + 一条停止规则（停止规则可以依赖算法的放置历史；SSW 的策略正是这种自适应类型）。说"实例 J 保证比值 ≥ c"，意为：对任意确定性算法，对手按此策略进行，必在某一停止点达到 L_alg ≥ c·OPT_m(P)。

**记号**。记 p_min(J)、p_max(J) 为 J 中最小、最大的任务。c = (1+√37)/6 ≈ 1.180460，满足 **3c² − c − 3 = 0**。

**辅助事实 1（OPT 的单调性）**。若 Q′ ⊆ Q（多重集包含），则 OPT_m(Q′) ≤ OPT_m(Q)。
*证明*：取 Q 的最优分配，删去 Q∖Q′ 中的任务，各机器负载只降不升，得到 Q′ 的一个合法分配，其 makespan ≤ OPT_m(Q)。∎

**辅助事实 2（大任务隔离上界）**。设任务 G 不小于 Q 中任何任务，则

OPT_{m+1}({G} ∪ Q) ≤ max(G, OPT_m(Q))。

*证明*：把 G 单独放第 m+1 台机器，把 Q 按最优方式放其余 m 台。这是 {G}∪Q 的合法分配，makespan = max(G, OPT_m(Q))，故最优值不超过它。∎
（注意：我们只需要上界。同时 OPT_{m+1}({G}∪Q) ≥ G 平凡成立，因为 G 总要占某台机器。）

## 1. 常数 G 与关键代数

定义

**G := c − 1/3 = (√37−1)/6 ≈ 0.847127**。

**引理 0（关键恒等式）**。**cG = 1**，等价地 G = 1/c。

*证明*：cG = c² − c/3。由 3c² − c − 3 = 0 得 c² = (c+3)/3，代入：

cG = (c+3)/3 − c/3 = 3/3 = 1。∎

**引理 1（范围）**。1/3 < G < 1。

*证明*：G > 1/3 ⟺ √37 − 1 > 2 ⟺ √37 > 3 ⟺ 37 > 9 ✓。G < 1 ⟺ √37 < 7 ⟺ 37 < 49 ✓。∎

## 2. 引理陈述

**填充提升引理**。设 m ≥ 2，J 是 m 台机器上的递减任务序列，S 是其上的对抗策略，二者满足以下四个不变量：

- **(I1)** OPT_m(J) ≤ 1；
- **(I2)** p_min(J) = 1/3，且 p_max(J) ≤ G；
- **(I3)** S 的每个停止点处，算法的 makespan ≥ 1；
- **(I4)** S 保证比值 ≥ c，即每个停止点处 L_alg ≥ c·OPT_m(P)（P 为该停止点的前缀）。

构造新序列 J′ = (G, J)，即把大小为 G 的任务插在最前。则：

1. J′ 是 m+1 台机器上的合法递减序列；
2. 存在 m+1 台机器上的对抗策略 S′，使 (J′, S′) 仍满足 (I1)–(I4)（p_min、p_max 条件中的界仍是同一个 G）。

**推论（可迭代性）**。由于结论 2 保持全部不变量且 G 不变，引理可依次应用于 m = 3, 4, 5, …。

---

## 3. 引理的证明

### 第 0 步：J′ 是合法递减序列

J′ 的第一个任务是 G，其余是 J。由 (I2)，G ≥ p_max(J)，故 G 不小于任何后续任务，非增序成立。∎

### 第 1 步：(I1′) 成立——OPT_{m+1}(J′) ≤ 1

由辅助事实 2（取 Q = J，条件 G ≥ p_max(J) 即 (I2)）：

OPT_{m+1}(J′) = OPT_{m+1}({G} ∪ J) ≤ max(G, OPT_m(J)) ≤ max(G, 1) = 1，

其中第二步用 (I1)，最后一步用引理 1（G < 1）。∎

*评注*：这里只需要 ≤，不需要等号。事实上迭代一次之后 OPT 可能严格小于 1（例如 SSW 的 m=3 实例放到 4 台机器上，OPT ≤ max{1−x+1−x, x+1/3} = 0.9098 < 1）——分母变小只会让对手更强，无害。

### 第 2 步：(I2′) 成立

p_min(J′) = min(G, p_min(J)) = min(G, 1/3) = 1/3（引理 1：G > 1/3）；
p_max(J′) = G（G ≥ p_max(J) 即 (I2)）。∎

### 第 3 步：定义新策略 S′

对手先出任务 G，然后按以下规则进行：

- **停止规则 α**：从出完 G 之后起，一旦算法把某个任务 q（q 必为 J 中的任务）放到 G 所在的机器上，对手立即在该前缀处停止。
- **规则 β**：若算法始终不把任何任务放上 G 的机器，则对手把其余 m 台机器视为一个 m 机器博弈，在其上按原策略 S 依次出 J 的全部任务，并沿用 S 的停止规则。

任何确定性算法只有两种行为：某时刻触动 G 的机器（规则 α 触发），或从不触动（规则 β 适用）。以下分别验证两种情形下 S′ 都保证比值 ≥ c，且停止点负载 ≥ 1。

### 第 4 步：情形 α（算法触动 G 的机器）——比值 ≥ c

设算法把任务 q 放上 G 的机器，对手立即停止。该机器负载 ≥ G + q。由于 q ∈ J，由 (I2) 有 q ≥ p_min(J) = 1/3，故

L_alg ≥ G + 1/3 = (c − 1/3) + 1/3 = **c**。

设已打出的前缀为 P。P 是 J′ 的子集，由辅助事实 1 与第 1 步：

OPT_{m+1}(P) ≤ OPT_{m+1}(J′) ≤ 1。

因此

L_alg / OPT_{m+1}(P) ≥ c / 1 = c。

这就是 (I4′) 对该停止点成立；同时 L_alg ≥ c > 1，(I3′) 对该停止点成立。∎

*评注*：等号 G + 1/3 = c 是引理的第一个约束：**G ≥ c − p_min**。这里取成了等号——这正是 G 被"夹死"的一侧。

### 第 5 步：情形 β（算法不碰 G 的机器）——比值 ≥ c

此时 J 的全部任务都被算法放进了其余 m 台机器，局面与 m 机器博弈完全相同，对手合法地执行 S。设 S 在某个停止点停止，对应 J 的前缀 P，算法在这 m 台上的 makespan 为 L。

**(a) 算法在 m+1 台机器上的总 makespan = L。**
G 独占一台机器，负载 G；其余 m 台最大负载 L。由 (I3)，L ≥ 1 > G（引理 1），故总 makespan = max(G, L) = L ≥ 1——(I3′) 对该停止点成立。

**(b) 新 OPT 的上界。**
已打出的 J′ 前缀是 {G} ∪ P。由 (I2)，G ≥ p_max(J) ≥ P 中任何任务，可应用辅助事实 2：

OPT_{m+1}({G} ∪ P) ≤ max(G, OPT_m(P))。

**(c) 比值。**
由 (I4)：L ≥ c·OPT_m(P)；
由 (I3) 与引理 0：L ≥ 1 = cG，即 L ≥ cG。
两式合并：

L ≥ max(cG, c·OPT_m(P)) = c·max(G, OPT_m(P)) ≥ c·OPT_{m+1}({G} ∪ P)。

结合 (a)（总 makespan = L）：

L_alg / OPT_{m+1}({G} ∪ P) ≥ c。

(I4′) 对该停止点成立。∎

*评注*：这一步用了引理的第二个约束：**cG ≤ min{停止点负载}**（这里以 L ≥ 1 = cG 的形式使用）。情形 α 要求 G ≥ c − 1/3，情形 β 要求 G ≤ 1/c，而引理 0 说 c − 1/3 = 1/c——两个约束在 G 处精确相遇，没有一分余地。这就是"刀刃上的填充"。

### 第 6 步：收尾

第 0–2 步给出 J′ 的合法性与 (I1′)(I2′)；第 3 步定义了 S′；第 4、5 步穷尽了算法的一切行为，证明 S′ 的每个停止点满足 (I3′)(I4′)。故 (J′, S′) 满足全部四个不变量，且 p_max 的界仍为同一个 G。**引理证毕。**∎

## 4. 主定理：所有 m ≥ 3 的下界 c

**定理**。在 SOSDP 模型中，对任意 m ≥ 3，任何确定性算法的竞争比 ≥ c = (1+√37)/6。

**证明**。对 m 归纳。归纳步即填充提升引理（G = (√37−1)/6 不变）。只需验证基例 m = 3 的四个不变量。

**基例：SSW 实例** J_SSW = (x, x, 1−x, 1−x, 1/3, 1/3, 1/3)，x = (13−√37)/12 ≈ 0.576436。

- **(I1)**：OPT_3(J_SSW) = 1。上界：划分 {x, 1−x}, {x, 1−x}, {1/3, 1/3, 1/3}，各机负载 1。下界：SSW 已证 OPT = 1。✓
- **(I2)**：p_min = 1/3 ✓。p_max = x ≤ G 的验证：x < G ⟺ (13−√37)/12 < (2√37−2)/12 ⟺ 15 < 3√37 ⟺ 5 < √37 ⟺ 25 < 37 ✓。
- **(I3)**：SSW 策略的停止点负载逐一核查：
  - 前三个任务 (x, x, 1−x) 中若有两者同机即停止：负载 ≥ min(2x, x+(1−x)) = min(2x, 1) = 1（因 2x = (13−√37)/6 ≥ 1 ⟺ 13−√37 ≥ 6 ⟺ √37 ≤ 7 ✓）；
  - 情形 A 停止：负载恰为 1；
  - 情形 B 终局停止：负载 ≥ c > 1。
  全部 ≥ 1 ✓。
- **(I4)**：即 SSW 定理本身（m=3 时该实例保证比值 ≥ c）。✓

四不变量成立，由引理逐次提升即得全部 m ≥ 3。**定理证毕。**∎

**推论（m = 4 的首个书面证明）**。特别地，m = 4 时竞争比 ≥ c。据我们所知，此前文献中没有这一事实的任何已发表证明（SSW 只构造了 m = 2, 3；CKK 引用了 m ≥ 3 的下界但未给出论证）。

## 5. 备选基例：m = 4 统一显式家族（另一条路）

本构造（新结果）未缩放时为 (1, 1, 1, r, r, r, s, s, s)，r = (2+√37)/11，s = (1+r)/3 = (13+√37)/33，OPT = 1+r。**整体除以 (1+r) 缩放**后验证四不变量：

- **(I1)**：OPT = 1（缩放）✓。
- **(I2)**：p_min = s/(1+r) = **1/3，精确成立**——这正是恒等式 s = (1+r)/3 的用途；
  p_max = 1/(1+r)。一个漂亮的巧合：1/(1+r) = 11/(13+√37) = 11(13−√37)/132 = (13−√37)/12 = **x，恰等于 SSW 的 x**！故 p_max = x < G 已由第 4 节验证。✓
- **(I3)**：停止点负载（已缩放）逐一核查：
  | 停止情形 | 负载 | ≥ 1 的验证 |
  |---|---|---|
  | 两个 1 同机 | 2/(1+r) = 2x ≈ 1.1529 | √37 ≤ 7 ✓ |
  | 第 1 个 r 与 1 同机 | (1+r)/(1+r) = 1 | 恰为 1 ✓ |
  | 三个 r 同机 | 3r/(1+r) = (√37−1)/4 ≈ 1.2707 | √37 ≥ 5 ✓ |
  | s 尾主支 | (2r+s)/(1+r) = c ≈ 1.1805 | ✓ |
  | 两 s 同低载机 | (1+2s)/(1+r) = (21−√37)/12 ≈ 1.2431 | √37 ≤ 9 ✓ |
  | s 上 1+r 机 | 4/3 ≈ 1.3333 | ✓ |
  全部 ≥ 1 ✓。
- **(I4)**：即我们的 m=4 五分支对抗分析（已经敌意复核：PROOF SOUND）。✓

因此该家族（m=4）同样可以作为归纳基例。两条路——"SSW 基例 + 填充引理"与"显式 m=4 家族 + 填充引理"——互相独立、互相印证。

## 6. 附注：为什么 G 被唯一确定，以及 G = 1 为何失败

**约束汇总**（以 p_min = 1/3、最小停止负载 = 1 为前提）：

1. 递减序：G ≥ p_max(J)；
2. 不变量 (I2′)：G > 1/3；
3. 情形 α：G + 1/3 ≥ c，即 **G ≥ c − 1/3 ≈ 0.847127**；
4. 情形 β：需要 L ≥ cG 在最小停止负载 L = 1 处成立，即 **G ≤ 1/c ≈ 0.847127**。

而 c − 1/3 = 1/c 恰恰就是 c 的定义方程 3c² − c − 3 = 0 的改写，于是可行区间 [c − 1/3, 1/c] 塌缩为**单点** G = (√37−1)/6。填充策略没有任何自由度：它能成功，完全系于 c 的这个代数性质。

**G = 1（朴素填充）失败的反例**。取 J′ = (1, x, x, 1−x, 1−x, 1/3, 1/3, 1/3)（m = 4）。算法把任务 1 独占第 4 台，然后**故意把两个 x 配对**：负载 2x ≈ 1.1529，但前缀 {1, x, x} 含大小为 1 的任务，故 OPT_4 ≥ 1（又 ≤ 1），比值 = 2x/1 ≈ 1.1529 < c。对手无论在此时停止还是继续打出余下任务，算法都能把最终比值压在约 1.15（余下任务 1−x, 1−x, 1/3, 1/3, 1/3 可分别入两台空机与低载机，最终 makespan ≈ 1.153，而 OPT(J′) = 1）。原因正是约束 4 被破坏：c·1 = c > 1 = 最小停止负载，情形 β 中"OPT 被大任务抬到 1"淹没了所有负载低于 c 的停止点（SSW 情形 A 的负载 1、OPT 2(1−x) ≈ 0.847，填充后比值塌缩为 1/1 = 1）。

**数学寓意**。提升引理不是免费的：它要求基例同时满足"OPT ≤ 1、p_min = 1/3、停止负载 ≥ 1"三个条件，而 G 的存在性等价于 c − 1/3 ≤ 1/c，即 3c² − c − 3 ≤ 0——c 恰好是这个二次方程的根，等号成立。SSW 常数的特殊性在填充引理中获得了第二次独立见证（第一次是 m=3 配平本身）。
