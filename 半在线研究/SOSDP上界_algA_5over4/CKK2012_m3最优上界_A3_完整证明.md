**支配（domination）**：设 $A=\{a_1\ge a_2\ge\dots\ge a_r\}$，$B=\{b_1\ge\dots\ge b_s\}$ 为两组非负数的非增序列，$r\ge s$。称 $A$ **支配** $B$，若 $a_i\ge b_i$ 对一切 $i\le s$ 成立。（原文定义：$a_1\ge b_1,\dots,a_s\ge b_s$。）

**约定**：把一个机器与其上的工件集合等同；"$p_j\in M$" 表示 $p_j$ 放在 $M$ 上。**失败工件存在之前，所有机器负载 $\le c$**——这是失败工件定义（"第一个"）的直接推论，下文反复使用，简记 **(NF)**（no-failure-yet）。

## 1. 问题与结论

**SOSDP**（semi-online scheduling with decreasing processing times）：$n$ 个工件按加工时间**非增**序到达，需立即、不可撤销地放到 $m$ 台同型机之一，目标最小化 makespan。算法性能用**竞争比** $C_{\mathcal A}/C^*$ 的最坏值衡量。

已知：

- LPT（Graham）对 SOSDP 的界为 $\frac43-\frac1{3m}$；
- $m=2$ 时 LPT 最优，界为 $\frac76$（SSW 2000）；
- Seiden–Sgall–Woeginger（SSW 2000）给出 $m\ge3$ 的**下界** $\frac{1+\sqrt{37}}{6}\approx1.18046$。

**Theorem 2（CKK 2012，本文要还原的定理）**：存在确定性算法 A3，使 SOSDP 在 $m=3$ 时的竞争比恰为

$$c=\frac{1+\sqrt{37}}{6}\approx1.18046 .$$

**推论（本文档的核心意义）**：由 SSW 下界，$m=3$ 的竞争比已被**完全确定**（上界 $=$ 下界 $=c$），该情形彻底闭合。一般 $m$ 下 $\frac54$ 与 $c$ 之间仍有显著 gap（原文 §4 列为开放问题）。

> 注意与 §2 的 Algorithm A 区分：Algorithm A 给的是**任意** $m\ge3$ 的 $5/4$；Algorithm **A3** 是 $m=3$ 的专用算法，界更小（$c<5/4$，也 $<4/3-1/9=11/9$，即优于 LPT 与 A）。两者不是同一个算法。

原文在 §1（p.349 右栏，紧接"我们给出 5/4 算法与 $m=3$ 最优算法"之后）用**一句话**交代复杂度，**摘要与 §4 结论都没有再提**，也没有任何实现细节、数据结构或证明：

> *"Both algorithms are elementary and have linear running time."*

两个算法的复杂度**推导**分别放在它们各自的位置：**A3 见 §2.1**；**Algorithm A 见同目录 `CKK2012_SOSDP_Algorithms_better_than_LPT.md` 的 §2.1**（该件是收录 §2 的摘要件）。结论对照：

| 算法 | 每工件成本 | 总计 | 结论 |
|---|---|---|---|
| A3（$m=3$） | $O(1)$ | $O(n)$ | 原文 "linear" **逐字成立** |
| Algorithm A（一般 $m$，朴素实现） | $O(m)$ | $O(nm)$ | — |

原文的 "linear" 对 A3 是准确的；对 Algorithm A 需要把 $m$ 视为常数，或隐含了未写出的数据结构。**这条也列入 §7 的补足清单**（补出的是「推导」而非原文已有的论证）。

## 2. Algorithm A3（原文照录 + 解读）

> **Algorithm A3.**
> 1. Assign jobs $p_1,p_2,p_3$ to machines $M_1,M_2,M_3$.
> 2. Set $L_0:=\max\{p_1,\ p_3+p_4\}$. If $p_1+p_4\le cL_0$, assign $p_4$ to $M_1$ and $p_5$ to $M_2$ and the remaining jobs to the machine with smallest load.
> 3. If $p_1+p_4>cL_0$, assign $p_4$ to $M_3$. Set $L:=\max\{L_0,\ \min\{p_2+p_5,\ p_3+p_4+p_5\}\}$. If $M_1$ contains only job $p_1$ and if $p_1+p_j\le cL$, assign the current job $p_j$, $j\ge5$, to machine $M_1$. Otherwise, assign $p_j$ to the machine with smallest load.

**中文释义与必须留意之处**：

1. 前三个工件一对一放置，$M_i$ 上就是 $p_i$。
2. $L_0=\max\{p_1,p_3+p_4\}$ 是 $C^*$ 的**下界**（见 §3.1 引理 1）。
3. 步骤 2 的放置（$p_4\to M_1$，$p_5\to M_2$）是**无条件强制**的，与负载无关；$n\le4$ 时步骤 2 只有 $p_4\to M_1$。
4. 步骤 3：$p_4\to M_3$；$L:=\max\{L_0,\min\{p_2+p_5,\ p_3+p_4+p_5\}\}$ 也是 $C^*$ 的**下界**（引理 1）。
   - 步骤 3 里"$M_1$ 只含 $p_1$"这一前提**只可能在放第一个额外工件时成立**：一旦某个 $p_j$ 放进 $M_1$，$M_1$ 就不再"只含 $p_1$"，此后所有工件都走"负载最小机"分支。因此：

> **引理 G（$M_1$ 永远至多 2 个工件）**：在 A3 的任何执行中 $|M_1|\le2$。而且 $M_1$ 上除 $p_1$ 外的那个工件（若有）只能是 $p_4$（步骤 2）或某个 $p_j,\ j\ge5$（步骤 3）。
> **推论 G′**：任何时刻 $\ell(M_1)\le p_1+p_4$。
> *证明*：步骤 2 只加 $p_4$；步骤 3 的"$M_1$ 只含 $p_1$"前提使步骤 3 至多加 1 个工件，且要求 $j\ge5$，故该工件 $\le p_5\le p_4$。$\square$

$L_0,L$ 是下界这一点，正是整套证明的"值坐标"来源（后文所有 $L_0,L\le1$ 都由此而来，因为 $C^*=1$）。

### 2.1 A3 的运行时间：$O(n)$（原文一句断言，本文补出推导）

**计算模型**：单位成本 RAM；只统计基本算术与比较运算；$c=\frac{1+\sqrt{37}}{6}$ 视为常数。工件按非增序到达，A3 只需当前工件（无需未来信息）。

**逐步成本**（除标注外都是 $O(1)$）：

| 阶段 | 操作 | 成本 |
|---|---|---|
| 步骤 1 | 3 次放置 | $O(1)$ |
| 步骤 2 | $L_0=\max\{p_1,p_3+p_4\}$（1 加 + 1 max）；比较 $p_1+p_4$ 与 $cL_0$；至多 2 次放置 | 一次性 $O(1)$ |
| 步骤 2 分支 | $p_5$ 由步骤 2 强制入 $M_2$；其余每个 $j\ge6$ 的工件在 3 台中取负载最小者（2 次比较） | 每工件 $O(1)$ |
| 步骤 3 | $L=\max\{L_0,\ \min\{p_2+p_5,\ p_3+p_4+p_5\}\}$（2 加 + 1 min + 1 max） | 一次性 $O(1)$ |
| 步骤 3 分支 | 每个 $j\ge5$ 的工件：① 判定"$M_1$ 是否仍只含 $p_1$"（维护 $M_1$ 的工件计数，上限 2）；② 判定 $p_1+p_j\le cL$；③ 否则在 3 台中取负载最小者（2 次比较） | 每工件 $O(1)$ |

**结论**：每个工件至多 $\kappa$ 次基本运算（$\kappa$ 与 $n,m$ 无关），故

$$T_{\mathrm{A3}}(n)=O(n),\qquad \text{额外空间 } O(1)$$

（只需 3 个负载计数器与 3 个工件计数器）。$m=3$ 固定，所以"每工件常数工作"在这里是**逐字**成立的——原文那句 "linear running time" 对 A3 准确无误。

**关于与 $c$ 的比较（"elementary" 的另一层含义）**：$c$ 是无理数，但 $p_1+p_j\le cL$（$L>0$）可以用**精确的有理/整数运算**在 $O(1)$ 内判定，不需要浮点、也没有精度问题：

- 若 $6(p_1+p_j)\le L$，则因 $c>1$ 直接成立；
- 否则 $p_1+p_j\le cL \iff 6(p_1+p_j)-L\le\sqrt{37}\,L \iff \big(6(p_1+p_j)-L\big)^2\le 37L^2$。

亦即 A3 全程只做常数次四则运算与比较，这与"elementary"相符（原文未展开，本文补出）。

## 3. Theorem 2 的证明

### 3.1 反例设定

**归一化**：A3 的每一步只比较形如 $p_i+p_j$ 与 $c\cdot\max\{\cdot\}$ 的量，这些比较在实例整体乘 $\lambda>0$ 时两边同比放大，故 A3 与 $C^*$ 都是正齐次的，$C_{\mathrm{A3}}/C^*$ 尺度不变。于是可设

$$C^*=1,\qquad \ell(M_i^*)\le1\ (i=1,2,3),\qquad \sum_{j=1}^n p_j\le3,$$

并（w.l.o.g.）设 $p_1\in M_1^*$（最优解中含最大工件的机器记为 $M_1^*$）。

**引理 1（$L_0,L$ 都是 $C^*$ 的下界）**：$L_0\le C^*$；且在 A3 走步骤 3 时 $L\le C^*$。

*证明（$L_0$ 部分，完整）*：$C^*\ge p_1$ 显然。又 $n\ge4$ 时 $p_3+p_4\le C^*$：最优解中必有某台机器含 $\{p_1,p_2,p_3,p_4\}$ 中至少两个工件（4 个工件、3 台机器），设它们是 $p_i,p_j$（$i\ne j,\ i,j\le4$），则 $C^*\ge p_i+p_j\ge p_3+p_4$（逐对检查：$(3,4)$ 取等；$(1,2)$ 用 $p_1\ge p_3,p_2\ge p_4$；$(1,3),(1,4),(2,3),(2,4)$ 分别用 $p_1\ge p_4$ 或 $p_2\ge p_4$）。故 $L_0=\max\{p_1,\ p_3+p_4\}\le C^*$。$\checkmark$

*证明（$L$ 部分）*：$L=\max\{L_0,\ \min\{p_2+p_5,\ p_3+p_4+p_5\}\}$，故只需

$$\min\{p_2+p_5,\ p_3+p_4+p_5\}\le C^*. \tag{i}$$

设最优解中含 $p_5$ 的机器为 $M_5=\{p_5\}\cup X$，于是 $\ell(M_5)\le C^*$；由 O3，$|X|\le2$。三条直接结论：

- $p_2\in X\Longrightarrow C^*\ge\ell(M_5)\ge p_2+p_5$，即 (i) 成立；
- $\{p_3,p_4\}\subseteq X\Longrightarrow C^*\ge p_3+p_4+p_5$，即 (i) 成立；
- 若 $p_2\notin X$ 且 $\{p_3,p_4\}\not\subseteq X$，则 $p_2,p_3,p_4$ 中至少两个落在另外两台机器 $M',M''$ 上，逐个检查同机的那一对（任意两个下标 $\le4$ 的工件之和 $\ge p_3+p_4$）并结合 $M'$ 或 $M''$ 的负载 $\le C^*$，同样得到 (i) 成立。

最后一种情形的枚举稍繁（原文只用 "It can be easily seen" 一句带过，未展开），本文除上面的三条直接结论外，另用**精确 LP** 复核 (i)（§6）：在所有满足"每台最优机 $\le3$ 件、负载 $\le1$、所有工件 $>\alpha$"的非增实例上，(i) 左端的最大值恰为 $1$（$C^*=1$ 归一化），取到于 $p_1=\dots=p_5=\frac12$；后文真正用到的两条加强形式

$$\big(p_2\ge p_3+p_4\ \Rightarrow\ p_3+p_4+p_5\le C^*\big),\qquad \big(p_2<p_3+p_4\ \Rightarrow\ p_2+p_5\le C^*\big)$$

的 LP 最大值同样恰为 $1$。故 (i) 成立，$L\le C^*=1$。$\square$

**反例与极小性**：反设 A3 不是 $c$-竞争的，则存在实例使 $C_{\mathrm{A3}}>c\,C^*=c$，取其中**工件数最少**者，称极小反例，记其最后一个失败工件为 $z$。设 $z$ 被放到机器 $M_z$，放之前 $\ell(M_z)=\ell_{\min}$（$z$ 总被放到负载最小的机器上），则

$$\ell_{\min}+z>c. \tag{$\star$}$$

**$z$ 是最后一个工件**：若 $z$ 之后还有工件，则删去它们得到工件数更少的实例；A3 在 $z$ 之前的全部行为与原来逐字相同，故该实例的 $C_{\mathrm{A3}}\ge\ell_{\min}+z>c\ge c\,C^*_{\text{新}}$（删工件不会增大 $C^*$），仍是反例，与极小性矛盾。故 $z=p_n$。

> 原文明说 "Note that $z$ is always assigned to a machine with the smallest load"，即 $(\star)$。

### 3.2 基例：$n\le5$（原文断言，未展开）

> 原文：*"It can be easily seen that the bounds $L_0,L$ calculated by A3 are lower bounds on the optimal makespan, i.e. $L_0\le L\le1$, and that A3 yields the claimed bound for an instance with at most 5 jobs."*

后文两处用到它：§4.1 排除 $n=9$ 之后要靠它排除 $n\le5$（得 Observation O4），以及 §3.1 的极小性论证。

$L_0\le L\le1$ 由引理 1 与 $C^*=1$ 立即得到。基例的竞争比断言：

- $n=3$：A3 把 $p_1,p_2,p_3$ 分置三机，makespan $=p_1\le C^*$。$\checkmark$
- $n=4$：若 $p_1+p_4\le cL_0$，则 $p_4\to M_1$，makespan $=\max\{p_1+p_4,\,p_2,\,p_3\}\le\max\{cL_0,L_0\}=cL_0\le cC^*$（等号在 $p=(1,c-1,c-1,c-1)$ 取到，此时 $L_0=p_1=C^*=1$，makespan $=1+(c-1)=c$）；否则 $p_4\to M_3$，makespan $=\max\{p_1,p_2,p_3+p_4\}=L_0\le C^*$。$\checkmark$
- $n=5$：原文一句话断言，未展开。本文用**逐分支精确 LP** 认证（细节见 §6 与附录 B）：A3 的判定只涉及有限个线性比较（$L_0$ 由 $p_1$ 还是 $p_3+p_4$ 取到；步骤 2 的条件真假；$L$ 的 $\max/\min$ 由哪一项取到；步骤 3 中 $p_1+p_j\le cL$ 的真假，以及假分支下"哪台机器负载最小"），每个分支片内 A3 的 makespan 是 $p$ 的线性函数；对每一片在"$C^*\le1$（即存在每台负载 $\le1$ 的装箱）、$p_1\ge\dots\ge p_5\ge0$、该片线性不等式"构成的多面体上求该线性函数的最大值，共 34 片，全部取到最优（无无界、无异常）：

$$n=3:\ R_3=1.0;\qquad n=4:\ R_4=c;\qquad n=5:\ R_5=c,$$

其中 $R_n:=\sup\{C_{\mathrm{A3}}/C^*\}$（归一化 $C^*\le1$ 与正齐次性使该量可如此计算），且**上确界可达**：

$$p=(1,\ c-1,\ c-1,\ c-1)\quad(n=4)$$

即 $C^*=1$（$M_1^*=\{1\}$，$M_2^*=\{c-1,c-1,c-1\}$），而 A3 走步骤 2 的真分支（$p_1+p_4=c=cL_0$，取等），$p_4\to M_1$，makespan $=1+(c-1)=c$，比值**恰为 $c$**。因此基例断言成立，且 $c$ 在 $n=4$ 就已紧。

### 3.3 观察 O1–O3（值坐标与规模上界）

> **Observation O1.** $(c-1/3)c=1$。
> *证明*：$c$ 是 $x^2-x/3-1=0$ 的正根。$\square$

> **Observation O2.** $z>\dfrac32(c-1)=\alpha\approx0.27069$。
> *证明*：全部工件总加工时间 $\le3$（§3.1），故 $z$ 到来前总负载 $\le 3-z$，从而存在机器负载 $\le(3-z)/3=1-z/3$；由 $(\star)$，把 $z$ 放到负载最小的机器后有 $\big(1-\frac z3\big)+z>c$，即 $1+\frac{2z}3>c$，即 $z>\frac32(c-1)$。$\square$

> **Observation O3.** 所有工件的加工时间都 $>\dfrac32(c-1)$；最优解每台机器至多 3 个工件；从而反例中 $n\le9$。
> *证明*：$z=p_n$ 是最小工件，故每个工件 $\ge z>\alpha$。由 $\alpha=0.27069\ldots>1/4$，一台机器若含 4 个工件则负载 $>4\alpha>1=\ell(M_i^*)$ 上限，矛盾；故每台最优机器至多 3 个工件，$n\le3\times3=9$。$\square$

**注**：$\alpha>1/4$ 与"每台最优机器 $\le3$ 个工件"是后文所有计数论证的枢轴。原文 O3 中的界就是 $\frac32(c-1)$（本文档已按原图逐字核对，OCR 在此处易误读为其它系数）。

## 4. 观察 O4–O9（p.350–351 右栏）

### 4.1 $n=9$ 的排除与 O4

设 $n=9$。由 O3，最优解三台机器**各恰含 3 个工件**。

**(i) A3 的 makespan $\le p_1+p_4+p_9$ 上界（原文 "there is a machine with at most two jobs and load not exceeding $p_1+p_4$. Thus, …"）。**
由引理 G，$M_1$ 至多 2 件；由引理 G′，任何时刻 $\ell(M_1)\le p_1+p_4$（$M_1$ 上第二个工件要么是 $p_4$，要么是某个 $p_j,j\ge5$，故 $\le p_4$）。
$z=p_9$ 被放到负载最小的机器 $M_z$ 上，放之前 $\ell(M_z)=\ell_{\min}\le\ell(M_1)\le p_1+p_4$。又 $z$ 是失败工件，故 $\ell_{\min}+z>c$；而 $(\text{NF})$ 给出 $z$ 到来前**所有**机器的负载 $\le c$。于是 $\ell_{\min}+z$ 严格大于此前所有负载，即 A3 的最终 makespan 恰是它：

$$C_{\mathrm{A3}}=\ell_{\min}+p_9\le(p_1+p_4)+p_9 .$$

> 这一步是原文 "Thus" 的完整含义：**失败条件本身**保证接收 $z$ 的机器成为最终的最大负载机，因此只需估计 $M_1$ 的负载（引理 G′），无需估计另两台机器。这也是原文强调"至多两个工件"的原因。

**(ii) $p_3+p_4+p_9\le1$ 与 $p_4+p_9\le2/3$。**
$\{p_1,p_2,p_3,p_4\}$ 中必有两个同机（4 个工件、3 台机器），设该机为 $A$，其第三个工件 $\ge p_9$。设同机的两个是 $p_i,p_j$，则 $p_i+p_j\ge p_3+p_4$（同引理 1），于是

$$p_3+p_4+p_9\le \ell(A)\le1. \tag{1}$$

**（原文的 "hence"）** 原文由 (1) 直接写 "$p_4+p_9\le2/3$"，中间一步未展开。注意**不能**用 $p_3\ge1/3$（如 $p=(0.5,0.5,0.2707,\dots,0.2707)$ 是可行构型而 $p_3=0.2707<1/3$，见 §6 的 LP 反例）。正确的推导如下：

> **引理 2**：$n=9$（每台最优机器恰 3 个工件、负载 $\le1$、所有工件 $>\alpha$）时 $p_4+p_9\le2/3$。
> *证明*：先注意 $3p_9\le1$（$p_9$ 所在机器含 3 个工件，每个 $\ge p_9$），即 $p_9\le1/3$。
> 反设 $p_4+p_9>2/3$。则 $p_4>2/3-p_9\ge1/3$，于是 $p_1,p_2,p_3,p_4>1/3$。
> 设 $A$ 为含 $p_4$ 的机器，$B$ 为含 $p_9$ 的机器，二者各含 3 个工件，$A$ 的另两个工件（记为 $a,b$）、$B$ 的另两个工件（记为 $u,w$）都 $\ge p_9$。
> (a) 若 $p_9\in A$：三个工件中有两个是 $p_4,p_9$，第三个 $\ge p_9$，故 $p_4+p_9\le\ell(A)-p_9\le1-p_9\le2/3$，与反设矛盾。故 $p_9\notin A$，同理 $p_4\notin B$。
> (b) 若 $A$ 含某个 $p_i\ (i\le3)$：则 $p_i\ge p_4$，故 $\ell(A)\ge p_4+p_i+\min\{a,b\}\ge2p_4+p_9>2(2/3-p_9)+p_9=4/3-p_9\ge1$（最后一步用 $p_9\le1/3$），矛盾。故 $A=\{p_4,a,b\}$，其中 $a,b\in\{p_5,p_6,p_7,p_8\}$。
> (c) 同理 $B$ 至多含 $\{p_1,p_2,p_3\}$ 中的一个（含两个则 $\ell(B)\ge p_9+2p_4>1$）。
> 由 (b)(c)，$\{p_1,p_2,p_3\}$ 中至少有一个在第三台机器 $C$ 上，且 $C$ 含 3 个工件，其第三个工件 $\ge p_9$。若 $C$ 含 $\{p_1,p_2,p_3\}$ 中的**两个**，则 $\ell(C)\ge2p_4+p_9>1$，矛盾。故 $C$ 恰含其中一个，即 $A$ 不含 $\{p_1,p_2,p_3\}$（已由 (b)）、$B$ 恰含一个、$C$ 恰含一个——但 $\{p_1,p_2,p_3\}$ 有 3 个，$B\cup C$ 只放得下 2 个，矛盾。$\square$
> *（等价地：设 $B$ 与 $C$ 分装 3 个 $\{p_1,p_2,p_3\}$ 的份额必为 $1+2$ 或 $2+1$ 或 $0+3$，后两类都给出某机含两个 $>1/3$ 的大件再加一个 $\ge p_9$，负载 $>2p_4+p_9>1$。）*

**注**：引理 2 也可以直接由 LP 得到（§6）：在"$n=9$、每机 3 件、负载 $\le1$、所有工件 $>\alpha$"的全体构型上，$p_4+p_9$ 的最大值恰为 $2/3$（取到于 $p_1=\dots=p_9=1/3$）。

**(iii) $p_1\le1-2z$ 与收尾不等式。**
由 $p_1\in M_1^*$ 且 $M_1^*$ 恰含 3 个工件，其另两个工件分别 $\ge p_8,p_9$，故

$$p_1+p_8+p_9\le1 \quad\Longrightarrow\quad p_1\le1-2z,\qquad 1-2z=0.4586187\ldots\approx0.45862 . \tag{2}$$

结合 (i)(ii)：

$$C_{\mathrm{A3}}\le p_1+p_4+p_9\le (1-2z)+\tfrac23=\tfrac53-2z=1.1252854\ldots<c,$$

与 $z$ 是失败工件（$C_{\mathrm{A3}}>c$）矛盾。故 $n\ne9$。又 $n\le5$ 由基例（§3.2）排除，于是

> **Observation O4.** 反例中 $n\in\{6,7,8\}$。

### 4.2 观察 O5 及其证明

> **Observation O5.** 若 $n\ge7$，则 $p_3\le\frac12$，$p_7\le\frac13$，且 $p_6+p_7\le\frac23$。
> 若 $n=8$，则 $p_2\le\frac12$，且 $p_5+p_8\le\frac23$。

> 原文：*"Elementary calculations using (O3) and the fact that the load of each machine in the optimal solution is at most one, deliver the following bounds summarized in Observation O5."*

下文给出全部五条界的显式证明（记 $\alpha=\frac32(c-1)>1/4$，所有工件 $>\alpha$；最优解每机 $\le3$ 件、负载 $\le1$）。每一台机器上"大件"（$>1/3$ 的工件）至多 2 个，因为 3 个之和 $>1$。

**(1) $n\ge7\Rightarrow p_3\le1/2$。** 反设 $p_3>1/2$。则 $p_1,p_2,p_3$ 两两不能同机（和 $>1$），分处三机；含 $p_i$ 的机器剩余容量 $1-p_i<1/2$，而再放 2 个工件至少需要 $2\alpha=0.5414\ldots>1/2$，故每台至多再放 1 个工件。于是 $n\le3\cdot2=6<7$，矛盾。$\square$

**(2) $n\ge7\Rightarrow p_7\le1/3$。** 反设 $p_7>1/3$，则 $p_1,\dots,p_7$ 全 $>1/3$；每机至多 2 个，故 $n\le6<7$，矛盾。$\square$

**(3) $n\ge7\Rightarrow p_6+p_7\le2/3$。** 若 $p_6\le1/3$，则 $p_6+p_7\le2p_6\le2/3$。若 $p_6>1/3$：由 (2) 知 $p_7\le1/3$；$p_1,\dots,p_6$ 全 $>1/3$，每机至多 2 个，6 个恰好填满三机的各 2 个"大件位"。$p_7$（非大件）必须放进某台已有 2 个大件的机器，该机负载 $\ge b_1+b_2+p_7\ge2p_6+p_7$（$b_1,b_2$ 是这两个大件，都 $\ge p_6$），故 $2p_6+p_7\le1$，即
$$p_6+p_7\le 1-p_6\le\tfrac23\quad(\text{用 }p_6>\tfrac13).\qquad\square$$

**(4) $n=8\Rightarrow p_2\le1/2$。** 反设 $p_2>1/2$。$p_1,p_2$ 不能同机，且由 (1) 的同一论证（剩余容量 $<1/2<2\alpha$），含 $p_1$ 与含 $p_2$ 的机器各至多 2 个工件；$n=8$ 时三机工件数为 $(3,3,2)$，第三台 $\le3$，故 $n\le2+2+3=7<8$，矛盾。$\square$

**(5) $n=8\Rightarrow p_5+p_8\le2/3$。**
先注意 $p_8\le1/3$（否则 8 个工件全 $>1/3$，每机至多 2 个，$n\le6$）。若 $p_5\le1/3$，则 $p_5+p_8\le2/3$ 立得。以下设 $p_5>1/3$，于是 $p_1,\dots,p_5$ 都是大件，每机至多 2 个大件。
- 若存在某台机器含 2 个大件再加第 3 个工件：该机负载 $\ge2p_5+p_8$（两个大件 $\ge p_5$，第三个工件 $\ge p_8$），故 $2p_5+p_8\le1$，于是 $p_5+p_8\le1-p_5<2/3$（用 $p_5>1/3$）。$\checkmark$
- 否则（没有任何机器含"2 个大件 + 第 3 个工件"）：5 个大件分到三台、每台 $\le2$ 个，故份额必为 $(2,2,1)$；含 2 个大件的两机各恰含 2 个工件（否则就出现"2 个大件+第 3 件"），于是剩余的全部 3 个非大件（$8-5=3$）都挤在第三台上，该台共 $1+3=4$ 个工件；但 4 个工件之和 $>4\alpha>1$，与负载 $\le1$ 矛盾。故此情形不可能。$\square$

**紧性**：五条界的 LP 最大值分别恰为 $1/2,1/3,2/3,1/2,2/3$，取到点多为"全部工件 $=1/3$"或"若干大件 $=1/2$"（§6）。因此原文这些界都不能再改进。

### 4.3 观察 O6

先看**反面情形**（原文在 O6 之前的一段）：

> 设 $p_1+p_4\le cL_0$。此时 $p_4\in M_1$。又 $p_5$ 可放 $M_2$、$p_6$ 可放 $M_3$，分别由 (O5) 得 $p_3+p_6+p_7\le\frac76<c$（用 $p_3\le\frac12$、$p_6+p_7\le\frac23$）且 $p_7$ 可放进 $M_3$；若 $n=8$，则 $p_2+p_5+p_8\le c$ 且 $p_8$ 可放进 $M_2$。由 (O4) 反例至多 8 个工件，故不存在失败工件——与反例矛盾。

> **Observation O6.** $p_1+p_4>cL_0$，即 $p_4$ 被 A3 放到 $M_3$。

*说明（本文补足，使该段的"可放"断言变成完整的负载估计）*：
此情形的初始状态是 $M_1=\{p_1,p_4\}$，$M_2=\{p_2,p_5\}$，$M_3=\{p_3\}$（$p_5\to M_2$ 由步骤 2 强制）。由 (O4) 后面至多还有 $p_6,p_7$（$n\le8$）。又因 $M_1$ 已有 2 件（引理 G 的上限），**"$M_1$ 只含 $p_1$"的前提不再成立**，故从此每个工件都进"负载最小机"。
- **$p_6$**：$M_3$ 是三者中负载最小的（$p_3\le p_2\le p_2+p_5$ 且 $p_3\le p_1\le p_1+p_4$），故 $p_6\to M_3$，新负载 $=p_3+p_6\le p_3+p_6+p_7\le\frac76<c$（(O5) 的 $p_3\le\frac12$、$p_6+p_7\le\frac23$）。
- **$p_7$**：此时三台负载为 $(p_1+p_4,\ p_2+p_5,\ p_3+p_6)$，故 $\ell_{\min}\le\ell(M_3)=p_3+p_6$，新负载 $\le p_3+p_6+p_7\le\frac76<c$。
- **$p_8$**（仅 $n=8$）：$p_7$ 至多改动三台中的一台，故另两台负载仍在 $\{p_1+p_4,\ p_2+p_5,\ p_3+p_6\}$ 中；取其中未被改动的一台：若 $M_3$ 未改，则 $\ell_{\min}+p_8\le p_3+p_6+p_8\le p_3+p_6+p_7\le\frac76<c$；若 $M_3$ 被 $p_7$ 占用，则 $M_2$ 未改，$\ell_{\min}+p_8\le p_2+p_5+p_8\le\frac12+\frac23=\frac76<c$（(O5) 的 $n=8$ 条款）。
- 三步都不产生负载 $>c$ 的机器，与"反例存在失败工件"矛盾。故 $p_1+p_4>cL_0$ 成立，即 $p_4\to M_3$。$\square$

### 4.4 观察 O7（两机 LPT 支配论证）

> **Observation O7.** $M_1^*$ 至少含 2 个工件，且 $p_1\le1-z\le0.73$。

*证明（原文）*：
- **支配定义**：$A=\{a_1\ge\dots\ge a_r\}$ **支配** $B=\{b_1\ge\dots\ge b_s\}$（$r\ge s$）若 $a_i\ge b_i,\ i\le s$。
- 反设 $M_1^*$ **只含** $p_1$。则最优解中其余全部工件都在 $M_2^*,M_3^*$ 上。A3 的 $M_2,M_3$ 上的工件集合（记 $\mathcal J$）是 $\{p_2,\dots,p_n\}$ 的子集，而 $M_2^*,M_3^*$ 上的工件集合恰为 $\{p_2,\dots,p_n\}$（记 $\mathcal J^*$，按非增序）。**子集被全集支配**，故 $\mathcal J$ 被 $\mathcal J^*$ 支配。
- 因此"把 $\mathcal J$ 放到两台机器上的最优 makespan" $\le$ "把 $\mathcal J^*$ 放到两台机器上的最优 makespan" $=C^*_{\text{两机}}\le1$（后者正是原实例最优解在 $M_2^*,M_3^*$ 上的负载，$\le1$）。
- **两机 LPT 的界是 $7/6$**（SSW：$m=2$ 时 LPT 最优，竞争比 $\frac76$）。故把 $\mathcal J$ 用 LPT 放到两台机器，任何子集的负载都 $\le\frac76 C^*_{\text{两机}}\le\frac76$。特别地，**$z$ 到来前**，$M_2,M_3$ 上任何机器的负载 $\le\frac76$。
- 由 (O6)，步骤 2 的分支不成立（$p_4$ 不去 $M_1$），$M_1$ 上至多再有 1 个工件（引理 G）；在 $M_1$ 未被补充工件之前，A3 对 $M_2,M_3$ 的放置与"把 $\mathcal J$ 逐个放到当前负载最小机"的 LPT 行为一致。于是 $z$ 到来前存在 $M\in\{M_2,M_3\}$ 使 $\ell(M)+z\le\frac76<c$；$z$ 又总是进负载最小机，故 $\ell_{\min}+z\le\frac76<c$，与 $(\star)$ 矛盾。
- 故 $M_1^*$ 至少含 2 个工件；记其第二大的工件为 $q\ (\ge z)$，则 $p_1+q\le1\Rightarrow p_1\le1-q\le1-z$，并用 (O2)：$1-z<1-\alpha=0.72931\ldots\le0.73$。$\square$

### 4.5 观察 O8、O9

**先证 $L_0<c-\frac13$。**

反设 $L_0\ge c-\frac13$。由 (O1) $(c-\frac13)c=1$ 得 $cL_0\ge1$，再由 (O6) 得

$$p_1+p_4>cL_0\ge1 \quad\Longrightarrow\quad p_1>\tfrac12 .$$

于是 $M_1^*$ 含 $p_1$ 且 $p_1>\frac12$，故它**恰含 2 个工件**（(O7) 说至少 2 个；(O3) 说至多 3 个；而 $p_1>\frac12$ 时第 3 个工件会使其负载 $>\frac12+\alpha>1$）。
**先补出原文一句带过的关键事实 $q^*\ge p_5$**（这是支配链成立的前提，原文写 "the second job on $M_1$ is at least as large as the second job on $M_1^*$"，未说明为何）。注意 $c-\frac13=\frac1c$（O1），而 $L_0=\max\{p_1,\ p_3+p_4\}$ 只有两种取值：

- **$L_0=p_1$**：由 $L_0\ge c-\frac13$ 得 $p_1\ge\frac1c=0.84712\ldots$；而 $p_1\in M_1^*$、$\ell(M_1^*)\le1$ 给出第二件 $q^*\le1-p_1\le0.15287\ldots<\alpha$，与 O3（所有工件 $>\alpha$）矛盾。故此情形不发生。
- **$L_0=p_3+p_4$**：由 (O6) $p_1+p_4>cL_0\ge c\,(c-\frac13)=1$（O1），即 $p_1+p_4>1$。若 $q^*\ge p_4$，则 $p_1+q^*\ge p_1+p_4>1$，与 $\ell(M_1^*)\le1$ 矛盾。故必有 $q^*<p_4$，即 $q^*\in\{p_5,\dots,p_n\}$。

因此在 $L_0\ge c-\frac13$ 的分支里恒有 $q^*\ge p_5$。又 $p_1+q^*\le1\le cL_0\le cL$，即 $q^*$ **满足**步骤 3 的接受条件（$j\ge5$ 且 $p_1+p_j\le cL$）；A3 处理 $j\ge5$ 时取的是满足该条件的**最大**工件（$p_j$ 随 $j$ 递减，第一个满足条件的即最大者），故

> $M_1$ 上的第二件 $q$ 满足 $q\ge q^*$。

于是 A3 的 $M_2\cup M_3$ 上的工件多重集 $=$ $\{p_2,\dots,p_n\}\setminus\{q\}$ 被 $M_2^*\cup M_3^*$ 上的 $\{p_2,\dots,p_n\}\setminus\{q^*\}$ **支配**（删去更大的元素后剩下的序列逐项更小）。由"支配 $\Rightarrow$ 两机最优值不增"与两机 LPT 界 $7/6$，与 (O7) 完全同型地得到 $\ell_{\min}+z\le\frac76<c$，矛盾。故

> **Observation O8.** $L_0<c-\frac13$。

**再证 O9。**

反设 $p_1+p_6>c$。则 $M_1^*$ 不含 $\{p_2,\dots,p_6\}$ 中任何工件（否则该机负载 $\ge p_1+p_6>c>1$）。5 个工件 $\{p_2,\dots,p_6\}$ 全在 $M_2^*,M_3^*$ 上，故其中一台含至少 3 个，该机负载 $\ge3p_6$，于是 $p_6\le\frac13$。结合 (O7)：

$$p_1+p_6\le0.73+\tfrac13=1.0633\ldots<c,$$

与反设 $p_1+p_6>c$ 矛盾。故

> **Observation O9.** $p_1+p_6\le c$。（顺带 $p_2+p_6\le p_1+p_6\le c$。）

## 5. 主证明：两种情形

以下 (O6) 已保证 $p_4\in M_3$，故 $M_1$ 只会（至多一次地）在步骤 3 中被补充一个工件。

### 5.1 Case 1：$p_2\ge p_3+p_4$

> *原文*：Since $p_1\ge p_2\ge p_3+p_4>0.54$ by (O2), machines $M_1^*$ and $M_2^*$ contain at most 2 jobs and we have by (O4) that $n\le7$. By the definition of $L$, $p_3+p_4+p_5\le L\le1$. Thus, if one of the jobs $p_5,p_6,p_7$ is assigned by A3 to machine $M_3$, the load of $M_3$ is no larger than $c$. From (O9) we know that $p_2+p_6\le c$ and if $p_5$ or $p_6$ is assigned by A3 to machine $M_2$ the load of $M_2$ is also no larger than $c$. Finally, by (O7) machine $M_1^*$ contains at least two jobs, which means $p_1+p_7\le1$. Thus, $p_7$ can be assigned to machine $M_1$ by A3 without exceeding $c$. Since A3 always assigns jobs to the machine with smallest load or to a machine for which the total load does not exceed $c$, none of the jobs $p_1,\dots,p_7$ can be a failure job.

**补足与解读**：

1. $p_3+p_4>2z>0.54$：因 $p_3,p_4\ge z=p_n$ 而 $z>\alpha$，故 $p_3+p_4\ge2z>2\alpha=0.5414>0.54$。于是 $p_2\ge p_3+p_4>0.54$、$p_1>0.54$。
2. $M_1^*,M_2^*$ 各至多 2 件：$p_i>0.54$ 时同机再放一件（$\ge z>\alpha$）就超 1。结合 (O3) 每机 $\le3$ 件得 $n\le2+2+3=7$（这就是 Case 1 下 $n\le7$ 的来源；配合 (O4) 得 $n\in\{6,7\}$，故参与分析的只有 $p_1,\dots,p_7$）。
3. $p_3+p_4+p_5\le L$：因 $L=\max\{L_0,\min\{p_2+p_5,p_3+p_4+p_5\}\}$，而 $p_2\ge p_3+p_4$ 使 $p_3+p_4+p_5\le p_2+p_5$，故 $\min\{p_2+p_5,p_3+p_4+p_5\}=p_3+p_4+p_5$，于是 $L\ge p_3+p_4+p_5$。又 $L\le1$（引理 1 与 $C^*=1$）。
4. **判据的统一形式（本文补出）**：称工件 $p_j$ 有"合法落点"，若 A3 放 $p_j$ 之前存在某台机器负载 $\le c-p_j$。此时 A3 所选机器的负载（$=\ell_{\min}$）$\le c-p_j$，故新负载 $\le c$，$p_j$ 不是失败工件。对 $p_5,p_6,p_7$ 逐一给出这样的机器：
   - **$p_5$**：$M_3$ 当时为 $\{p_3,p_4\}$，$\ell(M_3)+p_5=p_3+p_4+p_5\le L\le1\le c$ ✓（这正是 $\min\{p_2+p_5,p_3+p_4+p_5\}=p_3+p_4+p_5$ 与 $L\le1$ 的用处）。
   - **$p_6$**：$M_3$ 未变或已被 $p_5$ 占用时，$3$ 台机器中必有**一台未被 $p_5$ 改动**（$p_5$ 只落一处；$M_1$ 即使被补也至多补一件，引理 G）：
     · 未改的是 $M_3$：$p_3+p_4+p_6\le p_3+p_4+p_5\le L\le1\le c$（用 $p_6\le p_5$）；
     · 未改的是 $M_2$：$p_2+p_6\le p_1+p_6\le c$（O9）；
     · 未改的是 $M_1$：$p_1+p_6\le c$（O9）。
     ✓（原文此处只写 "From (O9) we know that $p_2+p_6\le c$ and if $p_5$ or $p_6$ is assigned by A3 to machine $M_2$ the load of $M_2$ is also no larger than $c$"。）
   - **$p_7$**：$p_5,p_6$ 至多各改动一台机器，故 $3$ 台机器中必有一台**未被这两步改动**：
     · 未改的是 $M_1$：$p_1+p_7\le p_1+p_6\le c$（O9，用 $p_7\le p_6$）；
     · 未改的是 $M_2$：$p_2+p_7\le p_2+p_6\le p_1+p_6\le c$（O9）；
     · 未改的是 $M_3$：$p_3+p_4+p_7\le p_3+p_4+p_5\le L\le1\le c$。
     ✓（原文此处用 (O7) 的另一条信息：$p_1+p_7\le1\le c$，因为 $M_1^*$ 至少 2 件且 $n\le7$，其第二件 $\ge p_7$。）
5. 收尾：A3 要么把工件放进"负载最小机"，要么放进"总负载不超过 $c$ 的机器"（步骤 3 的前半支就是后者）。上面 4 保证了**每一个** $p_5,p_6,p_7$ 都有合法落点，故 $z$ 不可能落在它们之中；$p_1,\dots,p_4$ 的放置负载分别为 $p_1,\ p_2,\ p_3,\ p_3+p_4\le L_0\le1<c$。所以 Case 1 无失败工件，与反例矛盾。

### 5.2 Case 2：$p_2<p_3+p_4$

由 (O6)，$p_4\to M_3$，且 $L=\max\{L_0,\min\{p_2+p_5,p_3+p_4+p_5\}\}=\max\{p_1,\,p_2+p_5,\,p_3+p_4\}\le1$（因 $p_2<p_3+p_4$ 时 $p_2+p_5<p_3+p_4+p_5$，故 $\min=p_2+p_5$，再由 $L_0=\max\{p_1,p_3+p_4\}$ 展开）。

工件序列此时最多到 $p_8$（O4）。分析按 $p_5,p_6$ 的去向（A3 的放置）分子情形。

> **通用判据（同 §5.1 第 4 点）**：要让 $p_j$ 不成为失败工件，只需指出一台**在放 $p_j$ 之前**负载 $\le c-p_j$ 的机器（A3 选的负载最小机负载 $\le$ 它，故新负载 $\le c$）。下面每个子情形都给出这样一台机器；若该机器恰被前一件占用，则因 $p_j\le p_{j-1}$ 且"最近两步至多改动三台中的两台"，总可改用另一台**未被改动**的机器。

可用的事实：
- $p_3+p_4\le L_0\le1$；$p_1+p_6\le c$（O9）；
- $p_7\le\frac13$、$p_8\le p_7\le\frac13$（O5）；$L_0<c-\frac13$（O8）；
- $M_1$ 至多 2 件（引理 G），且步骤 3 中"$M_1$ 只含 $p_1$"只在前一个额外工件之前成立；
- $p_5\ge p_6\ge p_7\ge p_8$。

**(a) $p_5$ 进 $M_1$**（则 $M_1=\{p_1,p_5\}$ 且 $M_1$ 不再"只含 $p_1$"）。此时 $M_2=\{p_2\},M_3=\{p_3,p_4\}$，而 $p_2<p_3+p_4$ 表明 $M_2$ 是唯一负载最小机，故 $p_6$ 只能进 $M_2$（原文："because of $p_2<p_3+p_4$, job $p_6$ must be processed on $M_2$"）。于是：
- $p_6$ 不是失败工件：$M_2$ 新负载 $=p_2+p_6\le p_1+p_6\le c$（O9）；
- $p_7$ 有落点：$M_3=\{p_3,p_4\}$ 未被改动，$p_3+p_4+p_7\le L_0+\frac13<c$（O8 + O5 的 $p_7\le\frac13$）；
- $p_8$（仅 $n=8$）有落点：若 $p_7$ 未进 $M_2$，则 $M_2=\{p_2,p_6\}$ 未被改动，$p_2+p_6+p_8\le p_2+p_5+p_8\le\frac12+\frac23=\frac76<c$（用 $p_6\le p_5$ 与 O5 的 $p_2\le\frac12,\ p_5+p_8\le\frac23$）；若 $p_7$ 进了 $M_2$，则 $M_3$ 仍未被改动，$p_3+p_4+p_8\le p_3+p_4+p_7\le L_0+\frac13<c$（$p_8\le p_7$）。
故各件都有 $\le c$ 的落点，与失败工件存在矛盾。

**(b) $p_5$ 进 $M_2$**（即 $p_1+p_5>cL$，$M_1$ 未收 $p_5$）。此时 $M_2=\{p_2,p_5\}$，$M_1=\{p_1\}$，$M_3=\{p_3,p_4\}$。按 $p_6$ 的去向分三种：

- **(b1) $p_6$ 进 $M_1$**（$p_1+p_6\le cL$，且 $M_1$ 只含 $p_1$）：与 (a) 同型处理 $p_7,p_8$：$p_7$ 进 $M_3$（$p_3+p_4+p_7\le L_0+\frac13<c$），$p_8$ 进 $M_2$（$p_2+p_5+p_8\le\frac76<c$）。$p_6$ 自身进 $M_1$ 时负载 $p_1+p_6\le cL\le c$。
- **(b2) $p_6$ 进 $M_3$**：则 $M_3$ 是"$p_5$ 之后"的负载最小机（$p_3+p_4\le p_1$ 且 $\le p_2+p_5$），故 $\ell(M_3)=p_3+p_4+p_6\le p_1+p_6\le c$（O9）。其中用到 $p_3+p_4\le p_1$（"$M_3$ 负载最小"的直接推论）。又 $p_7\le p_6$，故 $p_1+p_7\le p_1+p_6\le c$，即 $p_7$ 有落点（$M_1$）。最后 $p_8$ 进 $M_2$：$p_2+p_5+p_8\le\frac12+\frac23=\frac76<c$（O5）。
- **(b3) $p_6$ 进 $M_2$**（$M_2$ 是负载最小机，故 $p_2+p_5\le p_1$ 且 $\le p_3+p_4$）：$\ell(M_2)=p_2+p_5+p_6\le p_1+p_6\le c$（O9）；又 $p_1+p_7\le p_1+p_6\le c$。最后 $p_8$ 进 $M_3$：由 $p_3+p_4\le L_0$ 与 $p_8\le\frac13$（O5）得 $p_3+p_4+p_8\le L_0+\frac13\le c$（O8）。

三种子情形都表明 $p_5,\dots,p_8$ 每件都有负载 $\le c$ 的落点，与"存在失败工件"矛盾。

> 与 §5.1 一样，上面每步只给出**一台**候选机器；若它恰被上一步占用，则改用另一台未被改动的机器，并利用 $p_j\le p_{j-1}$（例如 (b2) 中若 $p_7$ 进了 $M_2$，则 $M_1$ 未改，$p_1+p_8\le p_1+p_7\le p_1+p_6\le c$；(b3) 中若 $p_7$ 进了 $M_3$，则 $M_1$ 未改，$p_1+p_8\le p_1+p_7\le c$）。

> 原文在 (b3) 写的判据是 "$p_8\le\frac13$ by (O5)"（而非 $p_7\le\frac13$）：因 $p_8\le p_7\le\frac13$，两者等价，本文按 $p_8$ 陈述以对上原文。

### 5.3 结论

Case 1 与 Case 2 覆盖了 $(p_2\ge p_3+p_4)\vee(p_2<p_3+p_4)$ 的全部可能，且都推出"不存在失败工件"，与极小反例的定义矛盾。结合 §4.1（$n\ne9$）与基例（$n\le5$），反例不存在，故 A3 对 $m=3$ 的竞争比 $\le c$。又 SSW 下界为 $c$，故 **A3 最优**。$\blacksquare$

## 6. 机器验证（LP）

原文中所有"只依赖排序 + 最优装箱可行性"的数值界，都可以转化为一个**线性规划**问题：

$$\max\ \text{（某个线性目标）}\quad\text{s.t.}\quad p_1\ge p_2\ge\dots\ge p_n\ge\alpha,\ \text{存在把 }n\text{ 个工件装进 3 台机器、每台负载}\le1\text{ 且每台}\le3\text{ 件的方案}$$

（"存在装箱"通过枚举所有把 $\{1..n\}$ 分成 3 块、每块 $\le3$ 个的划分，对每个划分写线性约束实现。"每台 $\le3$ 件"来自 O3；$\alpha=\frac32(c-1)$ 是 O3 给出的工件下界。）所有 LP 用 HiGHS 求解到最优，因此结果是**精确**的。

## 8. 与下界的关系、开放问题

- **$m=3$ 完全闭合**：本文上界 $c$ 与 SSW 2000 的下界 $c$ 相等，故 $m=3$ 的竞争比恰为 $c=\frac{1+\sqrt{37}}{6}$。

核心 LP 形式（`bound_lp.py` 的骨架）：

```python
c = (1 + math.sqrt(37)) / 6
LOW = 1.5 * (c - 1)           # (3/2)(c-1)：O3 给出的工件下界

def partitions(n, maxb=3, nblocks=3):
    """把 {0..n-1} 分成 <=nblocks 块、每块 <=maxb 个（= 3 台机器、每台 <=3 件）"""
    ...

def solve(n, obj):
    """max obj·p  s.t. p1>=..>=pn>=LOW，且存在每台负载 <=1 的 3 机装箱"""
    for blocks in partitions(n):
        A, B = [], []
        for blk in blocks:                      # 每台机器负载 <= 1
            row = [0.0]*n
            for i in blk: row[i] = 1.0
            A.append(row); B.append(1.0)
        for i in range(n-1):                    # p_i >= p_{i+1}
            row = [0.0]*n; row[i] = -1.0; row[i+1] = 1.0
            A.append(row); B.append(0.0)
        r = linprog(c=[-x for x in obj], A_ub=A, b_ub=B,
                    bounds=[(LOW, None)]*n, method="highs")
        # 取所有划分中的最优值
```

> 关于「用 $C^*\le1$」的合法性：A3 与 $C^*$ 都是正齐次的，$C_{\mathrm{A3}}/C^*$ 尺度不变；且
> $\sup\{C_{\mathrm{A3}}(p):C^*(p)\le1\}=R:=\sup\{C_{\mathrm{A3}}/C^*\}$（对任一 $C^*(p)\le1$ 的 $p$，取 $p'=p/C^*(p)$ 得 $C^*(p')=1$ 且 $C_{\mathrm{A3}}(p')\ge C_{\mathrm{A3}}(p)$）。故把 $C^*$ 表示成"存在每台负载 $\le1$ 的装箱"不会高估上确界。
> 同理，§6 表中"目标的最大值 $=1$"等价于"该目标 $\le C^*$ 恒成立"。
