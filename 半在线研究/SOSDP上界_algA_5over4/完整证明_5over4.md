# 第 I 部分　第一证明：极小反例 + 分情形（完整 5/4）

# CKK Algorithm A ≤ 5/4：完整证明（重构版）

**定理**（Cheng–Kellerer–Kotov 2012；本文件为自包含重构证明，m ≥ 4）。
m 台相同机器，任务按非增序到达、即时不可反悔分配。Algorithm A：前 m 个任务各占一机；
设 L := p_m + p_{m+1}，K := 5L/4；此后每个任务放入"装入后不超过 K 的最满机器"，无则放最空机器。
则对任意实例，makespan ≤ (5/4)·OPT。

记号：OPT 归一化为 1；t = makespan 机上最后放入的任务；ℓ_min = t 落入前最空机负载；C_A = ℓ_min + t。

## 0. 归约

- L = p_m + p_{m+1} ≤ OPT：前 m+1 个任务进 m 台机器必有一对同机，任一对之和 ≥ p_m + p_{m+1}。（鸽笼）
- 若 t 由 best-fit 放入：负载 ≤ K = 5L/4 ≤ 5OPT/4。∎
- 故下设 t 由 **fallback** 放入：此刻每台机器负载 > K − t，且 C_A = ℓ_min + t。（★）

由（★）：K − t < ℓ_min ≤ (T − t)/m ≤ 1 − t/m < 1 ⟹ t > K − 1。

## 1. Lemma A（Graham 平均界）

C_A = ℓ_min + t ≤ (T − t)/m + t ≤ 1 + t(1 − 1/m)。
故 t ≤ m/(4(m−1)) 时 C_A ≤ 5/4。**硬窗口：t ∈ ( m/(4(m−1)), 2/5 ]。**

## 2. Lemma B（计数界）t ≤ 2/5

反设 t > 2/5。fallback 时每台机器 > K − t ≥ 3t/2（用 L ≥ 2t）> 3/5。
只含 1 个任务的机器：其任务 > 3t/2，且与 t 之和 > 5t/2 > OPT，故 OPT 中它也独占一箱；
其余机器各含 ≥ 2 个 ≥ t 的任务。设单子机 a 台，则 ≥ t 的任务数 ≥ a + 2(m−a) + 1 = 2m − a + 1；
而 OPT 中这些任务的容量 ≤ a + 2(m−a) = 2m − a（大任务独占，其余箱至多 2 个 ≥ 2/5 的任务），矛盾。∎

## 2b. 任务数上界 n ≤ 3m 与分支完备性

硬窗口内 t > 1/4：OPT 每箱至多 3 件（4 件各 ≥ t 则和 > 4t > 1），故 **n ≤ 3m**。
fallback 前最闲机 M₀（**负载最小**）的件数分支——注意负载最小 ≠ 件数最小，三分支均真实存在：
- **1 件**（单子机）：**口袋 2**（§6）。
- **2 件**：**口袋 1**（§3–§5）。
- **≥ 3 件**：**口袋 3**（§6'）。
三分支最终均由 §2c 引理 F/G 的全局推论"fallback 无反例"闭合；口袋 1/2/3 的具体证书（§3–§6'）给出更紧的界。

**★★gen-k（任意 M₀ 通用）**：S ≤ m − ℓ₀ − t。证明同 §4：设 M₀ 有 k 件 {x₁..x_k}，
含 x_i 的箱内其余任务 ≤ 1−x_i，含 t 的箱内其余任务 ≤ 1−t，其余 m−k−1 箱各 ≤ 1；
合计 S = Σ(其余机器负载) ≤ Σ(1−x_i) + (1−t) + (m−k−1) = m − ℓ₀ − t。∎

## 2b'. 先导：z ≤ 1/3（最优解必含 3 件机）

反设 z > 1/3。则所有任务 > 1/3（z 最小），OPT 每机至多 2 件（3 件和 > 1），故 n ≤ 2m。

**配对下界**：C* ≥ B := max_{j=1..m}(p_j + p_{2m−j+1})，其中 p_i := 0（i > n）。
证明：前 j 大 p_1..p_j 与第 2m−j+1 大到第 2m 大共 2j 个任务，进 j 台机器（每机 ≤2 件）
必有一台含其中 2 个，负载 ≥ p_j + p_{2m−j+1}。∎

**n ≤ 2m ⟹ A 平凡 5/4-competitive**：
- 支路一（best-fit 放入）：≤ K = 5L/4 ≤ 5/4·C*。
- 支路二（fallback）：t 前 n−1 个任务中，前 m 任务各一机、后续 n−m−1 ≤ m−1 个，故至少
  2m−n+1 台机器（t 前）无后续（恰 1 件）。取其中 rank 最大的任务 p_j（j ≥ 2m−n+1，
  即 n ≥ 2m−j+1）。该机负载 p_j ≥ ℓ_min，且 t ≤ p_{2m−j+1}。故
  C_A = ℓ_min + t ≤ p_j + p_{2m−j+1} ≤ B ≤ C* ≤ 5/4·C*。
综上 A ≤ 5/4·C*，与反例（>5/4）矛盾。∎

故 z ≤ 1/3。

## 2c. fallback 的两种情形：浅/深（全局闭合工具）

fallback 时按 p₁ + p_{m+1} 与 5/4L 的关系二分。记最优解中恰含 1、2、3 件的机器数为
m₁*, m₂*, m₃*（最优解每机 ≤ 3 件，§2b）。两条最优解计数式：

- **式(1)** n_{1/2} ≤ m₁* + m₂*：>1/2 的 job 两两不能共箱（和 >1），各独占一机、至多配一个
  ≤1/2 的 job，故含 >1/2 job 的机器是 1 件机或 2 件机。∎
- **式(2)** n_{3/8} ≤ m₁* + 2m₂* + m₃* = m + m₂*：3 件机的次件 < 3/8（否则前两个 ≥3/8、
  第三 >1/4，和 >1），故 3 件机至多 1 个 >3/8 的 job，2 件机至多 2 个，1 件机至多 1 个。∎

**引理 F（浅情形 p₁+p_{m+1} ≤ 5/4L ⟹ 无危险）**：
- **n ≥ 2m+1**：浅情形对每个 j ≤ m 有 p_j + t ≤ p_j + p_{m+1} ≤ p₁ + p_{m+1} ≤ K，即每台机器
  初始负载 p_j ≤ K − t；fallback 要求所有机器负载 > K − t，故每台机器（t 前）至少加了 1 个
  后续，后续数 n − m − 1 ≥ m，n ≥ 2m+1。
- 设 M₁ = 前 m₁*+m₂* 台机，M₂ = 其余。归纳证前 m₁*+m₂* 个后续都放进 M₁：放第 i 个后续
  q_i（i ≤ m₁*+m₂*）时，前 i−1 个后续已放 M₁，故 M₂ 尚无后续、负载仍是初始 p_{j'} ≤ p_{m₁*+m₂*+1}；
  而 M₁ 的每台（已加后续者更满，未加者 p_j ≥ p_{m₁*+m₂*+1}）负载都 ≥ M₂ 的负载，且未加的 M₁ 台
  能放下 q_i（p_j + q_i ≤ p₁ + p_{m+1} ≤ K，浅情形）。故 best-fit 把 q_i 放进 M₁。故除 z 外至少
  2(m₁*+m₂*) 个工件落 M₁。
- 由式(1) M₂ 上工件 ≤ 1/2，由式(2) M₂ 上次工件 ≤ 3/8。最优解每机 ≤ 3 件 ⟹
  n ≤ m + m₂* + 2m₃* < 2(m₁*+m₂*) + 3m₃* + 1，故 M₂ 中某台在 z 到来前至多 2 件，z 可作
  第三件放入，负载 ≤ 1/2 + 3/8 + 1/3 = 29/24 < 5/4，与 z 是失败工件矛盾。∎

**引理 G（深情形 p₁+p_{m+1} > 5/4L ⟹ 无危险）**：
- **G1 最优解无单件机（m₁\* = 0）**：反设最优解有单件机 {x}。交换 x 与 p₁（p₁ 是最大任务，
  x ≤ p₁），p₁ 独占原 x 机、x 移入 p₁ 原机，最优 makespan 不增大。删去 p₁ 独占机及 A 解中
  p₁ 机上的其他工件（除 z），得 m−1 台机的新实例：因 p₁+p_{m+1} > K，p_{m+1} 未放 p₁ 机，
  故 p_m, p_{m+1} 保留、L 不变；其余指派不变，z 至多移到更差位置。极小反例矛盾。∎
- **G2 无 >3/4 的 job（x₁ = 0）**：X₁ job（>3/4）配任何 job（>1/4，因 z>1/4）和 >1，
  必独占最优解机，与 m₁* = 0 矛盾。∎
- **G-2a（L ≥ 4/5，即 5/4L ≥ 1）**：p₁+p_{m+1} > 5/4L ≥ 1 ⟹ p₁ > 1/2。由 G1 p₁ 在最优解
  是 2 件机 {p₁, p_ℓ}，p₁+p_ℓ ≤ 1，ℓ 取最大（p₁+p_{m+1} > 1 ⟹ ℓ > m+1）。
  - 若 A 的 p₁ 机单件（无后续）：ℓ_min ≤ p₁ 且 t ≤ p_ℓ（t 最小、p_ℓ rank > m+1），故
    C_A = ℓ_min + t ≤ p₁ + p_ℓ ≤ OPT ≤ 5/4·OPT，无危险。
  - 若 A 的 p₁ 机有后续：设首个进 p₁ 机的后续为 p_ℓ'。先证 **ℓ' ≤ ℓ**：反设 ℓ' > ℓ，则 p_ℓ
    （rank ℓ < ℓ'）在 p_ℓ' 前处理、此时 p₁ 机单件；p_ℓ 能放 p₁ 机（p₁+p_ℓ ≤ 1 ≤ K），故 p_ℓ
    未进 p₁ 机必因存在更满的机器 M'（M' > p₁，M'+p_ℓ ≤ K）；由 p_ℓ' < p_ℓ 得 M' + p_ℓ' < K，
    故 p_ℓ' 处理时 M'（仍 > p₁）能放下 p_ℓ' 且比 p₁ 机满，best-fit 必选 M'，与 p_ℓ' 是首个进
    p₁ 机者矛盾。故 ℓ' ≤ ℓ。删去 A 的 p₁ 机（p₁, p_ℓ' 及可能第三件）与一机，得 m−1 台新实例：
    p_ℓ' > m ⟹ p_m, p_{m+1} 保留、L 不变；其余指派不变，z 至多移到更差位置（A 不改善）。最优解
    删去 {p₁, p_ℓ} 机，并把保留的 p_ℓ 放到 p_ℓ' 原位置（ℓ' ≤ ℓ ⟹ p_ℓ' ≥ p_ℓ ⟹ makespan 不增），得
    m−1 台可行解。故新实例 OPT 不增而 A 不改善（仍 >5/4），与极小反例矛盾。∎
- **G-2b（L < 4/5，即 5/4L < 1）**：
  - **G3 A 无单件机（m₁ = 0）**：A 的单件机负载 ≤ 3/4（x₁ = 0），其负载 + z ≤ 3/4 + 1/3
    < 5/4，z 可放入、非 failure。∎
  - **G4 2 件机首件 >1/2（m₂ ≤ x₂）**：A 的 2 件机 y₁ ≥ y₂，若 y₁ ≤ 1/2，则
    y₁+y₂+z ≤ 1/2 + L/2 + 1/3 ≤ 5/4（y₂ ≤ p_{m+1} ≤ L/2，L < 4/5，z ≤ 1/3），z 可放入、
    非 failure。故 y₁ > 1/2，m₂ ≤ x₂。∎
  - **G5 计数矛盾**：A 中（m₁ = 0）z 前件数 ≥ 2m₂ + 3m₃，故
    n ≥ 2m₂ + 3m₃ + 1 = 3m − m₂ + 1 ≥ 3m − x₂ + 1；最优解侧（X₁ = X₄ = ∅，X₂ 各独占一机、
    至多再配一个）n ≤ 2x₂ + 3(m−x₂) = 3m − x₂。矛盾。∎

**推论（fallback 无反例）**：fallback 情形必落入引理 F 或引理 G，二者均无危险，故
fallback 不可能产生比值 > 5/4 的反例。∎

## 3. 口袋 1 的 n = 3m（M₀ 恰 2 件）

n = 3m 且 t > 1/4 ⟹ OPT 每箱恰 3 件 ⟹ 每件 ≤ 1 − 2t（箱内两小件各 ≥ t）。
M₀ 恰 2 件 x ≤ y ⟹ ℓ_min = x + y ≤ 2(1−2t) ⟹ C_A ≤ 2 − 3t < 5/4（t > 1/4）。∎
（n = 3m 时 M₀ 恰 1 件 / ≥3 件的情形由 §6 / §6' 引用 §2c 覆盖。）

## 4. 通用工具 ★★：S ≤ m − ℓ₀ − t

设 M₀ = {x, y}（x ≤ y，ℓ₀ = x + y），S = 其余 m−1 台机器的负载之和（= 除 {x, y, t} 外全部任务之和）。
在 OPT 中考察含 x、含 t、含 y 的三个箱（重合情形只会更紧，见下）：
- 含 x 的箱内其余任务之和 ≤ 1 − x；
- 含 t 的箱内其余任务之和 ≤ 1 − t；
- 含 y 的箱内其余任务之和 ≤ 1 − y；
- 其余 m − 3 个箱各 ≤ 1。

合计 S ≤ (1−x) + (1−t) + (1−y) + (m−3) = **m − ℓ₀ − t**。∎
（重合校验：x,t 同箱 ⟹ 该箱第三件 ≤ 1−x−t，合计 (1−x−t)+(1−y)+(m−2) = m−ℓ₀−t；x,y 同箱 ⟹ (1−ℓ₀)+(1−t)+(m−2) = m−ℓ₀−t；x,y,t 同箱不可能，因 x+y+t ≥ t + (1−2t) + t = 1，且 y > 1−2t 严格 ⟹ x+y+t > 1，而 y ≤ 1−2t 时 §5 前提已闭。）

## 5. 口袋 1（M₀ 恰 2 件）：n = 3m−1 全部 + n ≤ 3m−2 子情形 A

**前提**：y > 1−2t（否则 ℓ₀ ≤ 2(1−2t)，C_A ≤ 2−3t < 5/4，已闭）。
（其余机器若有单子机，该情形由 §2c 引理 F/G 的全局推论"fallback 无反例"直接覆盖；故下设
其余机器无单子机。）件数和 n − 3 ∈ [2m−2, 3m−4]，均值 < 3，
故由鸽巢**存在恰 2 件台 M\***（两件 u ≤ v）。

**子情形 A：v ≤ 1−2t（M\* 不含大任务）。**
- ℓ_\* = u + v ≤ 2(1 − 2t)。（F3：非大任务均 ≤ 1−2t）
- 权重分配：M\* 得 (m+2)/3，其余 m−2 台各得 1。总权 W = (m+2)/3 + (m−2) = 4(m−1)/3。
- W·ℓ₀ ≤ ((m+2)/3)·ℓ_\* + Σ_{其余} ℓ_i = ((m+2)/3)·ℓ_\* + (S − ℓ_\*) = ((m−1)/3)·ℓ_\* + S
  ≤ ((m−1)/3)·2(1−2t) + (m − ℓ₀ − t)。　（★★ 用于 S）
- 整理（两边乘 3/(4m−1)）：

$$\ell_0 \le \frac{5m-2}{4m-1} - t \quad\Longrightarrow\quad C_A = \ell_0 + t \le \frac{5m-2}{4m-1} < \frac54,$$

因为 5/4 − (5m−2)/(4m−1) = 3/(4(4m−1)) > 0。∎

**覆盖范围**：
- n = 3m−1：非-3 箱恰 1 个（箱型 (0,1,m−1)，sympy 验），大任务至多 1 个即 y，故 M\* 自动满足 v ≤ 1−2t——子情形 A 恒成立，**n = 3m−1 全部闭合**。
- n ≤ 3m−2：非-3 箱 ≥ 2，可能有第二个大任务 w。若存在不含大任务的 2 件台，子情形 A 适用。剩余情形（**每台 2 件台都含大任务**）为**子情形 B**：由 §2c 引理 F/G（fallback 浅/深情形均无危险）直接闭合。∎

## 6. 口袋 2（单子机）：闭合（引理 T''，2026-09-20）

口袋 2：最闲机为单子机 M₀ = {p_i}（p_i 是该机的初始任务，rank i），fallback 时 t 落入，
C_A = p_i + t。角落 = 危险 C_A > 5/4。

**引理 T''（口袋 2 角落闭合）**：口袋 2 角落不可能发生。

**关键（危险 ⟹ m₁* ≥ 1）**：危险 p_i + t > 5/4，t ≤ 2/5（Lemma B）⟹ p_i > 5/4 − t ≥ 5/4 − 2/5
= 17/20 > 3/4，即 p_i ∈ X₁。又所有 job > 1/4（z > 1/4 ⟹ x₄ = 0），故 p_i > 3/4 配任何 job（>1/4）和 > 1，
最优解中 p_i 独占一箱 ⟹ m₁* ≥ 1。

- 若 p₁ + p_{m+1} ≤ 5/4L：§2c 引理 F ⟹ 无危险，口袋 2 角落不存在。

## 6'. 口袋 3（最闲机 ≥ 3 件）：闭合——**两支独立证明并列**

M₀ 件数 k ≥ 3。m = 4 由 ★★gen-k 闭合（ℓ₀ ≤ 1 − t/m ⟹ C_A ≤ 1 + 3t/4 ≤ 5/4）。m ≥ 5 有**两支互相
独立的闭合**，各有自己的完整论证，可任取其一，也可并用作互证（本文两支并列）：

**第一支（引理 F/G，§2c）**：m ≥ 5 且存在非大 2 件台时复用 §5 证书（证书不依赖 M₀ 件数）；
残留情形（所有 2 件台含大任务 / 无 2 件台）由 §2c 引理 F/G（fallback 浅/深情形均无危险）直接闭合。

**第二支（引理 P3C：纯计数闭合，全文见 `pocket3_counting.md`）**：m ≥ 5 且**他机全 2 件**时，
**不依赖 danger、不依赖 $y,z\ge1-2t$、不依赖 firststep**，纯计数即得矛盾。设 M₀ = {x,y,z}
（x ≤ y ≤ z；z 为初始件故 z ≥ q₁，x, y ≥ t 为后至件），他机 m−1 台各 {s_i, j_i}，s_i + j_i ≥ ℓ₀：

1. **s_i ≥ 2t**：s_i ≥ ℓ₀ − j_i ≥ ℓ₀ − q₁ ≥ x+y+z − q₁ ≥ t+t+q₁−q₁ = 2t；
2. **senior 两两不共箱**：s_i + s_k ≥ 4t > 1（t > 1/4）⟹ m−1 个 senior 各占一个 OPT 箱；
3. **每 senior 箱至多带 1 件非 senior**：非 senior 全部 ≥ t，s_i + 两件 ≥ 4t > 1；
4. **OPT 每箱至多 3 件**：4 件各 ≥ t 则和 ≥ 4t > 1；

# 第 0 章 问题、模型与案例空间

## 0.1 SOSDP 与 Algorithm A

**SOSDP（decreasing processing times 半在线调度）**：$m$ 台同型并行机，工件按加工时间非增序到达 $p_1\ge p_2\ge\cdots\ge p_n$，每个工件到达时须立即不可撤销地指派到一台机器，目标最小化 makespan。竞争比 $=$ 算法解 / 离线最优解 $C^*$ 的最坏比值。

**Algorithm A（CKK 2012）**：
1. 前 $m$ 件 $p_1,\dots,p_m$ 一机一件；
2. 记 $L := p_m+p_{m+1}$；
3. 对后续工件 $p_j$（$j\ge m+1$）：若存在机器 $M$ 使 $\ell(M)+p_j\le \frac54 L$，放入**负载最大**的这样一台（best-fit）；否则放入**负载最小**的机器（fallback）。

**已知结果**：LPT 界 $\frac43-\frac1{3m}$；CKK 证 Algorithm A 竞争比 $\le \frac54$（$m\ge3$），且 $m=3$ 时有最优算法 $\frac{1+\sqrt{37}}6\approx1.18046$；下界同为 $\frac{1+\sqrt{37}}6$（SSW 2000）。本文的 (P)（razor 角落 ⟹ rest 不可装箱）覆盖 5/4 证明的最硬部分（razor 带），下文给出其独立第二证明。

## 0.2 极小反例框架（沿用 CKK 约定）

不妨设 $C^*=1$。设存在反例，取**极小**反例；其**失败工件** $z$ 是首个使某机器负载 $>\frac54$ 的工件。由极小性，$z=p_n$ 是最后一个工件，且被放入**负载最小**的机器。记 $t$ 为 $z$ 的尺寸。

- **事实 1（CKK）**：$z>\frac14$，且不存在 $\le\frac14$ 的工件（记 $x_4=0$）。故所有工件 $>\frac14$。
- **事实 2（CKK）**：最优解中每台机器至多 3 个工件。
- 值类：$X_1=\{p>\frac34\}$、$X_2=\{(\frac12,\frac34]\}$、$X_3=\{(\frac14,\frac12]\}$、$X_4=\varnothing$。

**口袋2 角落（本文战场）**：$z$ 落到**最小负载机** $M_0$（负载记为 $p$，$M_0$ 恰含 2 件，$p\le1$），其余 $nS=m-1$ 台机器各恰含 2 件——一个 **senior** $s_i$ 与一个 **junior** $j_i$。则必有
$$\textbf{danger：}\quad p+t>\frac54 \tag{0.1}$$
（否则 $z$ 可被 best-fit 正常放入 $\le\frac54 L$，不构成失败）。rest $=$ seniors $\{s_i\}$ $+$ juniors $\{j_i\}$ $+$ $\{z\}$（尺寸 $t$），共 $2m-1$ 件。

**(P)（命题）**：razor 角落 ⟹ rest 不可装箱（即 razor 角落 + rest 可装箱 ⟹ 矛盾）。由 rest 不可装箱 ⟹ OPT>1，与极小反例框架的 OPT=1（归一化）矛盾 ⟹ 口袋2 razor 角落不存在。

## 0.3 序事实与值域（全部在主证明框架内已证，本文引用）

1. **递减到达**：$a_m := p_m \ge q_1 := p_{m+1}$（$a_m$ 为最小 senior，$q_1$ 为最大 junior 类件）；$q_1\le a_m$。
2. **序分离**：seniors $\ge$ juniors（ seniors 是到达序前段）；且 $L=a_m+q_1\le1$ 给出 **$q_1\le\frac12$**。
3. **senior 非小引理**：$s_i>1-2t$（否则该 senior 与 $z$ 的和 $<1$，$z$ 可被放入）。
4. **窄带**：$t\le j_i\le 2t$（下界：junior 类件 $\ge t$；上界：junior 的定义域）。
5. **负载约束**：best-fit 放置 ⟹ 每台非 $M_0$ 机负载 $\ell_i=s_i+j_{(i)}\le K:=\frac54L$；且 $K=\frac54(a_m+q_1)$。
6. **$p\le1$**（$M_0$ 负载 $\le C^*=1$）。

## 0.4 rest 装箱的箱型计数与 razor cnt 族

rest 每件 $>\frac14$ ⟹ 每箱至多 3 件。箱型：
- $a$ = #SS 箱（2 senior）；
- $b$ = #SJ 箱（1 senior + 1 junior 类件）；
- $c$ = #S 箱（单 senior）；
- $d$ = #JJJ 箱（3 junior 类件）；
- $e$ = #JJ 箱（2 junior 类件）；
- $f$ = #J 箱（单 junior 类件）。

守恒方程：
$$2a+b+c=nS\ (\text{senior 数}),\quad b+3d+2e+f=m\ (\text{junior 类数}=\text{juniors}+t),\quad a+b+c+d+e+f=nS\ (\text{箱数}). \tag{0.2}$$
第一式减第三式：$a-d-e-f=0$；第二式减第三式：$d+e-a-c=1$。联立得**计数恒等式**：
$$\boxed{a=d+e+f},\qquad \boxed{d=1+c+f}. \tag{0.3}$$

**推论 0.4.1**：任意可装箱的 rest 必有 $a\ge1$（存在 SS 箱）且 $d\ge1$（存在 JJJ 箱）。

**razor 带（本文证明的覆盖域）**：项目案例空间扫描后，除已由其他路线闭合的区域外，剩余区域为
$$\text{cnt}\in\{(1,m-3,0,1,0,0),\ (2,m-5,0,1,1,0)\},\qquad k=1..m-1,\qquad m\ge4,\qquad t\in(t_{\rm lo},\tfrac13], \tag{0.4}$$
即 $(c,f,d)=(0,0,1)$、$(a,e)\in\{(1,0),(2,1)\}$、$b=m-3-2e$（与 (0.3) 一致：$a=d+e+f=1+e$，$d=1+c+f=1$）。$t_{\rm lo}=\frac{m-1}{4(m-2)}$（由 $nS$ 台机器负载 $>p>\frac54-t$ 与 OPT 体积联立推出的窗口下界）。razor 带外区域的闭合出处见附录 C。

**关于 $k$（情形参数）**（机器下标均 0-indexed：机器 $0..nS-1$）：$k=jj+1$，$jj$ 为 $q_1$（第一个到达的 junior 类件）经 best-fit 落入的机器下标；它由值唯一确定：机器 $0..jj$（低端区）负载前段 $\le K-q_1$，机器 $jj+1..nS-1$（hi 区）senior $>K-q_1$（$q_1$ 放不下的机器）。

# 第 1 章 基础引理（全部内证）

## 1.1 挤压引理

**引理 1.1（挤压引理）** rest 可装箱 ⟹ $\sum_{i=1}^{nS}\ell_i=\sum_i(s_i+j_{(i)})\ \le\ nS-t$。
**证明**：机器负载 $\ell_i$ 穷尽全部 seniors 与 juniors，故 $\sum\ell_i=\sum s+\sum j$。rest 装入 $nS$ 个容量 1 的箱 ⟹ $\sum s+\sum j+t\le nS$。两式相减即得。∎

**推论 1.1.1（挤压预算）** 记 $B=(nS-t)-nS\cdot p$。由 $\ell_i>p+MG$（pair，见 §0.5 框架甲）得 $\sum(\ell_i-p)<B$；又 danger $p>\frac54-t$ ⟹ $B<nS(t-\frac14)-t$。即全体机器负载超出 $p$ 的总预算是 razor 小量（$\approx\frac{nS}{12}$ 于 $t=\frac13$）。

## 1.2 SS 对与 JJJ 三元组的存在性

**引理 1.2（SS01，(B) 类合法）** rest 可装箱 ⟹ **最小两 senior 和 $\le1$**（值语言：$s_1+s_2\le1$；机器索引：$s_0+s_1\le1$）。
**证明**：由 (0.3)，$a=d+e+f\ge1$ ⟹ 存在一 SS 箱（两 senior 和 $\le1$）⟹ 最小两件和 $\le1$。∎

**引理 1.3（JJJ01，(B) 类合法）** rest 可装箱 ⟹ **$t$ 加最小两件 junior 和 $\le1$**（$t+j_1+j_2\le1$，值语言全序下 $j_1,j_2$ 为全体最小两件 junior）。
**证明**：由 (0.3)，$d=1+c+f\ge1$ ⟹ 存在一 JJJ 箱（3 个 junior 类件和 $\le1$）⟹ 最小的三个 junior 类件（$t$ 为全体最小件 + 两件最小 junior）和 $\le1$。∎

## 1.3 值带 B3

**引理 1.4（值带 B3，(B) 类合法）** razor 带 rest 可装箱 ⟹ **最大 senior $\le 1-t$**。
**证明**：razor cnt 族 $c=0$（无单 senior 箱）。若 $s>1-t$：与任一 junior 类件（$\ge t$）同箱和 $>1$；与任一 senior（$\ge1-2t$）同箱和 $>2-3t>1$（$t<\frac13$）。无处可放，与 $c=0$ 矛盾。∎

## 1.4 mon2（低端区 junior 随 senior 不减）

**引理 1.5（mon2，(A) 类合法）** 口袋2 角落产生运行中，$[0,jj]$ 区间机器的 junior 随 senior 单调不减：
$$j_0\le j_1\le\cdots\le j_{jj}=q_1.$$
**证明**：
1. **$[0,jj]$ 机对任意 junior 恒放得下**：对 $i\le jj$ 与任意后至件 $q$，$q\le q_1$ 且 $s_i\le s_{jj}$ ⟹ $s_i+q\le s_{jj}+q_1\le K$。
2. **已填机永不二次接收**：角落形状要求每台他机恰 1 个 junior；若某机收第 2 个则必有他机 0 个，破形状。
3. **归纳**：$q_1$ 落 $jj$；设 $q_1,\dots,q_{r-1}$ 已放且 $[0,jj]$ 被填机满足"senior 大者先填、junior 递减"。$q_r$ 到达时 best-fit 取"放得下的最满机"：$>jj$ 的单机若放得下必被选中（senior 更大），否则落到 $[0,jj]$ 当前最满单机＝剩余最大 senior 机；递减到达保持归纳。
4. **并列**：$s_i=s_{i+1}$ 时机器可互换重标号，同级内按 junior 递增排，w.l.o.g.。∎

## 1.5 低端区配对支配（A5）与 Qcount

**引理 1.6（A5，(A) 类合法）** 设低端区为机器 $1..k$（senior 值序 $s_1\le\cdots\le s_k$），则对 $i=1..k$：
$$j_{nS-k+i}\ \ge\ p-s_i+MG, \tag{1.1}$$
即全体 junior 值序中第 $nS-k+i$ 小者（$k$ 件最大者中第 $i$ 小）不低于机 $i$ 的 pair 下界。

**证明**：
- **mon2（引理 1.5）**：低端机 $i$ 的 junior $\le$ 低端机 $i+1$ 的 junior。
- **fs**：机 $k$（$=jj$）的 junior 为 $q_1=\max J$（firststep：$q_1$ 放入当时负载最大且放得下的机器 $jj$）。
- 由 mon2，低端机 $i$ 的 junior $chosen_i$ 为低端区 $k$ 件 junior 中第 $i$ 小者；由 fs，第 $k$ 件恰为全局最大。
- $k$ 件最大 junior 按分量支配任意 $k$ 件 junior（纯排序事实）⟹ $j_{nS-k+i}\ge chosen_i$。
- pair：$chosen_i\ge p-s_i+MG$（机 $i$ 负载 $>p$）。
∎

**注（与 hi 区的关系）**：hi 区 junior 若偏小，只会使 $k$ 件最大者更集中于低端区，结论方向恒加强——这是 A5 与"hi 区 junior 序无关"的原因（其合法性不依赖 hi 区任何序结构，附录 B.3 三层证据）。

**引理 1.6′（Qcount = A5 的 $i=1$ 特例，(A) 类，4 行简洁证明）** 取 A5 的 $i=1$（$s_1=s_0=a_m$ 为最小 senior）：
$$j_{\,nS-k+1}\ \ge\ p-s_0+MG . \tag{1.1'}$$
等价于"至少 $k$ 个 junior $\ge p-s_0+MG$"。其简洁证明（不经过支配论证）：
1. 机 0（最小 senior $s_0$）pair ⟹ $x_0\ge p-s_0+MG$；
2. mon2 升链 $x_0\le x_1\le\cdots\le x_{jj}=q_1$；
3. 低端区 $k$ 台 junior 全 $\ge p-s_0+MG$；
4. 值序翻译 ⟹ 第 $nS-k+1$ 小 junior $\ge p-s_0+MG$。∎

## 1.6 情形定义行（LZ/HZ）

**引理 1.7（LZ/HZ，(A) 类合法）** $k=jj+1$ 由值唯一确定：
$$s_k\le K-q_1\ (\text{LZ：机 } k-1=jj \text{ 是放 } q_1 \text{ 的最满载机}),\qquad s_{k+1}>K-q_1\ (\text{HZ：hi 区首机}). \tag{1.2}$$
**证明**：$q_1$ 到达时，各机负载 $=$ senior（junior 尚未到达）。best-fit 把 $q_1$ 放入负载最大且 $\ell+q_1\le K$ 的机器，即 $jj=\max\{i:s_i\le K-q_1\}$。$q_1$ 放不下的机器即 $s_i>K-q_1$（nofit）。∎

## 1.7 B 链四引理（匹配/消耗的支配与规范化）

> 供引理 1.9（min-triple w.l.o.g.）引用；均为阈值图匹配/消耗的标准支配结果。

**引理 1.8a（SJ-REV，阈值匹配 ⟺ 反序配对可行）**：阈值图（seniors×juniors，边 ⟺ $s+j\le1$）存在完美匹配 ⟺ **反序配对**逐位成立 ⟺ $\forall i: s_{[i]}+j^{[i]}\le1$（第 $i$ 大 senior + 第 $i$ 小 junior）。
**证明**：链图（seniors 升序 ⟹ 邻域 $N(s_i)\supseteq N(s_{i+1})$）的 Hall 条件 $|N(s_i)|\ge b-i+1$ ⟺ $s_i$ 兼容第 $b-i+1$ 小 junior ⟺ 反序逐位成立；两方向等价（反序失配 ⟺ 阈值 Hall 缺陷）。∎
