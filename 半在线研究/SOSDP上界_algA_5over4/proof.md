# CKK Algorithm A ≤ 5/4：完整证明（重构版）

**定理**（Cheng–Kellerer–Kotov 2012；本文件为自包含重构证明，m ≥ 4）。
m 台相同机器，任务按非增序到达、即时不可反悔分配。Algorithm A：前 m 个任务各占一机；
设 L := p_m + p_{m+1}，K := 5L/4；此后每个任务放入"装入后不超过 K 的最满机器"，无则放最空机器。
则对任意实例，makespan ≤ (5/4)·OPT。

记号：OPT 归一化为 1；t = makespan 机上最后放入的任务；ℓ_min = t 落入前最空机负载；C_A = ℓ_min + t。

## 0. 归约

- L = p_m + p_{m+1} ≤ OPT：前 m+1 个任务进 m 台机器必有一对同机，任一对之和 ≥ p_m + p_{m+1}。（鸽笼）
- 若 t 由 best-fit 放入：负载 ≤ K = 5L/4 ≤ 5OPT/4。∎
- 故下设 t 由 **fallback** 放入：此刻每台机器负载 > K − t，且 C_A = ℓ_min + t。（★）

由（★）：K − t < ℓ_min ≤ (T − t)/m ≤ 1 − t/m < 1 ⟹ t > K − 1。

## 1. Lemma A（Graham 平均界）

C_A = ℓ_min + t ≤ (T − t)/m + t ≤ 1 + t(1 − 1/m)。
故 t ≤ m/(4(m−1)) 时 C_A ≤ 5/4。**硬窗口：t ∈ ( m/(4(m−1)), 2/5 ]。**

## 2. Lemma B（计数界）t ≤ 2/5

反设 t > 2/5。fallback 时每台机器 > K − t ≥ 3t/2（用 L ≥ 2t）> 3/5。
只含 1 个任务的机器：其任务 > 3t/2，且与 t 之和 > 5t/2 > OPT，故 OPT 中它也独占一箱；
其余机器各含 ≥ 2 个 ≥ t 的任务。设单子机 a 台，则 ≥ t 的任务数 ≥ a + 2(m−a) + 1 = 2m − a + 1；
而 OPT 中这些任务的容量 ≤ a + 2(m−a) = 2m − a（大任务独占，其余箱至多 2 个 ≥ 2/5 的任务），矛盾。∎

## 2b. 任务数上界 n ≤ 3m 与分支完备性

硬窗口内 t > 1/4：OPT 每箱至多 3 件（4 件各 ≥ t 则和 > 4t > 1），故 **n ≤ 3m**。
fallback 前最闲机 M₀（**负载最小**）的件数分支——注意负载最小 ≠ 件数最小，三分支均真实存在：
- **1 件**（单子机）：**口袋 2**（§6）。
- **2 件**：**口袋 1**（§3–§5）。
- **≥ 3 件**：**口袋 3**（§6'）。
三分支最终均由 §2c 引理 F/G 的全局推论"fallback 无反例"闭合；口袋 1/2/3 的具体证书（§3–§6'）给出更紧的界。

**★★gen-k（任意 M₀ 通用）**：S ≤ m − ℓ₀ − t。证明同 §4：设 M₀ 有 k 件 {x₁..x_k}，
含 x_i 的箱内其余任务 ≤ 1−x_i，含 t 的箱内其余任务 ≤ 1−t，其余 m−k−1 箱各 ≤ 1；
合计 S = Σ(其余机器负载) ≤ Σ(1−x_i) + (1−t) + (m−k−1) = m − ℓ₀ − t。∎

## 2b'. 先导：z ≤ 1/3（最优解必含 3 件机）

反设 z > 1/3。则所有任务 > 1/3（z 最小），OPT 每机至多 2 件（3 件和 > 1），故 n ≤ 2m。

**配对下界**：C* ≥ B := max_{j=1..m}(p_j + p_{2m−j+1})，其中 p_i := 0（i > n）。
证明：前 j 大 p_1..p_j 与第 2m−j+1 大到第 2m 大共 2j 个任务，进 j 台机器（每机 ≤2 件）
必有一台含其中 2 个，负载 ≥ p_j + p_{2m−j+1}。∎

**n ≤ 2m ⟹ A 平凡 5/4-competitive**：
- 支路一（best-fit 放入）：≤ K = 5L/4 ≤ 5/4·C*。
- 支路二（fallback）：t 前 n−1 个任务中，前 m 任务各一机、后续 n−m−1 ≤ m−1 个，故至少
  2m−n+1 台机器（t 前）无后续（恰 1 件）。取其中 rank 最大的任务 p_j（j ≥ 2m−n+1，
  即 n ≥ 2m−j+1）。该机负载 p_j ≥ ℓ_min，且 t ≤ p_{2m−j+1}。故
  C_A = ℓ_min + t ≤ p_j + p_{2m−j+1} ≤ B ≤ C* ≤ 5/4·C*。
综上 A ≤ 5/4·C*，与反例（>5/4）矛盾。∎

故 z ≤ 1/3。

## 2c. fallback 的两种情形：浅/深（全局闭合工具）

fallback 时按 p₁ + p_{m+1} 与 5/4L 的关系二分。记最优解中恰含 1、2、3 件的机器数为
m₁*, m₂*, m₃*（最优解每机 ≤ 3 件，§2b）。两条最优解计数式：

- **式(1)** n_{1/2} ≤ m₁* + m₂*：>1/2 的 job 两两不能共箱（和 >1），各独占一机、至多配一个
  ≤1/2 的 job，故含 >1/2 job 的机器是 1 件机或 2 件机。∎
- **式(2)** n_{3/8} ≤ m₁* + 2m₂* + m₃* = m + m₂*：3 件机的次件 < 3/8（否则前两个 ≥3/8、
  第三 >1/4，和 >1），故 3 件机至多 1 个 >3/8 的 job，2 件机至多 2 个，1 件机至多 1 个。∎

**引理 F（浅情形 p₁+p_{m+1} ≤ 5/4L ⟹ 无危险）**：
- **n ≥ 2m+1**：浅情形对每个 j ≤ m 有 p_j + t ≤ p_j + p_{m+1} ≤ p₁ + p_{m+1} ≤ K，即每台机器
  初始负载 p_j ≤ K − t；fallback 要求所有机器负载 > K − t，故每台机器（t 前）至少加了 1 个
  后续，后续数 n − m − 1 ≥ m，n ≥ 2m+1。
- 设 M₁ = 前 m₁*+m₂* 台机，M₂ = 其余。归纳证前 m₁*+m₂* 个后续都放进 M₁：放第 i 个后续
  q_i（i ≤ m₁*+m₂*）时，前 i−1 个后续已放 M₁，故 M₂ 尚无后续、负载仍是初始 p_{j'} ≤ p_{m₁*+m₂*+1}；
  而 M₁ 的每台（已加后续者更满，未加者 p_j ≥ p_{m₁*+m₂*+1}）负载都 ≥ M₂ 的负载，且未加的 M₁ 台
  能放下 q_i（p_j + q_i ≤ p₁ + p_{m+1} ≤ K，浅情形）。故 best-fit 把 q_i 放进 M₁。故除 z 外至少
  2(m₁*+m₂*) 个工件落 M₁。
- 由式(1) M₂ 上工件 ≤ 1/2，由式(2) M₂ 上次工件 ≤ 3/8。最优解每机 ≤ 3 件 ⟹
  n ≤ m + m₂* + 2m₃* < 2(m₁*+m₂*) + 3m₃* + 1，故 M₂ 中某台在 z 到来前至多 2 件，z 可作
  第三件放入，负载 ≤ 1/2 + 3/8 + 1/3 = 29/24 < 5/4，与 z 是失败工件矛盾。∎

**引理 G（深情形 p₁+p_{m+1} > 5/4L ⟹ 无危险）**：
- **G1 最优解无单件机（m₁\* = 0）**：反设最优解有单件机 {x}。交换 x 与 p₁（p₁ 是最大任务，
  x ≤ p₁），p₁ 独占原 x 机、x 移入 p₁ 原机，最优 makespan 不增大。删去 p₁ 独占机及 A 解中
  p₁ 机上的其他工件（除 z），得 m−1 台机的新实例：因 p₁+p_{m+1} > K，p_{m+1} 未放 p₁ 机，
  故 p_m, p_{m+1} 保留、L 不变；其余指派不变，z 至多移到更差位置。极小反例矛盾。∎
- **G2 无 >3/4 的 job（x₁ = 0）**：X₁ job（>3/4）配任何 job（>1/4，因 z>1/4）和 >1，
  必独占最优解机，与 m₁* = 0 矛盾。∎
- **G-2a（L ≥ 4/5，即 5/4L ≥ 1）**：p₁+p_{m+1} > 5/4L ≥ 1 ⟹ p₁ > 1/2。由 G1 p₁ 在最优解
  是 2 件机 {p₁, p_ℓ}，p₁+p_ℓ ≤ 1，ℓ 取最大（p₁+p_{m+1} > 1 ⟹ ℓ > m+1）。
  - 若 A 的 p₁ 机单件（无后续）：ℓ_min ≤ p₁ 且 t ≤ p_ℓ（t 最小、p_ℓ rank > m+1），故
    C_A = ℓ_min + t ≤ p₁ + p_ℓ ≤ OPT ≤ 5/4·OPT，无危险。
  - 若 A 的 p₁ 机有后续：设首个进 p₁ 机的后续为 p_ℓ'。先证 **ℓ' ≤ ℓ**：反设 ℓ' > ℓ，则 p_ℓ
    （rank ℓ < ℓ'）在 p_ℓ' 前处理、此时 p₁ 机单件；p_ℓ 能放 p₁ 机（p₁+p_ℓ ≤ 1 ≤ K），故 p_ℓ
    未进 p₁ 机必因存在更满的机器 M'（M' > p₁，M'+p_ℓ ≤ K）；由 p_ℓ' < p_ℓ 得 M' + p_ℓ' < K，
    故 p_ℓ' 处理时 M'（仍 > p₁）能放下 p_ℓ' 且比 p₁ 机满，best-fit 必选 M'，与 p_ℓ' 是首个进
    p₁ 机者矛盾。故 ℓ' ≤ ℓ。删去 A 的 p₁ 机（p₁, p_ℓ' 及可能第三件）与一机，得 m−1 台新实例：
    p_ℓ' > m ⟹ p_m, p_{m+1} 保留、L 不变；其余指派不变，z 至多移到更差位置（A 不改善）。最优解
    删去 {p₁, p_ℓ} 机，并把保留的 p_ℓ 放到 p_ℓ' 原位置（ℓ' ≤ ℓ ⟹ p_ℓ' ≥ p_ℓ ⟹ makespan 不增），得
    m−1 台可行解。故新实例 OPT 不增而 A 不改善（仍 >5/4），与极小反例矛盾。∎
- **G-2b（L < 4/5，即 5/4L < 1）**：
  - **G3 A 无单件机（m₁ = 0）**：A 的单件机负载 ≤ 3/4（x₁ = 0），其负载 + z ≤ 3/4 + 1/3
    < 5/4，z 可放入、非 failure。∎
  - **G4 2 件机首件 >1/2（m₂ ≤ x₂）**：A 的 2 件机 y₁ ≥ y₂，若 y₁ ≤ 1/2，则
    y₁+y₂+z ≤ 1/2 + L/2 + 1/3 ≤ 5/4（y₂ ≤ p_{m+1} ≤ L/2，L < 4/5，z ≤ 1/3），z 可放入、
    非 failure。故 y₁ > 1/2，m₂ ≤ x₂。∎
  - **G5 计数矛盾**：A 中（m₁ = 0）z 前件数 ≥ 2m₂ + 3m₃，故
    n ≥ 2m₂ + 3m₃ + 1 = 3m − m₂ + 1 ≥ 3m − x₂ + 1；最优解侧（X₁ = X₄ = ∅，X₂ 各独占一机、
    至多再配一个）n ≤ 2x₂ + 3(m−x₂) = 3m − x₂。矛盾。∎

**推论（fallback 无反例）**：fallback 情形必落入引理 F 或引理 G，二者均无危险，故
fallback 不可能产生比值 > 5/4 的反例。∎

## 3. 口袋 1 的 n = 3m（M₀ 恰 2 件）

n = 3m 且 t > 1/4 ⟹ OPT 每箱恰 3 件 ⟹ 每件 ≤ 1 − 2t（箱内两小件各 ≥ t）。
M₀ 恰 2 件 x ≤ y ⟹ ℓ_min = x + y ≤ 2(1−2t) ⟹ C_A ≤ 2 − 3t < 5/4（t > 1/4）。∎
（n = 3m 时 M₀ 恰 1 件 / ≥3 件的情形由 §6 / §6' 引用 §2c 覆盖。）

## 4. 通用工具 ★★：S ≤ m − ℓ₀ − t

设 M₀ = {x, y}（x ≤ y，ℓ₀ = x + y），S = 其余 m−1 台机器的负载之和（= 除 {x, y, t} 外全部任务之和）。
在 OPT 中考察含 x、含 t、含 y 的三个箱（重合情形只会更紧，见下）：
- 含 x 的箱内其余任务之和 ≤ 1 − x；
- 含 t 的箱内其余任务之和 ≤ 1 − t；
- 含 y 的箱内其余任务之和 ≤ 1 − y；
- 其余 m − 3 个箱各 ≤ 1。

合计 S ≤ (1−x) + (1−t) + (1−y) + (m−3) = **m − ℓ₀ − t**。∎
（重合校验：x,t 同箱 ⟹ 该箱第三件 ≤ 1−x−t，合计 (1−x−t)+(1−y)+(m−2) = m−ℓ₀−t；x,y 同箱 ⟹ (1−ℓ₀)+(1−t)+(m−2) = m−ℓ₀−t；x,y,t 同箱不可能，因 x+y+t ≥ t + (1−2t) + t = 1，且 y > 1−2t 严格 ⟹ x+y+t > 1，而 y ≤ 1−2t 时 §5 前提已闭。）

## 5. 口袋 1（M₀ 恰 2 件）：n = 3m−1 全部 + n ≤ 3m−2 子情形 A

**前提**：y > 1−2t（否则 ℓ₀ ≤ 2(1−2t)，C_A ≤ 2−3t < 5/4，已闭）。
（其余机器若有单子机，该情形由 §2c 引理 F/G 的全局推论"fallback 无反例"直接覆盖；故下设
其余机器无单子机。）件数和 n − 3 ∈ [2m−2, 3m−4]，均值 < 3，
故由鸽巢**存在恰 2 件台 M\***（两件 u ≤ v）。

**子情形 A：v ≤ 1−2t（M\* 不含大任务）。**
- ℓ_\* = u + v ≤ 2(1 − 2t)。（F3：非大任务均 ≤ 1−2t）
- 权重分配：M\* 得 (m+2)/3，其余 m−2 台各得 1。总权 W = (m+2)/3 + (m−2) = 4(m−1)/3。
- W·ℓ₀ ≤ ((m+2)/3)·ℓ_\* + Σ_{其余} ℓ_i = ((m+2)/3)·ℓ_\* + (S − ℓ_\*) = ((m−1)/3)·ℓ_\* + S
  ≤ ((m−1)/3)·2(1−2t) + (m − ℓ₀ − t)。　（★★ 用于 S）
- 整理（两边乘 3/(4m−1)）：

$$\ell_0 \le \frac{5m-2}{4m-1} - t \quad\Longrightarrow\quad C_A = \ell_0 + t \le \frac{5m-2}{4m-1} < \frac54,$$

因为 5/4 − (5m−2)/(4m−1) = 3/(4(4m−1)) > 0。∎

**覆盖范围**：
- n = 3m−1：非-3 箱恰 1 个（箱型 (0,1,m−1)，sympy 验），大任务至多 1 个即 y，故 M\* 自动满足 v ≤ 1−2t——子情形 A 恒成立，**n = 3m−1 全部闭合**。
- n ≤ 3m−2：非-3 箱 ≥ 2，可能有第二个大任务 w。若存在不含大任务的 2 件台，子情形 A 适用。剩余情形（**每台 2 件台都含大任务**）为**子情形 B**：由 §2c 引理 F/G（fallback 浅/深情形均无危险）直接闭合。∎

## 6. 口袋 2（单子机）：闭合（引理 T''，2026-09-20）

口袋 2：最闲机为单子机 M₀ = {p_i}（p_i 是该机的初始任务，rank i），fallback 时 t 落入，
C_A = p_i + t。角落 = 危险 C_A > 5/4。

**引理 T''（口袋 2 角落闭合）**：口袋 2 角落不可能发生。

**关键（危险 ⟹ m₁* ≥ 1）**：危险 p_i + t > 5/4，t ≤ 2/5（Lemma B）⟹ p_i > 5/4 − t ≥ 5/4 − 2/5
= 17/20 > 3/4，即 p_i ∈ X₁。又所有 job > 1/4（z > 1/4 ⟹ x₄ = 0），故 p_i > 3/4 配任何 job（>1/4）和 > 1，
最优解中 p_i 独占一箱 ⟹ m₁* ≥ 1。

- 若 p₁ + p_{m+1} ≤ 5/4L：§2c 引理 F ⟹ 无危险，口袋 2 角落不存在。
- 若 p₁ + p_{m+1} > 5/4L：§2c 引理 G 的 G1 ⟹ m₁* = 0，与 m₁* ≥ 1 矛盾。∎

**注**：此符号证明覆盖全部口袋 2 角落（单子机任意 rank i、任意件数、任意窗口 t），核心机制
是"危险 ⟹ p_i > 3/4 ⟹ p_i 独占最优解箱（m₁*≥1）"，而深情形迫使 m₁* = 0。独立交叉验证：
修正版配对 LP（farkas_fixed.py：best-fit 最满优先序约束 + 件数三分 + 装箱枚举，m=4..11
全箱型全 k 精确常数证书 INFEASIBLE；m≥12 残余 k≈m−1 由二步 q_2 动态 LP 闭合，second_step.py）
与此一致，作为计算交叉验证存档。（2026-09-21 注：早期 pairing_feasible.py 的 firststep
编码方向有误，已废止，由 farkas_fixed.py 取代；本引理的符号证明不依赖任何 LP。）

## 6'. 口袋 3（最闲机 ≥ 3 件）：闭合（引理 F/G 引用，2026-09-20）

M₀ 件数 k ≥ 3。m = 4 由 ★★gen-k 闭合（ℓ₀ ≤ 1 − t/m ⟹ C_A ≤ 1 + 3t/4 ≤ 5/4），m ≥ 5 且存在
非大 2 件台时复用 §5 证书（证书不依赖 M₀ 件数）。残留情形（所有 2 件台含大任务 / 无 2 件台）
