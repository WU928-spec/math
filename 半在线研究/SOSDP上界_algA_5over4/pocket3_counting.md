# 口袋 3"他机全 2 件"角落：纯计数闭合（引理 P3C，无需 LP）

> 2026-09-21（agent-3）。背景：build_p3f 的 'y>=1−2t' 被审计判 INVALID（LP_CONSTRAINTS.md §2.1），
> 口袋3 残留的 LP 路线（统一族+体积链）作废。本节给出**不依赖任何 LP、不依赖 y/z 下界、
> 不依赖 danger、不依赖 firststep** 的纯计数闭合，且覆盖"他机全 2 件"的全部口袋3 子情形
> （含"含大任务"残留与"非大 2 件台"），q₁→M₀ 子情形自动在内。
> 验证：`code/pocket3_counting_verify.py`（sympy 全 PASS）；数值复核见 §4。

## 1. 角落设定

递减到达、OPT = 1（前缀归约：t 是前缀最后/最小任务，OPT(前缀) ≤ 1）。fallback 任务 t 落入
最闲机 M₀ = {x, y, z}（3 件，x ≤ y ≤ z）。他机 m−1 台各恰 2 件 {s_i, j_i}
（s_i = 该机初始件 = 较大件，j_i = 该机首个后至件）。mach：s_i + j_i ≥ ℓ₀ := x+y+z（M₀ 最闲）。
窗口 t > m/(4(m−1)) > 1/4（m ≥ 2 严格成立）。

**语义核对**（曾是不清点，显式列出）：
- z 是 M₀ 的初始件、x 与 y 是 M₀ 的两个后至件。依据：每台机器恰得一个初始任务；
  后至任务 ≤ q₁ := p_{m+1} ≤ p_m ≤ 任意初始任务，故 M₀ 三件中最大者 z 必为初始件。
- 直接推论：**z ≥ q₁**（z ≥ p_m ≥ q₁）；**x, y ≥ t**（先于 t 到达、递减、前缀最小）。

## 2. 引理 P3C

**引理**：上述"他机全 2 件"口袋3 角落不可能发生（不需要 danger）。

**证明**：
1. **s_i ≥ 2t ∀i**：s_i ≥ ℓ₀ − j_i（mach）≥ ℓ₀ − q₁（j_i ≤ q₁）
   = x+y+z − q₁ ≥ t + t + q₁ − q₁ = 2t（x,y ≥ t、z ≥ q₁）。
2. **senior 两两不共箱**：s_i + s_k ≥ 4t > 1（t > 1/4）⟹ m−1 个 senior 各占一个 OPT 箱。
3. **senior 箱至多带 1 件非 senior**：senior ≥ 2t，任意两件非 senior ≥ t + t（非 senior 全部 ≥ t：
   x, y ≥ t、z ≥ q₁ ≥ t、j_i ≥ t、t 自身），s_i + 两件 ≥ 4t > 1。
4. **OPT 每箱至多 3 件**：4 件各 ≥ t 则和 ≥ 4t > 1。
5. **计数矛盾**：非 senior 物品 = {x, y, z, t} ∪ {j_i}_{i=1..m−1} 共 **m+3** 件；
   容量 = (m−1) 个 senior 箱各带 ≤ 1 件 + 剩余 1 个箱子装 ≤ 3 件 = (m−1) + 3 = **m+2** < m+3。∎

**覆盖范围**：
- 不需要 danger（结构本身为空）；不需要 y/z ≥ 1−2t（被废止的假设）；不需要 firststep
  （q₁ 落 M₀ 或他机均在计数内）；不需要窄带 j < 2t、vol ≤ m、L 制度、"含大任务"条件。
- 故本引理统一闭合口袋3 的"他机全 2 件"全部子情形；口袋3 其余情形（他机有 1 件台或 ≥3 件台）
  不在本引理范围，仍由 proof.md §6'（§5 证书复用 / §2c 引理 F/G）覆盖。

## 3. 与 build_p3f 两个缺陷的关系

- 缺陷 A（审计发现）：'y>=1−2t' 承重且无角落必要性证明 ⟹ LP 闭合无效。P3C 不依赖该条。
- 缺陷 B（本次发现）：build_p3f 漏 'am<=z'（z 是初始件 ⟹ z ≥ p_m = a_m；文件有 am<=s_i 却漏 M₀ 的 z）。
  审计 E4 的见证点正是钻此缺口（z=0.32 < a_m=0.46、z < q₁）——该见证满足 build_p3f 其余全部
  约束，但违反 am<=z 这条合法约束。审计主结论（'y>=1−2t' 承重无据、证书支撑集为证）不受影响；
  "见证满足其余全部约束"的表述以此为准限定。
