# LP 约束逐条合法性审计（LP_CONSTRAINTS.md）

> 审计对象：`code/farkas_fixed.py: build_fixed`（口袋2角落）与 `code/pocket13_fixed.py: build_p3f`（口袋3残留）。
> 审计标准：**每条约束必须是所述角落情形的必要条件**；否则 LP 的 INFEASIBLE 结论无效（过约束假死）。
> 审计日期：2026-09-21（agent-3）。实验脚本：`code/audit_constraints.py`（E1–E7）、`code/audit_e1b.py`、`code/audit_e7b.py`。
> 约定：A x ≤ bc + bt·t（t 只在右端）；MG = 1/10000 精确有理数；OPT = 1 归一化；
> Algorithm A = cap K = 5L/4 的 best-fit **最满优先**（toolbox.py:27 `loads[i]>loads[best]`），L = p_m+p_{m+1}；
> 递减到达；前缀归约（会话12）：w.l.o.g. t 是前缀最后/最小任务，OPT(前缀) ≤ OPT = 1。

## 0. 角落定义（审计基准）

**口袋2角落（build_fixed）**：fallback 任务 t 落到单子机 M₀={p}（p = 该机初始任务，任意 rank；
LP 无 p≥s_i 约束，故 i=1..m−1 全覆盖），danger p+t > 5/4；他机 m−1 台各恰 2 件 {s_i,j_i}
（s_i = 该机初始件，j_i = 该机首个后至件）。角落窗口 t ∈ ((m−1)/(4(m−2)), 1/3]、L ∈ [2t, 4t)
（窗外由分片引理闭合，见 §1 第 6 条）。q₁ := p_{m+1} = 首个/最大后续；a_m := p_m = 最小初始。

**口袋3残留角落（build_p3f）**：最闲机 M₀ 恰 3 件 {x,y,z}（x≤y≤z），t fallback 落入，
danger x+y+z+t > 5/4；他机 = 2 件台含大任务（残留定义：所有 2 件台含大任务/无 2 件台，
proof.md §6'）。窗口 t ∈ (m/(4(m−1)), 1/3]。

**合法性的两个层次**：①语义必要（角落定义 ⟹ 约束成立）；②严格化（">" 编码为 ≥+MG）的
边界安全——用 E2 实验（MG=0 全松弛版 max 危险量 ≤ 5/4）兜底。

### 1.1 非小引理（#4）的准确陈述与证明

**引理**：口袋2角落中每台他机（2 件 {s_i,j_i}，s_i≥j_i）满足 s_i > 1−2t（严格）。
**证明**：M₀ 最空 ⟹ 该机负载 ℓ_i = s_i+j_i ≥ p（#9）。danger ⟹ p > 5/4−t，故 ℓ_i > 5/4−t。
反设 s_i ≤ 1−2t，则 j_i ≤ s_i ≤ 1−2t，ℓ_i ≤ 2(1−2t) < 5/4−t ⟺ 2−4t < 5/4−t ⟺ t > 1/4，
窗口 t > (m−1)/(4(m−2)) > 1/4 内成立，矛盾。∎
（窗口内还有一致余量：2s_i ≥ ℓ_i > 5/4−t ⟹ s_i > 5/8−t/2，与 1−2t 之差 = 3t/2−3/8 >
3/(8(m−2))（m=6: 3/32，m=12: 3/80），MG=1e-4 的严格化安全。）消融（E6）：m=6..7 全 cnt 全 k 去除后结论不变（本批证书未用它，但约束本身合法）。

### 1.2 窄带上界（#6）与其 L<4t 前提

- **前提闭合（分片引理）**：L ≥ 4t ⟹ t ≤ L/4 ≤ OPT/4 ⟹ C_A = p+t ≤ OPT+t ≤ (5/4)OPT（p ≤ OPT）。∎
  故角落残留于 L < 4t 制度。
- **该制度内**：q₁ ≤ L/2（q₁ ≤ p_m ⟹ q₁+q₁ ≤ p_m+q₁ = L）< 2t；j_i ≤ q₁ < 2t（严格）。∎
- 边界：L→4t⁻ 时 slack 2t−j_i 可 < MG；此类"近边界角落"的比值 ≤ OPT(1+t/L) ≤ 5/4+O(MG)——
  严格 5/4 由 E2 兜底：MG=0 时含装箱 LP 的 max(p+t) ≤ 5/4（m=4..11，见§3.3），近边界点不在区域中。∎
- 消融（E5）：m=6..7 去除后结论不变（不承重但合法）。

### 1.3 'p<K'（#16）为何是角落必要条件

**推导**：q₁ 恒由 best-fit 落到某他机 jj（q₁ 放不进 M₀：p+q₁ ≥ p+t > 5/4 ≥ K，因 K=5L/4≤5/4）。
2 件形态下 jj 机 = {s_jj, q₁}，best-fit 放入 ⟹ s_jj+q₁ ≤ K；M₀ 最空 ⟹ s_jj+q₁ ≥ p。
两式夹击 ⟹ **p ≤ s_jj+q₁ ≤ K**。∎（关键：无需"他机 ≤ K"这种可能失败的全局断言——
fallback 把他机填过 K 是允许的；只需 q₁ 落的那一台 jj 满足 ≤K，而它恒存在、恒 best-fit。）
**数值（E3）**：m=6..8 全 cnt 全 k，去除 'p<K' 后可行性逐点一致（LP 内冗余）；无 bins 松弛中
max(p−K) ≤ −0.30（蕴含链独立成立）。主代理疑点"p≥K 静态自洽"的解答：静态自洽是因为未计入
"q₁ 落机 jj 既 ≤K 又 ≥p"这条firststep 结构；计入后 p≥K 直接矛盾。

### 1.4 装箱固定分组（#23）的 w.l.o.g. 审核

**问题**：LP 对给定箱型计数 cnt=(a,b,c,d,e,f) 只编码**一种**固定分组（SS 用最小 2a 个 senior 连续配对、
SJ 用接下来 b 个 senior 配 jslot 前 b 件、JJJ/JJ 顺序取槽）；角落只保证**存在某种**合法分组。
两者不等价：senior 连续配对可以失败而另一种配对成功——抽象反例：seniors {0.41,0.42,0.55,0.56}，
合法配对 (0.41,0.56),(0.42,0.55) 存在，连续配对 (0.55,0.56)=1.11>1 失败。故固定分组可能把
"满足其余全部约束且可装箱"的角落点错误排除（过约束风险）。
**已确认的局部事实**：
- 箱型 taxonomy 完备：senior>1−2t（严格）+ junior≥t + t>1/4 ⟹ SSJ/SJJ/SSS/JJJJ 均 >1，
  rest 箱仅 SS/SJ/S/JJJ/JJ/J 六型（与 LP_ROUTE §1.0 一致）✓。
- SS 子集取最小 2a 个 w.l.o.g. ✓；SS 内**极端配对**（s_i 配 s_{2a−1−i}，最小配最大）w.l.o.g. ✓
  （标准重排论证）；但 LP 用的连续配对不是 w.l.o.g.（上例）。
- 数值证伪失败：E1/E1b 对 m=6..10 全 k、全 t 窗口、随机目标数千顶点做"无 bins 松弛 + 精确装箱
  DFS（m−1 箱、cap 1、≤3 件）"检查：**0 个可装箱点**（即声音松弛本身经验为空，角落不存在
  被固定分组错误排除的见证）；极端配对 SS 变体全扫 m=6..10：**0 翻转**（连续配对未额外承重）。
- m=12 k=11 cnt=(2,7,0,1,1,0) 已知静态洞：固定分组 LP 可行、见证点可装箱（与扫描自洽，
  该洞由二步 LP/保序 LP 另行处理，LP_ROUTE §1.3–1.4）。
**verdict**：【待证】理论上不严格（连续配对/恒等 junior 匹配非 w.l.o.g.），但本案 INFEASIBLE 结论
与声音松弛（无 bins+装箱）经验一致，未找到反例。修复建议：SS 帽改极端配对、junior 槽位
枚举排列或直接以装箱 DFS 替代帽约束重扫。

### 2.1 ❌ 首要发现：'y>=1-2t' 不是口袋3残留角落的必要条件

**承重性（E4）**：去除该条后，m=6..12 全部 k 由 INFEASIBLE 翻为 FEASIBLE（m=4,5 仍有证书）。
**反例级见证**（满足 build_p3f 其余全部 62 条约束、严格危险、违反 y>1−2t）：
- m=6 k=1 t=0.3139：max(ℓ₀+t) = **1.255733 > 5/4**，该点 y = 0.3139 < 0.3721 = 1−2t；
- m=6 k=3：同上 1.255733；m=8 k=1：1.258743，y = 0.3147 < 0.3706。
  （见证由 `audit_constraints.py e4` 输出，全约束最小松弛 ≥ −1e-15。）
  **限定（2026-09-21 续审计补记）**：这些见证还满足 am<=s_i 等全部 build_p3f 既有约束，
  但违反了 **am<=z**（z 是 M₀ 初始件 ⟹ z ≥ p_m = a_m）——一条合法但 build_p3f **漏编码**的
  约束（缺陷 B：文件有 am<=s_i 却没有 M₀ 自己的 am<=z）。见证的 z=0.32 < a_m=0.46。
  审计主结论不变（'y>=1−2t' 承重且无据、432 证书支撑集为证），但严格说见证是钻了
  缺陷 A（y 下界无据）与缺陷 B（am<=z 缺失）两个缺口的叠加。补上 am<=z 后，整个区域
  由纯计数引理 P3C 闭合（见 pocket3_counting.md，无需 LP、无需 y 下界）。
**证书归因**：m=6 k=1 精确证书支撑集 = {x<=y, y<=z, x>=t, y>=1-2t, mach×5, vol<=m}——
即闭合链为 "y,z ≥ 1−2t ⟹ ℓ₀ ≥ x+2y ≥ t+2(1−2t) = 2−3t ⟹ (mach 传递) m·ℓ₀ ≤ m−t ⟹
t ≥ m/(3m−1) > 1/3 ≥ t 矛盾"。uniform_certs_p3.py 的 432 发统一证书族（m=4..30）与
pocket3_volume.md 的"纯体积链"**全部建在这同一条无根据约束上**。
**为何无根据**：
1. 残留定义（proof.md §6'）只说"他机 2 件台含大任务"——约束的是他机 senior，不涉及 M₀ 的 y,z。
   pocket3_volume.md §4 括注"残留情形定义 y,z>1−2t"是对残留定义的误读。
2. pocket1 的 F2 类比（M₀={x,y}：y≤1−2t ⟹ C_A≤2−3t<5/4 已闭）在 pocket3 不成立：
   M₀ 有 3 件，即使 z ≤ 1−2t 也只有 C_A ≤ 3−5t < 5/4 ⟺ t > 7/20 = 0.35，而口袋3 窗口
   t ≤ 1/3 < 0.35——闭合不了。y（非最大件）≤1−2t 更无从闭合。
3. 体积/计数（★★gen-k、3 箱小件计数、大任务每箱 ≤2）均推不出 y 的下界（审计逐一尝试，见工作记录）。
**后果**：build_p3f 的 INFEASIBLE（m=4..30 全 k）作为"口袋3残留角落为空"的证明**无效**。
**缓冲事实**：(i) proof.md §6' 的符号闭合（§2c 引理 F/G）不经过该约束，主定理不受影响；
(ii) E4b 对被排除见证做精确装箱检查：采样数百点 **0 个可装箱**——角落很可能仍为空，
但需要的是装箱论证（或 F/G），不是这条 y 下界。
**修复方向（供后续，不在本审计范围）**：删除 y>=1-2t，改用装箱约束（口袋2式帽/装箱 DFS）或
直接引用引理 F/G 闭合残留。

### 2.2 覆盖缺口：q₁→M₀ 子情形不在建模内

build_p3f 的 fs 组（#13）强制 q₁=p_{m+1} 落到某台**他机** jj。但 M₀={x,y,z} 的初始件 z
可能满足 z+q₁ ≤ K 且是"放得下的最满机"——q₁ 会落 M₀（口袋2 免疫此情形：p+q₁ ≥ p+t > 5/4 ≥ K；
口袋3 的 M₀ 初始件可以小）。
**E7b 数值**：q₁→M₀ 角落 LP（z+q₁≤K、他机全 nofit、其余约束同 build_p3f 语义）在
m=6,7,8 静态自洽（如 m=6 t=0.301：x=y=q₁=z=0.3163，ℓ₀+t=1.25，他机 s_i+q₁>K 全成立）。
⟹ 该子情形角落**不在 build_p3f 覆盖范围**。当前无实际影响（E7：firststep 整组不承重），
但若按§2.1 修复 y-bound 后该组变成承重件，必须补上此子情形（或论证其不可能/由他处闭合）。

### 3.2 LP 覆盖范围边界（口袋2）
- LP 只覆盖"他机全 2 件"形态。他机 1 件：会话21(i) 的排除用了严格不等（负载=初始<p 不可能>p），
  **平局** s_i=p（另一台同值最大初始的单子机）未被该论证排除——此残余由 proof.md 的引理 F/G

## 16. 分支证书（disjunctive case-tree）设计（2026-09-22 agent-3）

洞本满足 MR（空区间），MR 对 razor 区不咬。✗ MR 不是所需新原料。
