## 1. 角落模型与记号（同 build_fixed）

m≥4，OPT=1 归一化。口袋 2 角落（n=2m 最紧形态）：
- M₀={p}：单子机，p = 最大初始任务；fallback 任务 t 最后到达落到 M₀；危险区 p+t>5/4。
- 他机 m−1 台各恰 2 件 {s_i, j_i}：s_i 为初始件（senior，>1−2t），j_i 为后至件（junior，
  窄带 [t,2t)）。机器按 senior 递增编号 s₀≤…≤s_{m−2}。
- 后至件递减到达：q₁=p_{m+1}（最大 junior，首个后至件）≥ q₂ ≥ … ≥ q_{m−1} ≥ t。
- q₁ 落机 = jj = k−1（best-fit 最满优先：s_jj+q₁≤K，且 s_i+q₁>K 对 i>jj，即 nofit）。
- 角落必要条件（LP 已有）：pair（M₀ 最闲 ⟹ s_i+j_i≥p ∀i）；K=5L/4，L=p_m+p_{m+1}≤1；
  OPT=1 装箱：rest 装入 m−1 箱，箱型计数 cnt=(a,b,c,d,e,f)（a 个 SS 箱、b 个 SJ 箱、
  c 个 S 独占箱、d 个 JJJ 箱、e 个 JJ 箱、f 个 J 独占箱；2a+b+c=m−1，b+3d+2e+f=m）。
- LP 的对称性约定（基线管线既有）：件为对称连续变量，装箱固定分组代表 WLOG——
  SS 箱取最小 senior（(s₀,s₁),(s₂,s₃),…），SJ 箱 senior s_{2a+k} 配 junior 池第 k 件，
  JJJ/JJ 箱依次取 junior 池后续件（池 = 他机 junior 按机器序 + t 殿后）。

## 2. 引理 1（单调匹配，动态，对一般 m 成立）

**陈述**：角落产生运行中，[0,jj] 区间机器的 junior 随 senior 单调不减：

$$j_0 \le j_1 \le \dots \le j_{jj} = q_1 .$$

**证明**。
(i) **[0,jj] 机器对任意 junior 恒放得下**：对 i≤jj 与任意后至件 q，
q≤q₁ 且 s_i≤s_jj ⟹ s_i+q ≤ s_jj+q₁ ≤ K（q₁ 落 jj 的定义）。
(ii) **已填机永不二次接收**：角落形状要求每台他机恰 1 个 junior（n=2m 计数：m−1 个
junior 对 m−1 台他机）；若某机收第 2 个 junior 则必有他机 0 个，破角落形状。
(iii) **归纳**：q₁ 落 jj（k 的定义）。设 q₁,…,q_{r−1} 已放置且 [0,jj] 区间被填机满足
"senior 大者先填、junior 递减"。q_r 到达时，best-fit 取"放得下的最满机"：凡 >jj 的
单机若放得下 q_r 则必被选中（其 senior > s_jj ≥ [0,jj] 任意负载），否则 q_r 落到
[0,jj] 当前最满的单机 = 该区间剩余最大 senior 机。junior 递减到达 ⟹ 归纳保持。
(iv) **senior 并列**：s_i=s_{i+1} 时机器可互换重标号（角落模型机器标号对称），
同级内按 junior 递增排列即可，约束 WLOG。∎

**实证**：`fuzz_mon2.py` 在 14,949,895 个随机递减实例中检出 51,516 个真口袋 2 角落
事件，逐例检查严格版（s_A<s_B≤s_{M*} ⟹ j_A≤j_B）、标号版 (i)、q₁ 落机可放性 (ii)、
nofit (iii) —— **0 反例**。

## 3. 引理 2（统一符号证书，静态不等式）

**陈述**：设角落配置满足引理 1 的单调匹配，且 OPT=1 装箱存在某个 SS 箱与某个 JJJ 箱
（即 cnt 中 a≥1 且 d≥1），JJJ 箱三件为 junior 池连续三件 j_b,j_{b+1},j_{b+2}
（b = SJ 箱数；设 b≥1、b+2≤m−2 即该箱不含 t），且 k≥b+2（单调链到达该箱）。则矛盾。

**证明**（望远镜恒等式）。下列括号均为可证非负量：
- D = p+t−5/4 ≥ 0（danger）；
- P_i = s_i+j_i−p ≥ 0（pair，i=0,1，取最小 senior 两台 = 首个 SS 箱的机）；
- C = 1−s₀−s₁ ≥ 0（SS 箱容量）；
- G = 1−j_b−j_{b+1}−j_{b+2} ≥ 0（JJJ 箱容量）；
- j_{b+1}−t ≥ 0、j_{b+2}−t ≥ 0（窄带下界）；
- M_i = j_{i+1}−j_i ≥ 0（引理 1，i=0,…,b；存在性由 k≥b+2 保证）。

直接展开验证恒等式：

$$6D + 3P_0 + 3P_1 + 3C + 4G + 2(j_{b+1}-t) + 4(j_{b+2}-t) + 3M_0 + 6\textstyle\sum_{i=1}^{b-1}M_i + 2M_b = -\frac12 .$$

（p: 6−3−3=0；t: 6−2−4=0；s₀,s₁: 3−3=0；j₀: 3−3=0；j₁: 3+3−6=0；
j_i(2≤i≤b−1): −6+6=0；j_b: −4+6−2=0；j_{b+1}: −4+2+2=0；j_{b+2}: −4+4=0；
常数: −15/2+3+4=−1/2。）左边每项 ≥0，和为 −1/2，矛盾。∎

**推论**：任何满足 a≥1, d≥1, b≥1, b+2≤m−2, k≥b+2 的 (cnt,k) 角落配置不可能——
不解 LP 的符号证明，对**一切** m 成立（恒等式与 m 无关）。

**结构事实（使覆盖区几乎全集化）**：任意合法箱型计数 cnt 恒有 a≥1 与 d≥1。
证明：a=0 ⟹ d=e=f=0（a=d+e+f）⟹ junior 守恒 b=m 与 senior 守恒 b+c=m−1 矛盾（c=−1）；
d=0 ⟹ f=a−e，junior 守恒给出 a+b+e=m，于是 2a+b = m+(a−e)−... 直接地：e=m−a−b≥0
且 f=2a+b−m≥0 ⟹ 2a+b≥m，与 c=m−1−2a−b≥0（即 2a+b≤m−1）矛盾。∎
故模板未覆盖区只剩三类：b=0（无 SJ 箱）、k<b+2（单调链短于 SJ 箱数）、
b+2>m−2（唯一 cnt=(1,m−3,0,1,0,0)，JJJ 箱含 t）。这三类在 m≤22 全扫中**从未出洞**
（基线 LP 已闭合，强化 LP 保持），由 `leftover_scan.py` 逐 m LP 复核 m≥23。

## 5. 动态不可达性的直接证据（hole_reach.py）
