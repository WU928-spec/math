# sliver 最终两格簿记 — a1_

> 格 α'（#{s≥J}=1, t∈(5/16,1/3]：证残差必死）/ 格 β（#{s≥J}=0：证 j₃≤1−s_{nS}）。

## 格 α' 第一步（两分支公共）：s_{nS} 必入 SS 对
s_{nS} ≥ J > 1−j₃（sliver）⟹ s_{nS}+j₃>1，且 s_{nS}+j_x>1 ∀x≥3。
若 s_{nS} SJ 配 j₁（或 j₂）：JJJ 需 t+2 junior≤1 自 {j₂,j₃,..}（或 {j₁,j₃,..}）：
t+j₂+j₃ > 1+t−j₁ ≥ 1（j₃>1−J=1−j₁−j₂）矛盾 ⟹ **JJJ 不存在 ⟹ 不可装箱**。
⟹ 可装箱 ⟹ **s_{nS} 必在 SS 对**（伴 ≤1−s_{nS}）。
**弹药应用**：s_{nS}+s_{nS−1} > 2p−2t > 5/2−4t ≥ 1（t≤1/3: 5/2−4t ≥ 7/6>1）
⟹ **s_{nS−1} 不能作 s_{nS} 的伴** ⟹ s_{nS−1} 留在残差。

## 格 α' 分支 1（J < 2p−4t）：残差必死 ✓ 证讫
s_{nS}≤2t（SS 可行性）+ 弹药：s_{nS−1} > 2p−2t−s_{nS} ≥ 2p−4t。
j₃ > 1−J。残差反序首行：s_{nS−1}+j₃ > 2p−4t+1−J > 1（J<2p−4t）。
链图 Hall（§21.1）：反序首行破 ⟹ 残差匹配不存在 ⟹ 不可装箱。**∎**

## 格 α' 分支 2（J ≥ 2p−4t）：未决（精确值区）
J∈[2p−4t, 2t]（窗口非空 ⟺ t>5/16，恰 α' 窗）。值例 t=1/3, p=0.92:
J=0.55, j₁=0.32, j₂=0.33, j₃=0.45, s_{nS}=0.6, s_{nS−1}=0.52：全约束过
（A1r1 紧、B2、band、弹药 0.6+0.52=1.12>1.17? 弹药需 >2p−2t=1.17: 1.12<1.17 不过——
弹药实际收窄该值区；待按弹药重算残余值区）。残差首行 s_{nS−1}+j₃=0.97≤1 可行
——此区值不自死，需 A5/LZ/HZ（机配 k 结构）或分支 1 的加强弹药。
**状态：α' 半证（分支 1 闭，分支 2 移交 k-结构弹药）**。

## 格 β（#{s≥J}=0）：证 j₃ ≤ 1−s_{nS}
失败形 j₃ > 1−s_{nS} 与 A1r1（s_{nS}≥p−j₁）+β（s_{nS}<J）+B2（J≤1−t）+
band 在 t=1/3 **值相容**（例：s_{nS}=0.6, J=0.65, j₁=0.32,j₂=0.33,j₃=0.45,
A1r1=0.92≥p 紧）——与 α' 分支 2 同型：**需机配结构或 packable 侧论证**
（packable ⟹ j₃≤1−s_{nS} 恰为 (P) 型）。β 与 α' 分支 2 合流为同一未决值区。

## 判决
- α' 分支 1（J<2p−4t）：**证成**（s_{nS}→SS 强制 + 弹药杀伴 + 残差 Hall 死）。
- α' 分支 2 + β：**同值区未决**，值约束单独相容，需 A5/LZ/HZ 机配结构或
  packable 侧——登记移交（与 main 的 CEGAR 幻影-阻断路线合流：值区点若是幻影，
  CEGAR 应杀；若杀不动=新信息）。

## 格 α' 分支 2 子分裂（追加）
分支 2（J ≥ 2p−4t）按残差首行再分：
- **(2a) s_{nS−1} > 1−j₃**：残差反序首行 s_{nS−1}+j₃ > 1 ⟹ Hall 死 ⟹ 不可装箱 ✓
  （与分支 1 同型，条件以 j₃  vs 1−s_{nS−1} 表述）。
- **(2b) s_{nS−1} ≤ 1−j₃**：首行紧（≤1 成立）。级联：row q 需 s_{nS−q} + j_{q+2} ≤ 1。
  s_{nS−q} 上界受 s_{nS−1} ≤ 1−j₃ 传导（s_{nS−q} ≤ s_{nS−1} ≤ 1−j₃ ≤ 1−j_{q+2} 仅当
  j_{q+2} ≤ j₃——恒真（升序）⟹ **传导给不出**（1−j_{q+2} ≤ 1−j₃，需更紧）。
  ⟹ (2b) 的可行性强依赖 j₄..j_{nS} 与 s_{nS−2}.. 的精细分布——值级联条件链。

**(2a) 覆盖核算**（弹药+分支 2 值域）：s_{nS−1} > 2p−2t−s_{nS}（弹药, s_{nS}≤2t 用满时
s_{nS−1} > 2p−4t）。(2a) 条件 j₃ > 1−s_{nS−1} 的**充分条件**：
j₃ ≥ 1−2p+2t+s_{nS}（弹药代入）。其可达性：1−2p+2t+s_{nS} ≤ 2t ⟺ s_{nS} ≤ 2p−1：
p > 5/4−t ⟹ 2p−1 > 3/2−2t ≥ 7/6（t≤1/3）> 2t ≥ s_{nS} ✓ **恒可达**——即对任意
分支 2 值组，j₃ 落 [1−2p+2t+s_{nS}, 2t] 时 (2a) 杀。j₃ 落 (1−J, 1−2p+2t+s_{nS}) 为 (2b)。
**(2b) 剩余义务**：j₃ 低段 + 弹药全紧（j₁=p−2t, s_{nS}=J, s_{nS−1}=2p−4t 边界）的
级联链可破性——按 CEGAR 实证（290 见证 0 可装）此区应全死，符号化 = row 2+ 的
逐 rank 值条件或体积细账（squeeze 单用已证不够；候选：A1 r≥4 反序与 squeeze 的联合）。

## (2b) 薄性核算 + 钉扎值（追加）
(2b) 区间 j₃ ∈ (1−J, 1−2p+2t+s_{nS}) 在分支 2 边界 J=2p−4t+2MG 处宽度：
(1−2p+2t+s_{nS}) − (1−J) = J − 2p + 2t + s_{nS} = 2MG + s_{nS} − 2t ≤ 2MG（s_{nS}≤2t）

J≈2p−4t, j₁=j₂≈p−2t（弹药紧）, j₃≈1−J≈0.493, s_{nS}≈2t, s_{nS−1}≈1−j₃≈2p−2t−s_{nS}

**级联在该钉扎点一致**（A1 r≥3 与 row-q 紧相容），无值级强杀 ⟹ **杀手必为机配 k-结构**

深入需 LZ/HZ 的 k 定位）。**移交 main CEGAR**（290 见证 0 可装实证该 MG 薄区全死）。
