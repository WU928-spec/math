## 2. SJ 行的合法性分析（剩余枢纽）

LP 保守形 SJ = 最小 b juniors 配中段 seniors（同向配对）。合法性 ⟺ 可装箱 ⟹ 存在
此形可行匹配。
- ** juniors 最小 b 个 ⟹ 帽安全方向正确**（小 junior 配 senior 不易超 1）；
- **B 链对照**：B 规范形 SJ = MRF 伴侣集（最大相容）+ SJ-REV 反序——与 LP 形相反。
- **合法性来源候选**：MRF 伴侣集 G 支配一切可行匹配的伴侣集 C ⟹ 最小 b juniors ≤ C
  逐分量？G 支配 C（G≥C 逐分量）⟹ 最小 b  juniors ≤ G——但需 ≤ C（真实伴侣集）。
  最小 b ≤ C？**C 是某 b 子集 ⟹ 最小 b ≤ C 逐分量 ✓**（平凡：最小 b 个子集逐分量
  ≤ 任意 b 子集）。⟹ 最小 b juniors 逐分量 ≤ 真实 SJ 伴侣集 C。真实侧 C 与中段
  seniors 可行匹配 ⟹ 最小 b（更小）与中段 seniors…… **同向配对**给最小 juniors 配
  最小中段 senior——可行？最小 juniors 配最小中段 seniors：和最小 ⟹ 可行 ✓？
  需谨慎：SJ 匹配是 b 个 senior 与 b 个 junior 的双射；真实侧 C 与中段 senior 可行
  ⟹ 存在匹配。最小 b juniors ≤ C 逐分量 ⟹ 用同一匹配模式装最小 b ⟹ 各对和 ≤
  真实对和 ≤1 ✓（支配传递）。**所以 SJ 行合法性 = "真实 SJ 伴侣集 ⊇ 支配 ⟹ 最小 b
  可行" ⟸ C 支配最小 b（平凡子集最小）✓**——这给出 SJ 行合法性的证明：
  可装箱 ⟹ 真实 SJ 匹配存在 ⟹ 最小 b juniors 与中段 seniors 的匹配（支配传递）可行 ⟹
  LP 的 SJ 行（同向配对帽）成立？同向配对（s 升序配 j 升序）：最小 junior 配最小
  中段 senior——支配传递需 juniors 与 seniors 的配对方位一致。让我验证支配传递的
  配对方向：真实匹配 μ：s_{σ(k)} 配 C_k ≤1。最小 b juniors w_k ≤ C_k。同配对
  s_{σ(k)} 配 w_k ≤ C_k ⟹ s_{σ(k)}+w_k ≤ s_{σ(k)}+C_k ≤ 1 ✓ 可行 ✓。但 LP 的 SJ 行
  是**固定配对**（s_{2+k'} 配 j_{k'} 同向）——支配传递给的是"存在某配对"，
  不是"同向配对"。同向配对可行性需 SJ-REV/重排：存在匹配 ⟺ 反序可行；
  同向 = 最坏配对——**同向配对可行不能从存在匹配直推**（同向可能失败而反序可行）。
  **SJ 行的同向配对合法性 = LP 形 vs B 形的真实差异所在**——需 razor 区 juniors
  近全等（同向≈反序≈任意配对等价）躲开。razor 壳 juniors 低端区全等（§18.3）✓
  razor 壳内同向=任意 ✓ 合法。非 razor 壳 razor 带（同带不同 razor 点）——
   juniors 非全等时同向配对合法性**未证**（缺口）。

## 3. 判决与不可闭合义务的精确形态
