# G1 路线 C（删机归纳）遗传性判决 — a1_

> 任务：评估 CKK2012 Subcase 2a 式删机归纳对 G1-razor 的可移植性。
> 判决：**朴素遗传性证伪（计数结构破裂）；条件遗传性（重配对语义）成立但其归纳
> 扩展步重新引入 Case B 簿记——路线 C 不绕开 razor-thin 墙**。正面副产物：
> razor cnt 家族对"删 2 个 SJ 箱"封闭（shape A→A′、B→B′）。

## 1. 朴素删除的计数破裂（证伪核心）
razor 角落的紧绑定：nS 台机各绑 1 senior + 1 junior（nS=m−1），守恒恒等式
(a=d+e+f, d=1+c+f) 使箱型计数脆。候选删除逐一核：
- **删 {s₁,s₂} 的实箱（2 箱）**：实箱若为 2 个 SJ 箱 {s₁,J₁},{s₂,J₂}：物项 −4
  (s₁,J₁,s₂,J₂)，余 nS−2 senior、nS−2 junior、m′=m−2：计数 ✓。但**扩展步**：
  归纳给出余量的规范装箱（SS={s₃,s₄}）后，加回 {s₁,s₂} 作 SS（1 箱）只恢复到
  m−1 箱——**缺 1 箱**（J₁,J₂ 两物项无处可放，它们已被删除）。加回 J₁,J₂ 则
  守恒破（pool 多 2 件）。⟹ 归纳扩展 ≠ 原 G1 的解，环闭合失败。
- **删 1 机 + 1 箱**：物项 −1 senior −2 junior（机 junior + 箱伴）或 −2 senior −1
  junior，恒差 ±1：nS′=nS−1 需 nS−1 junior，实余 nS−2 或 nS ✗。
- **根因**：CKK 的删除有**动态替换件**（p_ℓ′ 来自 Algorithm A 的放置，ℓ′>ℓ 用
  更小者替换不增 OPT）——静态 razor 角落无此物；机器紧绑定（1s+1j/机）使任何
  删箱在 senior/junior 双侧不同步破裂。

## 2. 条件遗传性（重配对语义）——成立但扩展步=原问题
若"角落"语义放宽为**值多重集 + ∃合法机配对**（删后允许重配 remaining seniors
与 juniors）：
- 可装箱性传递 ✓（OPT 删 2 箱平凡）。
- 配对重构 ✓（余 nS′ 台机任意配）。
- squeeze 不必承袭：余量实例的挤压由其**自身** OPT 导出（Σℓ′≤nS′−t 是
  packable 的推论，agent-3 挤压引理）。
- **razor cnt 家族封闭 ✓**：shape A (1,m−3,0,1,0,0) 删 2 SJ → (1,m−5,0,1,0,0)
  = (1,m′−3,0,1,0,0) (m′=m−2) = razor A′ ✓；shape B (2,m−5,0,1,1,0) 删 2 SJ →
  (2,m−7,0,1,1,0) = (2,m′−5,0,1,1,0) = razor B′ ✓。
- **但**：归纳假设给"余量（已重配对）的规范装箱"，扩展步 = 加回 {s₁,s₂} SS 箱 +
  安置 J₁,J₂（挤出的 junior）+ 恢复被重配对的机——**扩展步在 m′ 上重铸原 G1
  难度**（s₁,s₂ 与余量 senior 的 SS 资格交换 = 原挤出问题的化身）。无绕开。

## 3. 判决与移交
- **朴素遗传性：证伪**（§1，计数结构 + 无动态替换件）。CKK 删机归纳的两个支柱
  （独占机交换 m₁*=0 化简 + 动态替换件 ℓ′）在 razor 静态角落均缺对应物。
- **条件遗传性：成立但循环**（§2）——归纳的扩展步 = Case B 簿记的 m′ 版。
- **正面副产物**：razor cnt 家族对"删 2 SJ 箱"封闭（A→A′、B→B′）——若未来有
  动态语义（序到达的替换件），路线 C 的家族侧已就绪。
- 建议（上板）：路线 C 需要"替换件源"（动态放置或外部件注入），纯静态 razor
  角落不适用；回到 Case A（值中性已条件证）+ Case B 的 c-常数（agent-3 动力学）。

## 4. 路线 C′复活（删 1 机，2026-09-23 追加）——遗传性成立 + 扩展步归约
**删机方案**：删最小 senior s₁ 的机 (s₁, j₁) + 从真实装箱 P 删 s₁ 的箱。
- **计数 ✓**：m′=m−1, nS′=nS−1, senior −1, junior −1(j₁)−箱伴 J（SJ 情形）→ nS−1=nS′ ✓,
  pool = nS ✓ = m′。
- **razor 家族封闭 ✓**：s₁ 的箱为 SJ 时 cnt′=(a,b−1,c,d,e,f)：A (1,m−3,..)→(1,m′−3,..) ✓,
  B (2,m−5,..)→(2,m′−5,..) ✓。
- **packability/corner ✓**（P 删箱；余机 ℓ≥p 不变；squeeze 由余量自身 OPT 导出）。
**扩展步（构造原规范装箱）**：余量规范装箱（归纳假设）中插入 s₁（全局最小 senior）：
- **s₁ 的放置极易**：B3(s_max≤1−t) ⟹ s₁≤1−t ⟹ **s₁+t≤1 恒成立**——s₁ 可与 t 组
  SJ 箱（cap 1−s₁ 最大，s₁ 是最易安置的 senior）。
- 级联深度 ≤2：t 移出 JJJ → JJJ 补最小 SJ junior j_a → j_a 原箱 senior 需新 junior。
  **微引理（剩余义务）**：razor 下该二级联的可行性——j_a 取最小可用 ⟹ JJJ 最宽松；
  末级 senior 的 cap = 1−s_a，由 razor 值带给 slack。此微引理 = Case B 的 **单点
  版**（非全序 ∀q），强度大减：只需一个 senior-junior 对相容，μ/ν 退化为单对差。
**判决更新**：朴素 2-箱删除证伪（§1）；**1-机删除遗传性成立**，G1 归约为"插入最
小 senior 的二级联微引理"（单对相容，非 Hall ∀q）。若微引理证成（razor 值带应足——
j_a 最小 + s_a cap 由 B3 给），G1-razor 经归纳闭合，且**绕开 ∀q 簿记**（路线 C 的
预期价值在 1-机形态下兑现）。

## 5. 扩展步完整构造 + 微引理精确形态（C′ 证明主体）
**扩展（余量规范装箱 π′ 上插入全局最小 senior s₁，计数恢复 (a,b,c,d,e,f) ✓）**：
取 SJ 箱 (s_a, j_a)（j_a = 任选），三级联：
1. **新箱 (s₁, j_a)**：合法 ⟸ j_a ≤ 1−s_a ≤ 1−s₂ ≤ 1−s₁（s_a≥s₂≥s₁，SJ 可行性传导）✓ 恒成立。
2. **s_a 移配 t**：合法 ⟸ B3（s_a ≤ s_max ≤ 1−t ⟹ s_a+t≤1）✓ 恒成立。
3. **JJJ 补件 j_new**：需 j_x+j_y+j_new ≤ 1（j_x,j_y = 余量 JJJ 中除 t 的两件）。
**微引理 ⟸ B2'：三最小 junior 和 j_(1)+j_(2)+j_(3) ≤ 1**（取 j_new = 第 3 小即满足；
j_(1)+j_(2)+j_(3) ≤ 1 ⟹ 任意 j_new ≤ j_(3) 都满足 j_x+j_y+j_new ≤ j₁+j₂+j₃ ≤ 1 ✓）。
**B2' 不是角落/可装箱必要**（B2 = t+j₁+j₂≤1 才是；B2' 更强：t<juniors 使 B2 更易）。
**失效 sliver**：t+j₁+j₂ ≤ 1 < j₁+j₂+j₃——此时 JJJ 三元组被**唯一强制** = (t,j₁,j₂)
（其它 trio 含 j₃ 必超）⟹ G2a 平凡成立；SJ 层 = 余池 {j₃..} 上的匹配（回到 m′ 归约，
但该 sliver 的 JJJ 刚性可能反过来钉住 junior 分布使匹配易判——登记深挖）。
**判决（更新）**：G1-razor 经路线 C′ 归纳 **条件闭合于 B2'**（三最小 junior 和 ≤1）；
失效 sliver 窄（JJJ 唯一强制形）。这是 G1 的第一个**归纳架构条件证明**（非 ∀q 簿记），
路线 C 的价值在 1-机删除形态兑现。

## 6. sliver（B2' 失效带）刻画 = 路线 C′ 的最终残差
**sliver 定义**：j_(1)+j_(2)+j_(3) > 1（任意三 junior 和 >1）∧ t+j₁+j₂ ≤ 1（JJJ 存在）。
**结构**：① JJJ 必含 t（无 t 三 junior 必超）；② 三级联的 JJJ 补件需"三 junior 和≤1"
⟹ **补件在 sliver 内恒不可行**（任何补件+JJJ 原两件 ≥ j₁+j₂+j₃ > 1）——t 移动方案
在 sliver 内全灭。
**sliver 内的替代扩展（登记）**：不移动 t，s₁/s₃ 直接入 SJ 层（cap 最大），SJ 匹配
吸收额外 senior——即"余量匹配 + 最易 senior"问题，sliver 的 junior 分布（至多 2 个
小 junior，其余 > 1−j₁−j₂）使 SJ 层 junior 偏大、匹配难在 senior 端——**回到 Case B
∀q 簿记，但仅限 sliver**（B2' 成立时路线 C′ 已闭合，与 ∀q 无关）。
**总判决**：路线 C′ 给出 **G1-razor 在 B2' 下的归纳证明**（三步两级联，两步恒真
B3/传导，唯余 B2'）；sliver 窄（razor 紧带内 j₁+j₂+j₃ ∈ (1, 1+2t]）且结构刚性
（JJJ 含 t 强制）。sliver 闭合 = razor 带 (P) 第二证明全域完成；移交 sliver 的
SJ 层匹配（值带约束强，可能直接可判）。
