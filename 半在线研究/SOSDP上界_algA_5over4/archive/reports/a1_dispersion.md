## 1. 引理与证明
**引理 D**（∀m≥4，∀cnt，∀t∈窗口）：若角落值（band j∈[t,2t)、s>1−2t、pair ℓ_i≥p）
可装箱，则池（juniors ∪ {t}）的最小三元组和 ≤ 1，即 t + j_(1) + j_(2) ≤ 1。
**证明**：
1. 装箱计数恒等式（bin_count_solutions 守恒的直接推论，已核验 m=4..12 全 cnt）：
   a = d+e+f 且 **d = 1+c+f ≥ 1**——每个合法箱型计数含至少一个 JJJ 箱。
2. JJJ 箱 = 池的 3 件和 ≤ 1 ⟹ 池最小三元组和 ≤ 1。
3. band j ≥ t ⟹ 池排序 t ≤ j_(1) ≤ j_(2) ≤ … ⟹ 最小三元组 = t + j_(1) + j_(2)。
∎（反证形式：t + j_(1) + j_(2) > 1 ⟹ 一切三元组 > 1 ⟹ JJJ 箱不存在 ⟹ 一切 cnt
不可装箱。）

## 2. 数值核验
- 恒等式 a=d+e+f、d=1+c+f：m=4..12 全部 cnt PASS。
- 违规实例（t+j_(1)+j_(2) > 1，band+pair 过滤）：300 试中 27 个违规，
  **27/27 全 cnt typed_feasible 不可装箱**——引理反证形式实验恒真复现。

  ⟹ LP 的 JJJ 身份行在"可装箱"前提下**恒合法**（razor 带 JJJ 行缺口闭合）。

## 5. 口袋1 迁移（验证完成）

（tv=钉住参数 t 的变量 = 池最小件），即口袋1 LP 规范 JJJ 行恒合法。**JJJ 腿跨口袋闭合。**
