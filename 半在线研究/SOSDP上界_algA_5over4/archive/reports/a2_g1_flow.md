# G1 的"无指派计数刻画"狩猎：判决（agent-2，2026-09-23）

> 代码：code/a2_g1_flow.py（typed 可行性 mask DP 精确判定 + 计数条件族 + 对拍）。
> 方法：角落窗口随机实例（t∈(1/4,1/3)、seniors∈(1−2t,0.75]、juniors∈[t,2t)），m=4..8，
> 30 万例级与全枚举判定对拍。

## 1. 计数条件族（池级、免指派、全部平凡合法——任何装箱自动满足）

- **F0 体积**：Σs + Σpool ≤ m。
- **F1 双边吸收流**：∃x∈[0,b]∩ℤ：β_s ≤ c+a+x ∧ β_j ≤ f+e+(b−x)，
  β_s=#{senior>1/2}、β_j=#{pool>1/2}。（JJJ 箱在窗口内不吸收 >1/2 件：>1/2+2t>1。）
- **F2 伙伴 Hall（双阈值双侧）**：∀L ∈ 值集：#{s≥L} ≤ c+#{s≤1−L}+#{j≤1−L} 且
  #{j≥L} ≤ f+#{j≤1−L}+#{s≤1−L}。
- **F3 JJJ 低位**：#{pool ≤ 1−2t'} ≥ 3d（t'=min pool）。
- **F4 最小 3d 聚合**：sum（最小 3d 池件） ≤ d。

## 2. 一致性统计（36 万例）

| 族 | 失配率 | 失配方向 |
|---|---|---|
| F1 流 | 13.7% | 全过宽 |
| F2 +伙伴 Hall | 5.6% | 全过宽 |
| F3 +JJJ 低位 | 1.6% | 全过宽 |
| F4 +最小 3d 聚合 | 1.1% | 全过宽 |

真实可行率仅 0.15%（窗口内 typed 可行性极稀有——(P) 的又一佐证）。
**每层细化都显著降低失配但永不归零——失配全部"计数满足但不可行"（过宽）。**

## 3. 最小失配反例形态（F4 后仍存活）

最小 m=4、cnt=(1,1,0,1,0,0)：s={0.47, 0.495, 0.605}、pool={0.298, 0.319, 0.36, 0.546}。
- 大 senior 0.605：SS 配谁和都>1、c=0 无 S 箱 ⟹ 必须 SJ；
- 大 junior 0.546：与任意两小件三装和>1 ⟹ JJJ 不可收、e=f=0 ⟹ 必须 SJ；
- **两个被迫件争唯一 SJ 槽** ⟹ 不可行。计数条件（含 F4）全满足 ⟹ 过宽失配。
**这就是 JEL 刻画的双边吸收张力在最小尺寸的原形**：计数看不见"被迫件挤同一槽"。
加"JJJ-禁区件数 ≤ f+e+b"式细化能杀此例，但同构张力在更大尺寸再生（迫使联合
senior 侧 Hall + junior 禁区 + SJ 槽分配纠缠）——**未见收敛迹象**。

## 4. 鬼影点检验（附带快检，任务要求）

洞区鬼影值（m=12..20 分层有理族）对 F1–F4 全条件**满足**（逐一核验：流 ∃x=5..7 区间、
伙伴 Hall 全阈值、最小 3d 和=1≤d）——**Hall 行不能直接杀洞族**，"(W'') 绕过"幻想破灭：
鬼影在计数层完全自洽，杀它们必须靠序/配对结构（这正是现有模板做的事）。

## 5. 判决建议：G1 必须构造性（或 Erdős–Gallai 式理论化）

- **无指派计数刻画不存在**（在池级统计量族内）：F1–F4 阶梯失配率 13.7%→1.1% 但不归零，
  残余是双边吸收的槽位争抢结构（最小反例 §3）。
- **理论化出路（登记）**：typed 装箱 = 阈值图上带型计数的因子问题；对 d=1,c=f=0 核
  （鬼影族形态）它是"阈值图完美匹配 + 颜色度计数 (a,b,e)"——度序列型刻画
  （Erdős–Gallai 式不等式组）在文献结构上存在可能性，值得作为 G1 理论化的候选路线；
  它给的是"值排序坐标上的整值线性不等式组"，恰好可直接作 LP 行（main 的战略发现）。
- **对 LP 路线的关系**：计数条件平凡合法 ⟹ 可无条件加为 LP 行；但鬼影全满足 ⟹ 
  加它们不杀洞。G1 的闭合仍须走 (W'')（规范形构造）或 (P)（不可装箱性）——
  计数捷径不存在。
