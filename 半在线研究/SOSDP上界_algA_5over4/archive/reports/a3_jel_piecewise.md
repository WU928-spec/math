# JEL②：分片线性形式化引理（交换判据的线性性）——严格陈述与证明

> 2026-09-23，agent-3。配套：`code/a3_jel_corner.py`（角落复验）、`code/a3_jel_verify.py`
> （小 n 图解验证）。母文档：JEL.md（主代理骨架）。本文件证明：贪心下降过程是值空间的
> **分片线性/胞腔恒定**过程——路径与输出在线性超平面 arrangement 的胞腔内恒定。

## 1. 设定

固定：物品数 n、箱数 m、容量 1。值向量 x = (x₁,…,xₙ) ∈ ℝⁿ_{>0}。装箱 P = 把 [n] 分进
m 个箱（允许空箱），可行 ⟺ 每箱和 σ_b(P;x) := Σ_{i∈b} x_i ≤ 1。

**贪心下降过程**（JEL.md）：从可行装箱 P₀ 出发，每步取"保持可行且使有序箱和向量
key(P) = (σ 的降序排列) 按字典序严格最小化"的移动（单件移动或两物交换），直到局部极小
P\*（无严格改进的移动）。

## 2. 引理（分片线性/胞腔恒定）

**引理 JEL-LIN**：存在 ℝⁿ 的有限超平面族 H（全为有理系数线性超平面），使得在其
arrangement 的每个开胞腔 C 上，贪心下降过程满足：对所有 x, x′ ∈ C，从同一组合起点
P₀ 出发的下降路径与输出 P\* 的**组合结构**（箱内物品集合划分）相同。

**证明**（逐环）：
1. **箱和线性**：σ_b(P;x) = Σ_{i∈b} x_i 是 x 的（0/1 系数）线性函数。∎
2. **序胞腔内排序恒定**：key(P;x) 是 σ(P;x) 的降序排列。在箱和序超平面族
   H₁ = {σ_b(P) = σ_{b′}(P) : b≠b′, P 可达装箱} 的胞腔内，σ 的两两序关系恒定 ⟹
   存在固定置换 π 使 key(P;x) = (σ_{π(1)}(P;x), …, σ_{π(m)}(P;x))——固定线性函数组。∎
3. **字典序比较 = 线性布尔组合**：对固定组合装箱 P, P′，在 H₁ 胞腔内，
   key(P′) <_lex key(P) ⟺ ∃k ≤ m：前 k−1 分量相等 ∧ 第 k 分量小。相等分量 = 线性方程
   （σ_{π(i)}(P′) = σ_{π(i)}(P)），小 = 线性严格不等式。故判据 = 线性约束的布尔组合。∎
4. **可行判据线性**：P′ 可行 ⟺ ∀b: σ_b(P′;x) ≤ 1——线性不等式。∎
5. **贪心选择恒定**：best = argmin_lex{key(P′)} 由两两比较（每比较 = 3 的布尔组合）决定；
   胞腔内全部比较的真值恒定 ⟹ best 的组合身份恒定 ⟹ 每步移动恒定。∎
6. **路径恒定**：下降路径 = 有限移动序列；归纳：胞腔内第 r 步的候选集（组合）与判据真值
   恒定 ⟹ 第 r+1 步装箱的组合结构恒定 ⟹ 路径与终点 P\* 的组合结构恒定。∎
7. **边界刻画**：胞腔边界 = 某两候选装箱的 key 在某分量相等 ⟺ σ_b(P) = σ_{b′}(P′)
   ⟺ Σ_{i∈b} x_i = Σ_{i∈b′} x_i——**线性方程**（两对/多对物品和相等）。∎

**推论（胞腔数有限）**：H 有限（可达装箱数有限 × 箱对数有限）⟹ 胞腔数有限。
组合输出在胞腔间恒定 ⟹ 极小形组合结构数 ≤ 胞腔数。∎

## 3. 边界=key 相等的精确形式

两候选装箱 P, P′ 的下降优先级交替 ⟺ key(P;x) = key(P′;x)（字典序相等 ⟺ 逐分量等）
⟺ 降序排序后箱和向量逐分量相等 ⟺ **两组箱和多重集相等**。最强表达：
边界超平面 ⊂ {x : 存在两箱划分 b≠b′ 使 σ_b(P;x) = σ_{b′}(P′;x)}——
即"两对物品和相等"的线性超平面。小 n 验证：`code/a3_jel_verify.py`。

## 6. 与 E 树的接口

- **E 树** = 组合指派的显式枚举（内节点 = 换位指派分支，叶 = 组合输出）；
- **JEL 胞腔** = 值空间的线性划分（每胞腔 ⟹ 一个组合输出）。
- 对应关系：胞腔映射到组合输出 ⟹ 存在一个"值空间 → 组合指派"的映射。
  **胞腔比 E 树叶更细或同构**：同一组合输出可对应多个胞腔（值区域内多个线性胞腔
  映射到同一规范形）；E 树叶是组合索引，胞腔是其值空间纤维的划分。
  ⟹ 两者合流的形式：E 树给组合索引，JEL 胞腔给值空间内的构造性证明；
  胞腔数 ≥ E 树叶数（胞腔可能细分同一叶）。实测对照见 §5。
