## 1. 三个立即推论

**(C1) 全体 junior ≤ s₁**：q₁=max J ≤ a_m=s₁（到达递减）。
**(C2) SS 对和=1 ⟹ s₁ ∈ SS 且 SS={s₁,s₂} 且 s₁+s₂=1**：
- 先证 s₁∈SS：若 s₁∉SS，则 s₁∈R ⟹ 1−s₁∈J ⟹ q₁≥1−s₁；又 q₁≤s₁ ⟹ s₁≥1/2。SS={u,v}（u+v=1，u≤v）取 u≥s₂：v=1−u≤1−s₂≤1−s₁≤s₁（s₁≥1/2）⟹ v≤s₁，与 v 是 senior ≥s₂≥s₁ 且 v≠s₁ 矛盾（v≤s₁ ⟹ v=s₁，但 s₁∉SS）。∴s₁∈SS。
- SS={s₁,v}，和=1 ⟹ v=1−s₁。q₁≥1−s_min_R=1−s₂（s₂∈R 若 v≠s₂；v=s₂ 则 s₃）且 q₁≤s₁ ⟹ s₂≥1−s₁（或 s₃≥1−s₁）。又 B1：s₁+s₂≤1 ⟹ **s₁+s₂=1 ∧ v=s₂**。∎
**(C3) 机 1（senior s₁）junior x₁ 满足 p−s₁+MG ≤ x₁ ≤ q₁ ≤ s₁ ⟹ p+MG ≤ 2s₁**（机 1 pair 可行必要条件；p>2s₁−MG 时**窗口空直接死**）。

## 2. 高位 junior 存货引理（核心计数）

**引理 H**：#J 中 ≥ p−s₁+MG 的件数 ≤ **2**（s₁∈SS={s₁,s₂} 形下）。
**证明**：逐一查 J 的三类成员：
1. **j₁**：j₁ ≤ (1−t)/2（j₁+j₂=1−t、j₁≤j₂）。(1−t)/2 ≥ p−s₁ ⟺ s₁ ≥ p−(1−t)/2 ≥ 5/4−t−(1−t)/2 = 3/4−t/2。但 s₁ ≤ s₂ = 1−s₁ ⟹ s₁ ≤ 1/2 < 3/4−t/2（t<1/2）。∴j₁ < p−s₁，**不够格**。
2. **j₂**：j₂ ≥ p−s₁ ⟺ j₂+s₁ ≥ p。j₂ ≤ q₁ ≤ s₁ ⟹ 需 2s₁ ≥ p（C3 的加强）。**j₂ 够格 ⟺ 2s₁ ≥ p**（至多 1 件）。
3. **互补件 1−s（s∈R）**：1−s ≥ p−s₁ ⟺ s ≤ 1−p+s₁ =: τ。danger：p ≥ 5/4−t+MG ⟹ τ ≤ s₁+(t−1/4)−MG。t≤1/3 ⟹ 余量 <1/12。R={s₃,s₄,…}（s₁,s₂ 已入 SS）⟹ #{s∈R : s≤τ} ≤ #{s₃ ≤ s₁+(t−1/4)}：**至多 1 件**（若 s₃−s₁ ≤ t−1/4，则 s₃ 够格；否则 0 件；s₄≥s₃ 不会同时够格除非 s₄−s₁≤t−1/4——归入下文 k 链更强的约束）。
∴ 总存货 ≤ 0+1+1 = **2**。∎

## 3. mon2 升链杀

低端区机器 1..k（k=jj+1≥2，open 段 k≤m−3=nS−2）的 mon2 升链 x₁≤x₂≤…≤x_k=q₁：
- x₁ ≥ p−s₁+MG（机 1 pair）且链升 ⟹ **链上 k 件全部 ≥ p−s₁+MG** ⟹ 需存货 ≥ k。
- 引理 H：存货 ≤2 ⟹ **k ≤ 2**。
- **k≥3（含 open 段 k=3..nS−2 全部）死** ✓。
- **k=2**：链={x₁, q₁}，机 1 拿存货中较小者：
  - 存货须 ≥1：即 2s₁ ≥ p（j₂ 够格）或 s₃ ≤ τ（互补件够格），否则机 1 窗口空死 ✓。
  - fs：q₁ 上机 2（jj=1）：需 s₂+q₁ ≥ p+MG（pair）∧ s₂ ≤ K−q₁（lowzone），K=5(s₁+q₁)/4。
  - s₂ = 1−s₁（C2），q₁ = max(j₂, 1−s₃)。s₂+q₁ ≥ p+MG ⟺ 1−s₁+q₁ ≥ p+MG ⟺ q₁ ≥ p+s₁−1+MG。又 q₁ ≤ s₁（C1）⟹ **2s₁ ≥ p+MG**（同 C3，一致）。
  - 机 1 的 x₁：若取 j₂（2s₁≥p）：则 q₁ 不能也是 j₂ ⟹ q₁=1−s₃：需 1−s₃ ≤ s₁ ⟺ s₃ ≥ 1−s₁ = s₂ ✓（恒真）；且机 2 pair：s₂+1−s₃ ≥ p+MG ⟺ s₃ ≤ 1+p−s₂−MG = 1+p−(1−s₁)−MG = s₁+p−MG ⟸ s₃≤s₂=1−s₁ 需 1−s₁ ≤ s₁+p ⟺ 恒真（p>0）。lowzone：s₂ ≤ K−q₁ ⟺ 4(1−s₁)+4q₁ ≤ 5s₁+5q₁ ⟺ q₁ ≥ 4−9s₁…（细查）。
  - **若取 1−s₃（s₃≤τ）**：q₁=j₂ 或 1−s₄…逐核（待补）。
  - **x₁=1−s₃ 时机 1 pair**：s₁+1−s₃ ≥ p+MG ⟺ s₃−s₁ ≤ 1−p−MG ≤ t−1/4−MG ✓（与 s₃≤τ 相容）。
- **k=2 的 hi 区**（机器 3..nS）：剩余 junior = J ∖ {x₁, q₁}，hi 机窗口 [max(t,p−sᵢ), min(2t,K−sᵢ)] 逐机匹配 + nofit（sᵢ>K−q₁）。**待完成的子分析**：hi 区残量 junior（= {j₁} ∪ {1−s : s∈R, s>s₃ 或 s>τ}）与 hi 机窗口的匹配——机制预期：hi 机 senior 大 ⟹ pair 下界低、但 cap K−sᵢ 小 ⟹ 只能收小 junior，而剩余小 junior（j₁≈(1−t)/2 与最小互补件）在 sliver 下界 j>1−J=t…**此处是草稿唯一待补缺口**。
- **s₁∉SS 情形已在 C2 排除** ✓。

## 4. 结论（条件于 §3 hi 区子分析补全）

全紧结构 ⟹ C2（SS={s₁,s₂} 紧）+ 引理 H（存货 ≤2）⟹ k≤2；k=2 的低端链可排（条件性）但 hi 区匹配预期矛盾 ⟹ 全紧结构非合法角落 ⟹ 可装箱+sliver+razor 角落 = ∅ ⟹ **β 引理成立**。
