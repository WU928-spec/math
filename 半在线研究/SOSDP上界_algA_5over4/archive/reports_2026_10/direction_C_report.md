## 1. 方法（含一个可复用的方法论引理）

### 1.1 截断等价引理（把「全部 n ≤ 12」压成「每个 j 只看 n=j」）

> **引理（截断等价）**　固定分支（Λ=p45 或 Λ=p1）。对任意 i < j：工件对 (i, j) 在某个长度 n ≥ j 的实例上同机 ⟺ 它在长度 **n = j** 的家族里同机。

**证明**　两个方向都靠一条事实：算法对前 j 件的放置只依赖 p1..pj（τ 只由 p1..p5 决定，第 j 步的规则只看当前负载与 p_j）。故 n 实例与它的 j 截断在前 j 件上轨迹完全相同。截断保持：有序 ✓、工件 > 4/15 ✓、C\* ≤ 1（子集仍可装入原来的 4 箱）✓、分支谓词（只看 p1..p5）✓。反向：n=j 家族本身就是合法实例。∎

于是「全家族（n ≤ 12、两分支）的同机对分类」= 对每个 j ∈ {5,…,12}、每个分支，判定 (i, j) 在 n=j 家族是否同机。（n=12 且 Λ=p1 已证为空；n ≥ 13 已证为空。）

### 1.2 判定引擎：同机 MILP（精确 tie-break 语义）+ 宽松语义 + 采样

- **`dc_coloc.jl`**：把「∃ 实例使 (i,n) 同机」编码成一个 MILP：装箱约束（C\*≤1，每件 > 4/15 ⟹ 每箱 ≤ 3 件，**精确**）+ 轨迹约束。两种语义：
  - **`:relaxed`**（宽松并列语义）：并列时允许任意选择 = 一切 tie-break 的超集。**不可行 ⟹ 严格「永不同机」（对任意 tie-break 成立）**。
  - **`:exact`**（ε=1e-4/1e-3 间隔语义）：与真实算法（最小下标 tie-break）一致，至多差一个 ε 薄层。可行点再经**精确模拟器复核** ⟹ 严格显式见证。
- 模型经 150+43 个随机真实实例校验（真实轨迹恒可实现模型；有余量实例零误判），见 `dc_validate.jl`。
- **采样**（`dc_sample.jl`）：每 (分支, n) 配置 3000–30000 个精确模拟实例，给出常见同机对的显式见证与填充/兜底分类。罕见对由 MILP 补刀（如 (9,11)@Λ=p45 采样 0/21858 但 MILP 找到真见证；反之 (9,12) 采样 0/19372 且 MILP 宽松语义不可行 ⟹ 真不变量）。

**严谨性备注**：宽松语义在「ℓ+p = τ 恰取等」的边界上会产生不可实现的伪可行点（本文抓到过多例）；因此一切 NEVER 结论都以「宽松语义不可行（任意 tie-break）」或「手工证明覆盖全部并列情形」为准，不以单边 MILP 为准。

## 3. 新已证不变量（手工证明）

**公共事实**（两分支均成立）：E_5 ∋ 4 恒成立（p4+p5 ≤ Λ ≤ τ），故 **p5 必为填充**。

### I1（填充资格死亡引理，Λ=p45）

> **设 X 为 p5 的接收机，则对一切 j ≥ 6，X ∉ E_j**（X 永远不再是填充合格机）。

**证明**　负载单调不减 ⟹ 第 j 步时 ℓ_X ≥ p_X + p5 ≥ p4 + p5（X ∈ {1,..,4} 故 p_X ≥ p4）。又 p_j ≥ 4/15 > ρ−1 ≥ (ρ−1)(p4+p5)（用到鸽笼界 p4+p5 ≤ C\* = 1，见不变量报告 §1.2 第 2 步）。故
ℓ_X + p_j ≥ p4+p5 + p_j > (p4+p5) + (ρ−1)(p4+p5) = ρ(p4+p5) = τ。∎

**推论**：X 此后只能收**兜底**件；且 (5,j) 同机 ⟺ 第 j 步是「E_j = ∅ 且 X 为最轻（并列时最小下标）」。

### I2（(5,6)、(5,7)、(5,8) 永不同机，Λ=p45；j=8 是精确边界）

> **定理**　Λ=p45 分支中，p5 的接收机 X 在 j ∈ {6,7,8} 步不接收任何工件（无论填充还是兜底）；而 (5,9) 同机存在（见 §5 见证）。

**证明**（计数 + tie-break 论证，覆盖全部并列情形）
对 j ≤ 8 归纳。由 I1，X ∉ E_j，故只可能兜底落入 X，这要求 E_j = ∅ 且 X = argmin（并列取最小下标）。
**基例 j=6**（补齐不变量报告 §1.2 的兜底缺口）：若 X 在放 p6 前为最轻，则任何 E_5 的其他成员 m 都满足 ℓ_m = p_m ≤ p_X < p_X + p5 = ℓ_X（X 是 E_5 中最满者），与「X 最轻」矛盾；故 E_5 = {X}。又 4 ∈ E_5 ⟹ X = 4。此时其余三台 m=1,2,3 有 p_m > τ−p5 且 p_m ≥ p4+p5（X 最轻）；但 Λ=p45 给出 p1 ≤ p4+p5，三式夹逼 ⟹ **p1 = p2 = p3 = p4+p5**。第 6 步：每台机 ℓ+p6 ≥ p4+p5+p6 > τ（同 I1 的估计）⟹ E_6 = ∅，四台全并列 p4+p5，argmin 取最小下标 **M1 ≠ X**。∎（这正是 §5 中 (1,6) 边界见证的轨迹。）
**归纳步 j ∈ {7,8}**：由归纳假设 X 在 6..j−1 步未收件，ℓ_X = p_X+p5。第 6..j−1 步共 j−6 ≤ 2 件工件，至多落在 X 以外的 2 台机上 ⟹ 其余 3 台机中**至少一台 M_k 从未被触碰**，其负载 = p_k ≤ p1 ≤ p4+p5 ≤ p_X+p5 = ℓ_X。若 p_k < ℓ_X，argmin ≠ X；若 p_k = ℓ_X，等式链要求 p_k = p1 = p4+p5 = p_X+p5，从而 p_X = p4 且 k < X（k > X 时 p_k ≤ p_X < p_X+p5 矛盾）⟹ 并列中 M_k 下标更小，argmin = M_k ≠ X。∎
**紧性**：j = 9 时第 6,7,8 步共 3 件工件可分别落到 X 以外的全部 3 台机并把它们推过 ℓ_X（较小下标严格推过），此时 X 可成为 argmin——§5 给出 X=M2 与 X=M4 两个显式构造。∎

> 评注：j=8 ⟺ 「其余 3 台机全部至少被碰一次」所需的最少步数（6,7,8 三步）刚好不够；这是边界的纯计数本质。

### I3（Λ=p1 分支：M1 永远不收填充件）

> **定理**　Λ=p1 分支（τ = ρp1）中，对一切 j ≥ 5：M1 ∉ E_j。即 **M1 上的每件后到工件都是兜底**；特别地 (1,5) 永不同机。

**证明**　ℓ_1 ≥ p1，而 p_j ≥ 4/15 > ρ−1 ≥ (ρ−1)p1（p1 ≤ C\* = 1）⟹ ℓ_1 + p_j > p1 + (ρ−1)p1 = ρp1 = τ。∎

**推论**：(1,j) 同机 ⟺ 第 j 步 E_j = ∅ 且 M1 最轻（需要 M2..M4 全被喂过 p1 之上）。j=5 时 E_5 ∋ 4 ≠ ∅ 故 (1,5) 彻底不可能；j ≥ 6 时可能（§5 见证），j=6 时仅在边界 p1 = p4+p5（此时该实例同时属于 Λ=p45 家族）。

### 与不变量报告（(5,6) 定理）的关系

不变量报告 §1.2 的 (5,6) 证明只处理了「X ∉ E_6」，未处理「E_6 = ∅ 且 X 最轻被兜底」的子情形——本文 I2 的基例补上了这个缺口（且揭示该缺口恰由最小下标 tie-break 守住）。另外 I1 是 (5,6) 的真正推广：不变量报告 §2 已证「(p_j, p_{j+1}) 旋转」对 j ≥ 6 全错，而 I1/I2 给出的是「**p5 的接收机**在 j ≤ 8 步完全免疫」，这是不同维度的正确推广。

## 6. DFF 调查：能否用对偶可行函数啃下 5/4？

### 6.1 框架与一个规范化更正

DFF w: [0,1]→R⁺ 超可加（w(a)+w(b) ≤ w(a+b)，a+b ≤ 1）。对装箱（4 箱、容量 1）有 Σ_i w(p_i) ≤ Σ_{箱} w(箱载) ≤ **4·B(w)**，B(w) = 可行箱（≤3 件、各 > 4/15、和 ≤ 1）的最大 Σw。（任务书里「Σw ≤ C\*」应为「Σw ≤ 4·B(w)·C\*」；w(1)=1 时界为 4。）
证明 makespan ≤ α 的标准形态：失败（某机 > α，z 兜底）⟹ 每台机 > α−z ⟹ Σw(p_i) > 4·B(w) 矛盾。

### 6.2 经典 DFF 逐个评估

- **w(x) = x**：B = 1，Σp ≤ 4。失败 ⟹ Σp > 4(α−z)+z ⟹ α < 1 + 3z/4 ≤ 1 + 3/4·(1/3) = **5/4**（z ≤ 1/3：n ≥ 9 时 >1/3 的工件每箱 ≤2 共 ≤8 个）。这就是已知「统一界」。
- **w(x) = 1{x > 1/2}**（超可加 ✓）：给出计数事实 p5 ≤ 1/2（>1/2 的 ≤4 个），本身不给比值。
- **调和 w = 1/j（x∈(1/(j+1),1/j]）**：可行箱上 B = 3/2（如箱 (0.6,0.4)：1+1/2），Σw ≤ 6，比 w=x 还弱；且机内 Σw ≥ w(机载) 方向不成立（如 {0.45,0.3}：5/6 < 1），无法直接用于失败侧。
- **结论**：任何单一经典 DFF 都不超过 w=x。多个 DFF 的最优组合 = 相应 LP 的对偶 ⟹ 转到 6.3 的 LP 实验。

### 6.3 失败情形 LP（= 最优线性证书/DFF 组合）分层实验

失败情形（z = p_n 兜底）按接收机结构分 (0,0)/(1,0)/(0,1) 三情形（该划分在 6533 片家族上经验完备，未证——见 §8 注）。约束层：**L0** 家族（分支/有序/Σp≤4/[4/15,1]）；**L1** +计数（p5≤1/2、p9≤1/3）；**L2** +**鸽笼 C\* 线性约束（本文新加）**：p4+p5≤1、p5+p6≤1、p6+p7≤1、p7+p8≤1、p7+p8+p9≤1、p8+p9+p10≤1、p9+p10+p11≤1、p10+p11+p12≤1、p4+..+p7≤2、p5+..+p8≤2、n=12 时 p_i+p11+p12≤1 (i≤4)（全部一行可证的鸽笼：前 m 件必有一箱 ≥⌈m/4⌉ 件 ⟹ 最小几件之和 ≤ C\*）；**L3** = L2 + 装箱整数性（MILP）。

**两点决定性观察**

1. **多面体世界（任意线性证书 = 广义 DFF 组合）在 n=10、11 恰好封顶 1.25**：L1 已达 1.25，我新加的整族鸽笼约束**没有带来任何改进**（L2 = 1.25）。1.25 的见证点（(1,0) 情形 p = (0.5833, 0.4167×5, 0.3333×4)；(0,1) 情形 p = (0.5833, 0.5833, 0.3901, 0.3883, 0.3883, 0.3333×5)）满足**全部**线性约束（含鸽笼），但 C\* = 1.0833 / 1.0549 > 1——**它们不可装箱**。换言之：封顶点恰好落在「线性条件全真但整数装箱不成立」的盲区里。
2. **只有整数性能排除这批伪见证**：L3（装箱 MILP）把 n=10 Λ=p45 压到 1.2444（与探索记录 §2p 一致），仍 > 1.2——因为该 MILP 仍看不见轨迹级散差。

### 6.4 DFF 结论（诚实）

- **尺寸型 DFF（含任意线性组合/广义线性证书）不能把 A4c 的界压到 5/4 以下**：多面体松弛最优值恰为 1.25 且被（不可装箱的）见证取到；我枚举的一整族有效线性鸽笼约束也不破防。这是**否定性结论**，但它是干净的：5/4 的墙不在「缺某条线性不等式」，而在**装箱整数性 + 轨迹散差**两处。
- 若要一个「严格 < 5/4」的 DFF 式命题，目前唯一已验证的路径是**整数装箱版 LP = 1.2444**（不是可读证明，是机器最优值；其对偶证书混杂原始装箱变量，不属于尺寸 DFF）。
- 6/5 不在 DFF 可达范围内（已知 1.2 临界实例取等）；它必须由轨迹级论证（引理 O/TL）给出。
