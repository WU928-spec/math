## 2. k=m−2（JJJ 墙）——∀m 统一符号证书（本文新增）

### 2.1 恒等式

k=m−2（jj=nS−1，hi 区 1 台）。在值语言角落行 + A5/LZ/HZ @k=m−2 上，取权重

$$w = (4nS{-}2)\,\text{danger} + 2(nS{-}1)\,(j_1{\ge}t) + 2\,\text{A1}_1 + 2\,\text{squeeze}
+ (nS{-}1)\,\text{srt}_1 + (nS{-}1)\,\text{B1} + 2(nS{-}1)\,\text{B2} + 2nS\,\text{A5}_1
+ 2\!\!\sum_{i=2}^{nS-1}\!\text{A5}_i,$$

其中 A5_i（@k=m−2）：j_{i+1} ≥ p−s_i+MG（i=1..nS−1）。
**三条校验（逐变量手工配平，见 §2.2）**：A^T w = 0；bt^T w = 0（t-全窗口统一）；
bc^T w = **−1/2 − 4(nS−1)·MG < 0**。

### 2.2 逐变量配平账（证明核）

行定义（con 形式 row·x ≤ bc+bt·t）：danger: −p≤−5/4+t；j1>=t: −j₁≤−t；
A1_1: p−j₁−s_{nS}≤0（反序 maximin，B.2）；squeeze: Σs+Σj≤nS−t；srt1: s₁−s₂≤0；
B1: s₁+s₂≤1（SS 存在必要，a≥1）；B2: j₁+j₂≤1−t（JJJ 存在必要，d≥1）；
A5_i: p−s_i−j_{i+1}≤−MG。

- p: −(4nS−2) + 2 + 2nS + 2(nS−2) = 0 ✓（danger + A1_1 + A5_1 + A5_{i≥2}）
- s₁: +(nS−1)(srt1) + (nS−1)(B1) − 2nS(A5_1) + 2(squeeze) = 2(nS−1)−2nS+2 = 0 ✓
- s₂: −(nS−1)(srt1) + (nS−1)(B1) − 2(A5_2) + 2(squeeze) = 0 ✓
- s_i (3≤i≤nS−1): −2(A5_i) + 2(squeeze) = 0 ✓；s_{nS}: −2(A1_1) + 2(squeeze) = 0 ✓
- j₁: −2(nS−1)(j1>=t) − 2(A1_1) + 2(nS−1)(B2) + 2(squeeze) = 0 ✓
- j₂: 2(nS−1)(B2) − 2nS(A5_1) + 2(squeeze) = 0 ✓
- j_r (r≥3): −2(A5_{r−1}) + 2(squeeze) = 0 ✓；am、q₁ 无涉 ✓
- bt：danger +1·(4nS−2)、j1>=t −1·2(nS−1)、squeeze −1·2、B2 −1·2(nS−1)：
  (4nS−2) − 2(nS−1) − 2 − 2(nS−1) = 0 ✓
- bc：danger −5/4·(4nS−2) + squeeze nS·2 + B1 (nS−1) + B2 2(nS−1) + A5 −MG·(2nS+2(nS−2))
  = −5(2nS−1)/2 + 2nS + 3(nS−1) − 4(nS−1)MG = **−1/2 − 4(nS−1)MG < 0** ✓
