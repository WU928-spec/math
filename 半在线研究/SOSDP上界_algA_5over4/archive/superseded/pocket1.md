# 口袋 1 攻击笔记（n ∈ [2m+1, 3m−1]，最闲机恰 2 件）

**范围：只证 m ≥ 4**（用户指令：m=3 不在范围内）。所有"对 m≥4 一致"或"逐 m≥4"的论证有效。

记号：OPT=1；fallback 事件，t = 最后到达任务（= 全局最小任务）；最闲机 M₀ = {x, y}，x ≤ y，ℓ₀ = x+y，C_A = ℓ₀ + t；所有机器负载 > K − t，K = 5L/4，L = p_m + p_{m+1} ≥ 2t。
危险区：ℓ₀ > 5/4 − t（否则 C_A ≤ 5/4 直接成立）。硬窗口 t ∈ (1/4, 2/5]。

## 事实库（全部 sympy 可验 / 已验）

- **F1** x ≥ t（t 是最小任务，x ≠ t）。故"恰 2 件"即 t ≤ x ≤ y。
- **F2** y > 1 − 2t ⟹ 已闭（C_A = x+y+t ≤ 2(1−2t)+t = 2−3t < 5/4 当 t > 1/4）。**故下设 y > 1 − 2t（"y 是大任务"）。**
- **F3** 3 任务 OPT 箱中每件 ≤ 1 − 2t（箱内两小件各 ≥ t）。
- **F4** 大任务（>1−2t）只能在 1 或 2 任务箱中。设 OPT 箱型 (b₁, b₂, b₃)：b₁+b₂+b₃ = m，b₁+2b₂+3b₃ = n ⟹ b₁+b₂ = 3m − n − b₃... 修正：b₂ = n − m − 2b₃，b₁ = 2m − n + b₃。非三箱数 b₁+b₂ = m − b₃ ≤ m − (n − 2m) = 3m − n（用 b₃ ≥ n − 2m，因 b₂ ≤ (n−b₃)/2 … 需验证：b₃ ≥ n − 2m 来自 b₁ ≥ 0 ⟹ b₃ ≥ n − 2m ✓）。
- **F5** 大任务数 ≤ b₁ + b₂ ≤ 3m − n。
  - n = 3m−1 ⟹ 至多 **1 个大任务**（= y 本身）。✓（已 sympy 验 b₃ ≥ m−1）
- **F6** 每台其他机器负载 > K − t ≥ 3t/2（L ≥ 2t）。

## 重大纠错（2026-09-19 会话2）

**M₀ 的件数**：fallback 前 M₀ = {x, y}（2 件），t 落下后 M₀ = {x, y, t}（3 件）。
因此 n=3m−1 时其他机器任务总数 = n−3 = 3m−4（不是 3m−3）。
- 件数分布：c₂ 台 2 件 + c₄ 台 4 件 + 其余 3 件，满足 c₂ = c₄+1（Σ(n_j−3) = −1，无单子机）。
- **推论：n ≤ 3m−1 时其他机器中必有 2 件台**（(n−3)/(m−1) < 3 ⟹ 鸽巢）——之前 LP 里纠结的 a=0 死角**不存在**。
- **★★'（加强版）**：S ≤ m−1−x−t+z（x 和 t 各占一个 OPT 三箱，其搭档分别 ≤ 1−x、≤ 1−t；同箱时亦然）。
- 体积击杀链修正后结论不变：n=3m−1 ⟹ (3m−4)t ≤ S ≤ m−4t ⟹ **t ≤ 1/3**（sympy 已验）。
- 旧 LP（lp_probe/lp_dual）的分布求和 = 3m−3，实际建模的是 n=3m（已由 K3 §3 闭合），对 n=3m−1 需用修正卡片机 lp_cards.py。其证书模式（权重 (4m−3)/(4(m−1)) 等）预期可迁移。

### 分支 N-k：按 n 值（n = 3m−1, 3m−2, …, 2m+1）

**N-(3m−1)（最紧，先行）**【sympy 已验】箱型方程 b₁+b₂+b₃=m, b₁+2b₂+3b₃=3m−1 的唯一非负整数解是 **(b₁,b₂,b₃) = (0,1,m−1)**：恰一个 2 任务箱、无 1 箱。结合 F5：唯一大任务 y 必在该 2 箱中，箱 = {y, z}，z ∈ [t, min(1−y, 1−2t)]。

  - 机器侧：M₀={x,y}，其余 m−1 台共 3m−3 件，全 ≤ 1−2t（F3+F5）。
