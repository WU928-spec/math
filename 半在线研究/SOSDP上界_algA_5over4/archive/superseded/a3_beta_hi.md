## §5.1 k=1（jj=0）：纯代数杀

k=1 ⟺ 机 1 hi：s₁ > K−q₁。fs ⟹ 机 0 取 q₁，机 0 pair 需 **q₁ ≥ p−s₀+MG**。
- 机 1 hi：s₁ = 1−s₀（C2：SS={s₀,s₁} 紧）> (5s₀+q₁)/4 ⟺ **q₁ < 4−9s₀**。
- 合：p−s₀+MG ≤ q₁ < 4−9s₀ ⟹ p+MG < 4−8s₀。
- C3：s₀ ≥ (p+MG)/2 ⟹ 8s₀ ≥ 4p+4MG ⟹ p+MG < 4−8s₀ ≤ 4−4p−4MG ⟹ **p < 4/5**。
- danger：p > 5/4−t ≥ 5/4−1/3 = **11/12 > 4/5** ✗ 矛盾。**k=1 死**。
（与 a3_beta_hi.md 旧版 k=1 推导一致；数据背书：k=1∧q₁ 高档在 15438 例中 0 例。）

## §5.2 k=2（jj=1）：三情形全杀

机 0 的 x₀ 必须是高档 junior（pair+链）；候选三类核查：
j₁ 永不高档（H′ 类 1）、t 永不高档、**互补件在 k=2 全不高档**
（k=2 ⟹ R∩low=∅；R∩hi 互补件由 nofit 封死：s>K−q₁≥τ，H′ 类 3，agent-1 复核 VALID）
⟹ **机 0 的唯一候选 = j₂（需 j₂ ≥ p−s₀+MG）**。按 q₁ 身份分格：

**情形 A（q₁=j₂ > 1−s₂）**：j₂ 为唯一高档（j₁/t/互补件全排除）且被 fs 钉去机 1
⟹ 机 0 窗口空 ✓ 死。

**情形 B（q₁=1−s₂ > j₂，j₂ 高档）**：nofit（机 2=s₂ hi）：s₂ > K−q₁ = (5s₀+q₁)/4
⟺ 4s₂ > 5s₀+1−s₂ ⟺ s₂ > s₀+1/5 ⟹ q₁ = 1−s₂ < **4/5−s₀**。
而 j₂ 高档：p−s₀+MG ≤ j₂ ≤ q₁ < 4/5−s₀ ⟹ p+MG < 4/5 ✗ 与 danger p>5/4−t≥11/12 矛盾。**死**。

**情形 B′（q₁=1−s₂ > j₂，j₂ 不高档）**：机 0 无候选（j₂ 不高、互补不高、j₁/t 不高）
⟹ 窗口空 ✓ 死。

**情形 C（边界 j₂=s₀ 或 s₂=s₁，q₁=s₀）**：v2.1 条件钉 q₁=s₀。
- C1 钉 j₂=s₀（τ-杀法，agent-1 终审 salvage 版）：j₁ = 1−t−j₂ = 1−t−s₀；窄带 j₁≥t
  ⟹ **s₀ = 1−2t**（双向夹死），故 s₁ = 1−s₀ = 2t、s₂ ≥ s₁ = 2t（q₁=max 只给 s₂≥2t，
  可严格大于——不需 s₂=s₁）。互补件高档阈值
  **τ = 1−p+s₀−MG < (t−1/4)+s₀−MG = 3/4−t−MG < 2t ≤ s₂**
  （首步 danger p>5/4−t；第三步 3/4<3t ⟸ t>tlo>1/4）⟹ s∈R 全 s≥s₂>τ ⟹
  **互补件 1−s₂ 及一切互补件不够格**（H′ 类 3 同法）；又 j₂ = s₀ = q₁ 被 fs 钉在机 1
  ⟹ **机 0 窗口空死**——与 s₂ 是否等于 s₁ 无关（反例形 t=0.28, s₀=0.44, s₁=0.56,
  s₂=0.70 同死），t=0.3 边界亦覆盖（仅用 t>1/4）。
- C2 钉 s₂=s₁：j₂<s₀ 时 j₁=1−t−j₂ > 1−t−s₀ ≥ t ⟹ 同钉 s₀=1−2t；s₁=s₂=2t 同值，
  机 1 low（s₀≥2/5）与机 2 hi（s₀<2/5）相斥 ✓ 空（边界落 k≥3）。

**∴ k=2 全灭；hi 区匹配无一例到达。**
