## 1. 证明（五步链）

**步骤 1（紧性）**：可装箱 ⟹ J = 1−t 且 SS 对（们）和=1 且 SJ 互补。
**步骤 2（大 senior 钉天花板）**：设 s ≥ J。由 B3，s ≤ 1−t = J ⟹ **s = 1−t = J**。即所有 ≥J 的 senior 恰好 = 1−t，且被迫进 SS。
**步骤 3（伴侣逼迫 t=1/3）**：≥J 的 senior s=1−t 的 SS 伴侣 x = 1−s = **t**。senior 非小引理要求 x ≥ 1−2t ⟹ **t ≥ 1−2t ⟺ t ≥ 1/3**。razor t ≤ 1/3 ⟹ **t = 1/3**。
  - **t < 1/3 情形直接死**：伴侣 x = t < 1−2t 非 senior ⟹ SS 不可成 ⟹ 不可装箱。∎（**t≈5/16 楔死于此步**——彼时 J=2t<1−t，与步骤 1 的 J=1−t 亦矛盾。）
**步骤 4（全体 junior 钉 t）**：t = 1/3 ⟹ s_{nS}=2/3、x=1/3。s₁ ≤ x = 1/3 且 s₁ ≥ 1−2t = 1/3 ⟹ **s₁ = 1/3 = a_m**。到达递减 **q₁ ≤ a_m = 1/3**；窄带 j ≥ t = 1/3 ⟹ **全体 junior = 1/3**。
**步骤 5（机 1 pair 矛盾）**：senior s₁=1/3 的机器 junior = 1/3（唯一值）⟹ 负载 2/3。pair 要求负载 > p+MG ⟹ p ≤ 2/3−MG；danger：p > 5/4−t = 11/12 > 2/3 ⟹ **矛盾**。∎

## 2. 各 #{s≥J} 分格的统一覆盖（不再需要分支）
