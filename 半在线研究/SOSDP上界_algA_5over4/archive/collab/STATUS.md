## 一、已证（sympy 或 LP 验证过，代码在 code/）

**归约与通用工具**
- best-fit 放入 ≤ K ≤ 5OPT/4（L ≤ OPT 鸽笼）⟹ 只处理 fallback 事件。
- Lemma A：C_A ≤ 1 + t(1−1/m)，闭合 t ≤ m/(4(m−1))。Lemma B：t ≤ 2/5。
- t > 1/4 ⟹ 箱 ≤ 3 件 ⟹ n ≤ 3m。三分支：最闲机件数 = 1（口袋2）/ 2（口袋1）/ ≥3（口袋3）。
- ★★gen：S ≤ m − ℓ₀ − t（任意 M₀ 通用）；★★sgl：S ≤ m−1−t（单子机独占箱）。

**口袋 1（最闲机恰 2 件）**
- n = 3m：闭合（全 3 箱 ⟹ 件 ≤ 1−2t ⟹ C_A ≤ 2−3t < 5/4）。
- n = 3m−1 与 n ≤ 3m−2 中"存在非大 2 件台"：统一证书 C_A ≤ (5m−2)/(4m−1) < 5/4
  （权重法：2 件台权 (m+2)/3，其余各 1；verify_proof.py 全 PASS）。
- 子情形 B（所有 2 件台含大任务）：**闭合**（§2c 引理 F/G 全局推论）。

**口袋 2（最闲机 = 单子机 {p_i}）**
- 情形 (c) 消除：fallback 到单子机 ⟹ p_i + p_{m+1} > K（t ≤ p_{m+1}）——单子机从首个后至任务起就放不下。
- t > 1/3 段：闭合（危险 ⟹ 巨大任务独占箱 b1 ≥ 1+sg 与容量矛盾）。
- t ≤ 1/3 段：m=4、5 闭合。
- 分片引理：t ≤ OPT/4 ⟹ C_A ≤ OPT+t ≤ 5/4；L ≥ 4t ⟹ C_A ≤ OPT(1+t/L) ≤ 5/4。
- rank 引理：i < m；rank 上界：i < 4m/5。
- 独占箱增殖：危险区 p_j ≥ p_i 的初始任务在 OPT 独占箱。
- distinct-bin：他机初始两两不共箱（t < 3/8）。
- rest 体积界：p_i < 1 − t/(m−i)。
- **残留角落：已闭合（引理 T''，会话 21）**：按他机件数三分——(i) 1件不可能；(ii) 2件 =
  best-fit 第一步序约束 + 机器对和 + danger 的计算引理+消融（pairing_feasible.py q1_target
  全枚举 m=6..10 全 t INFEASIBLE）；(iii) ≥3件 体积矛盾（负载>1 ⟹ OPT>1）；(iv) ≥4件（>5/4≥K）。
  写入 proof.md §6，verify_proof 代数骨架 6 项 PASS。详见 pocket2.md 会话 19–21。

**口袋 3（最闲机 ≥ 3 件）**

- 残留：单子机/含大 2 件台卡片——**闭合**（§2c 引理 F/G 全局推论）。
