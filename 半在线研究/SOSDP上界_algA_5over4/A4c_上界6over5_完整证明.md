# $m=4$ 半在线调度（SOSDP）上界 $6/5$：算法 A4c 的完整证明

> **主定理**：4 台机器、工件非增序到达的半在线调度问题（SOSDP）上，算法 **A4c** 的竞争比不超过 $6/5$（严格小于 LPT 的 $5/4$），且临界实例精确取等 ⟹ **A4c 的竞争比恰为 $6/5$**。
>
> **证明形态**（诚实分级）：主体为可读手证（化约引擎 + 逐层闭合）；唯一取等点（razor 层）用 **108 张精确有理对偶证书**封底（非浮点）；若干大余量环节辅以**双求解器一致**的计算背书（余量 $\ge 0.005$，比浮点容差 $\sim10^{-6}$ 高三个数量级）。所有计算成分均可复现（§12）。
>
> 工作规范与协作史见 `AGENTS.md` / `BOARD.md` / `m4_候选算法探索记录.md`；本文是 AGENTS.md §4.2 意义上的干净终稿（作废内容一律外置，不贴补丁）。

## 0. 记号、常数与代数恒等式

- 机器 $M_1,\dots,M_4$；工件 $p_1\ge p_2\ge\cdots\ge p_n$（问题设定：工件按非增序到达）。最优 makespan 归一化 $C^*=1$。
- 常数 $\rho=\dfrac{1+\sqrt{37}}{6}=1.1804604\ldots$（m=3 最优竞争比，CKK 2012）；$6/5-\rho=0.0195\ldots$。
  **代数恒等式**：$3\rho^2=\rho+3\iff\rho^2=1+\dfrac\rho3$；$\dfrac1\rho=\dfrac{\sqrt{37}-1}{6}=0.84713\ldots$。目标界常记 $\dfrac65$。
- 安全线 $\tau=\rho\Lambda$，其中 $\Lambda=\max\{p_1,\ p_4+p_5\}$。$\Lambda\le1$：$p_1\le1$ 显然（$C^*=1$）；$p_4+p_5\le1$ 由鸽笼（前 5 件装入 4 个最优箱、必有两件同箱，而同箱两件之和 $\ge p_4+p_5$）。故 $\tau\le\rho<\tfrac65$。
- $z:=p_n$（最小件）；除另述外，$\ell_m$ 指**放 $z$ 之前** $M_m$ 的负载（即前 $n-1$ 件的分配）。
- **填充 / 兜底**：步 $j$ 的合格集 $E_j=\{m:\ell_m+p_j\le\tau\}$；$E_j\ne\varnothing$ 时把 $p_j$ 放到 $E_j$ 中**最满**的机器（并列取下标小者）——填充；$E_j=\varnothing$ 时放到**最轻**机（argmin，并列取下标小者）——兜底。

## 1. 问题、算法与主定理

### 1.1 问题与已知结果

SOSDP（semi-online scheduling with decreasing processing times）：$m$ 台同构机，工件以非增序逐个到达，到达即指派（不可迁移），目标最小化 makespan。

- **LPT**（每件放当前最轻机）竞争比 $=5/4$（$m=4$ 且紧）。
- $m=3$ 的最优竞争比 $=\rho$，由 Algorithm A3 达到（CKK 2012）；A3/A4c 都是"安全线 + 最满合格/最轻兜底"族的单参数算法，运行时间 $O(n)$（输入已排序；$\tau$ 只算一次，每件 $O(m)=O(1)$）。
- $m=4$ 下界：SSW 型对抗族 $(1^3,r^3,s^3)$（$r=\frac{2+\sqrt{37}}{11}=0.7348\ldots$、$s=\frac{13+\sqrt{37}}{33}=0.5783\ldots$、OPT $=1+r$）⟹ 任何算法竞争比 $\ge\rho$（详见 §10 的对偶闭环）。

### 1.2 算法 A4c

```
输入：p1 ≥ … ≥ pn（在线到达）。常数 ρ = (1+√37)/6。
1. p1..p4 分别放上 M1..M4。
2. 安全线 τ ← ρ · max{p1, p4+p5}（n ≥ 5；n ≤ 4 时平凡）。
3. 对 j = 5..n：
     E ← { m : ℓ_m + p_j ≤ τ }
     若 E ≠ ∅：放 E 中负载最大者（并列取下标小者）   —— 填充
     否则：    放负载最小者（并列取下标小者）          —— 兜底
```

### 1.3 主定理与证明总览

**定理 1（主定理）**。对任意实例，$C_{A4c}\le\dfrac65\,C^*$。

**定理 2（紧性）**。实例 $p=(0.6,\ 0.5,\ 0.5,\ 0.4^{\times3},\ 0.3^{\times4})$（$C^*=1$）上 A4c 的 makespan $=1.2$ 精确（逐步重放见 §8.1）⟹ A4c 的竞争比恰为 $6/5$。

**定理 1 的证明地图**（各节即各部件，依赖关系线性）：

| 部件 | 内容 | 形态 |

| §2 反例框架 | 极小反例 ⟹ 只剩 $z$ 兜底 + $z\in(4/15,1/3]$ + $6\le n\le12$；目标收窄为**引理 M**：$z$ 兜底 ⟹ $\min_m\ell_m\le\frac65-z$ | 手证 |

## 2. 反例框架与初等闭合

**极小反例框架**。设存在比值 $>6/5$ 的实例，取 $n$ 最小者。删去 $z$ 后 A4c 在前 $n-1$ 件上的 makespan $\le\frac65\,C^*_{n-1}\le\frac65$（$C^*_{n-1}\le C^*=1$）⟹ **放 $z$ 前各机负载 $\le6/5$**。比值 $>6/5$ ⟺ 放 $z$ 的接收机（某台最轻机）终载 $>6/5$。

**引理 2.1（填充情形闭合）**。若 $z$ 是填充，则接收机终载 $\le\tau\le\rho<\frac65$；其余机 $\le6/5$（极小性）⟹ makespan $\le6/5$，不失败。$\square$

**引理 2.2（$z\le4/15$ 闭合）**。$\min_m\ell_m\le\frac14\sum_{i<n}p_i\le\frac{4-z}{4}=1-\frac z4$（$\sum p\le4C^*=4$）⟹ 终载 $\le1+\frac{3z}{4}\le\frac65\iff z\le\frac4{15}$。$\square$

**引理 2.3（$z>1/3$ 不可能）**。设 $z>\frac13$：每件 $>\frac13$ ⟹ 每箱至多 2 件 ⟹ $n\le8$。设 $k$ = 1-lump 机数（只含初始件的机器，其件 $>\frac65-z$ 独占一箱，见 D3）。逐 $k$ 枚举（$k=0$：$n-1\ge8$；$k=1$：$n\le7$ 且可行计数的 1-lump 机数均 $\ne1$；$k=2$：$n\le6$ 与计数 $\{2,1,1,1\}$ 的 $k=3$ 矛盾；$k\ge3$：$n\le5$）全部矛盾。$\square$（逐条展开见 `TL_proof_attempt.md` §5.2。）

**推论（失败区定型）**。失败实例必满足：$z$ 兜底；$z\in(\frac4{15},\frac13]$；每件 $>\frac4{15}$ ⟹ 最优箱每箱至多 3 件（4 件 $>\frac{16}{15}>1$）⟹ $n\le12$；$n\ge6$（步 5 恒为填充：$p_4+p_5\le\Lambda<\rho\Lambda=\tau$ ⟹ $M_4\in E_5\ne\varnothing$）。

**引理 M（核心目标）**。$z$ 兜底 ⟹ $\min_m\ell_m\le\dfrac65-z$。
充分性：极小反例中其余机放 $z$ 前已 $\le6/5$；$\min+z\le6/5$ ⟹ 终 makespan $\le6/5$。$\square$

**反证假设**（此后通篇）：
$$H:\quad \text{放 }z\text{ 前四台机器负载全部}>\tfrac65-z,$$
在 H 下推出与 $C^*=1$ 的矛盾即证得引理 M。（注：直观的强化版"TL：三台最轻机负载之和 $\le3.6-3z$"**为假**——反例 $p=(\frac13)^{12}$，三轻之和 $\frac83>\frac{13}5$；min 版才是 6/5 真正需要的命题。TL 的作废不影响本文任何部件。）

## 3. 化约引擎与五层化约（手证主线）

### 3.1 引擎：六条通用事实（均严格）

H 下，记 $S=\sum_{i<n}p_i$、$\sigma=4-\sum p$（总体积余量）：

- **(D1) 体积余量**：$S>4(\frac65-z)=\frac{24}5-4z$ ⟹ $\sigma<3z-\frac45\le\frac15$。
- **(D2) z-tight 箱**：每个最优箱 slack $\le\sigma<z$ ⟹ 负载 $>1-z$ 且不能再容纳任何件（件均 $\ge z$）。
- **(D3) 独占箱**：1-lump 机（仅初始件）的件 $>\frac65-z$ ⟹ 该件在最优装箱中独占一箱（箱伴 $\ge z$ ⟹ 和 $>\frac65>1$）。
- **(D4) 3-lump 箱上界**：3-lump 箱中每件 $\le1-2z$（另两件各 $\ge z$）。
- **(D5) 接收机两件的去向**：接收机 $=\{p_M,p_i\}$（$M\le4<i$）且 $p_M+p_i>\frac65-z$：同箱 ⟹ 该箱恰为 2-lump 箱；拆箱 ⟹ 两件不能都在 3-lump 箱（各 $\le1-2z$ ⟹ 和 $\le2-4z<\frac65-z$，因 $z>\frac4{15}$）。
- **(D6) 2-lump 机拆箱原理**：2-lump 机 $\{x,y\}$（$x+y>\frac65-z$）的两件不能同处一个 3-lump 箱（$\le1-z<\frac65-z$）⟹ 每台 2-lump 机要么两件自组 2-lump 箱，要么拆入不同箱且至多一件落 3-lump 箱。
- **(D6′)（6/5 目标加强版）**：2-lump 机两件若分处**不同** 3-lump 箱，和 $\le2-4z<\frac65-z$（$z>\frac4{15}$）⟹ **每台 2-lump 机至少一件落在 2-lump 箱**（全域 $z>\frac4{15}$ 生效）。

**引理 A（最重机 $\ge4$ 件 ⟹ 闭合）**。若某台机在放 $z$ 前有 $\ge4$ 件：其负载 $\ge4z$，故
$$\min_m\ell_m\le\frac{S-4z}{3}\le\frac{4-5z}{3}\le\frac65-z\iff z\ge\frac15\quad✓\ (z>\tfrac4{15}).\ \square$$
此后可设**每机至多 3 件**。

### 3.3 关于引理 B（接收机 ≤2 件）的地位

化约引擎的每条击杀都是"存在某机负载 $<\frac65-z$ 违反 H"型，**与哪台机是 $z$ 的接收机无关**；唯一曾以接收机件数为前提的是层 (4) 手证内部的结构假设，而层 (4) 的终端模型本就不含接收机约束 ⟹ 其 sup 天然覆盖接收机 3 件的变体。结合 §4 的全形状地图（含 3-lump 机的形状全部 $\le6/5$，唯一取等者为 razor 序并被证书封死），**引理 B 从前提中删除**（全形状分类兜底，非承重墙）。

## 5. 层 (1)（$n=8$、$\{2,2,2,1\}$、箱 $(3,2,2,1)$）：纯手证闭合

设 H。$B_0=\{s\}$ 为 1-lump 箱（$s>\frac65-z$，D3）。三台 2-lump 机 $R_1,R_2,R_3$；$M_s$ = 闲置机（1-lump 机）。$z\le3/10$ 已由体积法封死（§3.2）；设 $z>\frac3{10}$。由 (D6′) 每台 2-lump 机至少一件落在两个 2-lump 箱之一；3-lump 箱的三件来自不同机（D6）。

**情形 (A)：3-lump 箱 $=\{u_1,u_2,u_3\}$（每机一件）。** $u_i\le1-2z$（D4）⟹ 其伴侣 $v_i>\frac65-z-u_i\ge\frac15+z$。三件伴侣与 $z$ 共四件装两个 2-lump 箱，鸽笼 ⟹ 某箱装两件 $v_j,v_k$：$v_j+v_k>\frac25+2z>1$（$z>\frac3{10}$）✗。$\square$

**情形 (B)：3-lump 箱 $=\{u_1,u_2,z\}$。** $R_3$ 两件都在 2-lump 箱；$v_1,v_2$ 不能同箱（$v_1+v_2>\frac75-z>1$，因 $u_1+u_2\le1-z$）⟹ 摆法 $\{v_1,u_3\},\{v_2,v_3\}$（对称不另列）。两条轨迹引理杀灭本情形：

**引理 (B0)（初始件结构）**。$v_1,v_2>\frac15+z>\frac12$ 且**必为初始件**（若 $v_i$ 是后续件 $p_j$（$j\ge5$），则 $p_1..p_5$ 五件皆 $\ge p_5\ge v_i>\frac12$，两两不相容需 5 箱 ✗）⟹ $R_3$ 的初始件 $p_{m_3}$ 与 $v_1$ 或 $v_2$ 同箱 ⟹ $p_{m_3}\le1-v_i<\frac12$。$\square$

**引理 (B1)（$p_5\to R_3$ 不可能）**。步 5 必为填充（§2 推论）。若 $p_5\to R_3$：步 5 的"最满合格"规则 ⟹ 凡 $p_m+p_5\le\tau$ 的 $m$ 都有 $p_m\le p_{m_3}$；(B0) 给 $v_i>p_{m_3}$ ⟹ $v_i+p_5>\tau$（$i=1,2$）。但装箱把 $p_5$ 配入某 2-lump 箱与某 $v_i$ 同箱 ⟹ $v_i+p_5\le1$。合：$\tau<1$ ⟹ $\Lambda\le\tau/\rho<\frac1\rho=0.84713$。而 $s$ 是初始件 ⟹ $s\le p_1\le\Lambda$，H 给 $s>\frac65-z$ ⟹ $z>\frac65-\frac1\rho=0.35287>\frac13$，与 $z\le\frac13$ 矛盾。$\square$

**引理 (B2)（$p_5\to R_1$/$R_2$ 不可能）**。设 $p_5\to R_1$（$R_2$ 对称）。$v_1>\frac12>1-2z$ 进不了 3-lump 箱 ⟹ $R_1$ 落 3-箱的件是 $p_5$ ⟹ $p_5\le1-2z$。$R_3$ 的后续件 $p_{j_3}\in\{p_6,p_7\}$ 满足 $p_{j_3}\le p_5\le1-2z$；H 要求
$$p_{m_3}>\tfrac65-z-p_{j_3}\ge\tfrac65-z-(1-2z)=\tfrac15+z>\tfrac12\quad(z>\tfrac3{10}),$$
但 (B0) 给 $p_{m_3}\le1-v_i<\frac12$。矛盾。$\square$

**定理（层 (1) 闭合）**。$z\le3/10$ 体积法；$z>3/10$：情形 (A) 鸽笼杀；情形 (B) 中 $p_5$ 的落点只有 $R_3$（(B1) 杀）、$R_1/R_2$（(B2) 杀）或 $M_s$（与闲置矛盾）。引理 M 成立。$\square$

（复核注记：case 划分按 $z$ 是否在 3-lump 箱穷举，完备；(B1)(B2) 是全文仅有的两处"轨迹级"论证之一——它们杀掉的正是 §4 地图里 $\sup=11/9$ 的伪见证形状 $[1,2,2,2]$（$M_1$ 闲置型）。）

## 6. 层 (2)（$n=9$、$\{3,2,2,1\}$、箱 $(3,3,2,1)$）：纯手证闭合

**定理**。层 (2) 中引理 M 成立。

*证明*。设 H。$z\le3/10$ 由体积法封死（§3.2）。设 $z\ge\frac3{10}$。$z$ 不在 2-lump 箱（否则两台 2-lump 机只剩一格，必有一台两件全落 3-lump 箱，被 (D6′) 杀）。故 2-lump 箱的两格全归机器：两台 2-lump 机由 (D6′) 各出一件 $x_1,y_1$ 组成该箱，其伴侣 $x_2,y_2$ 落在 3-lump 箱 ⟹ $\le1-2z$（D4）。于是
$$x_1>\tfrac65-z-x_2\ge\tfrac15+z,\quad\text{同理 }y_1>\tfrac15+z\ \Longrightarrow\ x_1+y_1>\tfrac25+2z\ge1\quad(z\ge\tfrac3{10}),$$
与容量矛盾（$z=3/10$ 处严格大于同样矛盾）。$\square$

且 $a=\frac1{1+r}=x$ 恰为 SSW $m=3$ 对抗参数（$x=\frac{7-3c}{6}$），三处恒等式互相咬合。

**推论**。
- A4c 在下界对抗族上的比值**恰好** $=\rho$（下界值）——算法与最难实例的对偶咬合；
- $m=4$ SOSDP 的最优竞争比 $\in[\rho,\ \frac65]$（区间宽 $0.0195$）：下界 = 对抗族，上界 = 本文 A4c（razor 紧）。
- **开放问题**：收口 $[\rho,\frac65]$（更强算法压上界 / 更强对抗抬下界）。两层吸引子图景：$\rho$（层 (3) 紧族 + 填充情形）与 $\frac65$（razor 唯一取等）。
