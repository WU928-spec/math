# E-nec 裁决报告：必要条件行替换固定分组行的 LP 强度（agent-4，2026-09-23）

实验代码 `code/a4_enec.py`（build_enec：rows_fixed 去 SS/SJ/JJJ/JJ caps + 必要条件行族）。

## 0. 行族合法性设计（brief 风险点落实）

值排序指标只在有 w.l.o.g. 依据处使用：**senior 全序由 srt 行给（合法），junior 全局值序无依据**
（hi 区 junior 与低端 junior 无已知序——fs 只给 j≤q1）。因此：

| 族 | 实现 | 序依据 | 合法性论证 |
|---|---|---|---|
| ①XSS（a 条） | s_i+s_{2a−1−i}≤1 | srt senior 全序 ✓ | ∃a 对≤1 ⟹ 最小 2a 极端配对逐对≤1（重排） |
| ⑤V XVOL（1 条） | Σj+t+Σ_{i<b}s_i ≤ b+d+e+f | 无需 junior 序 ✓ | 池装入 b+d+e+f 箱；SJ senior 和≥最小 b 个（srt） |
| ⑤B XBIG（≤1 条） | s_{nS−1−(c+a+b)}≤1/2 | srt ✓ | 大 senior 数 ≤ c+a+b（每箱至多一件>1/2） |
| ②③④ 强形 | **未实现** | 需 junior 全局序 ✗ | 留待序结构引理；本版用 ⑤V/⑤B 替代 |

注：②③④ 的 junior 值序强形（最小 3d 聚合/最小 2e 反序对/SJ-Hall）是强度损失的最大嫌疑——见 §3。

## 1. 洞族命运（razor/鬼影洞，基底=无保序无 caps 隔离计数行）

**0/20**（m=12..20 全部一步洞）：三族新行单独（无保序）一个洞都杀不死——
鬼影点全部满足 XSS/XVOL/XBIG。**无路线级利好**（已 BOARD FLAG）。
换言之：对洞族，计数必要条件行的杀伤力严格弱于保序（ord）行。

## 2. 保持率（基底含保序；基线=fast 管线全闭）

m=4..14 全 cnt 全 k（1244 情形）：**保持 779/1244 = 62.6%**。
强度损失 465 处全部集中在 razor 带形态：cnt=(1,m−3,0,1,e,0) 与 (2,m−5,0,1,e,0)
（a≤2, c=0, d=1, e∈{0,1}）——正是固定身份 SJ/JJJ 行承重的区域。
非 razor 形态（c≥1 或 d≥2 或 a≥3）几乎全保持。

## 3. 承重行定位（消融）

- XSS 在小型案例独立承重（m=6 (1,3,0,1,0,0) k=1：去 XSS→FEASIBLE，且无需保序即独立杀）——
  **①族有真牙，不止 razor 区外**；
- XVOL/XBIG 在抽样中从未承重（全是冗余杀）——**⑤族现形太弱，纯陪跑**；
- 保序行在 razor 带仍是主承重（变体去保序后 razor 带全 FEASIBLE——与 §1 一致）。

## 4. 结论与行族细化建议（反馈给计数刻画）

1. 必要条件行现形（机器对称版）**不足以替代固定分组行**：保持率 62.6%，razor 带全崩。
   LP 路线若要去 (W'') 合法化，**必须**加入 junior 值序强形（②最小3d聚合/③反序对/④Hall），
   而这需要先证 junior 序结构引理（hi 区 junior 与低端 junior 的关系），或用 agent-2 的
   计数流刻画（β_s/β_j 联合流）的**强化析取版**（∃x 析取不能用单条线性行，需逐 x 多行
   或证角落内坍缩）。
2. XSS（极端配对）独立承重 ⟹ senior 侧"最小 2a 极端配对"值得保留进任何最终合法行集。
3. 鬼影洞的命运再次确认：**计数/必要条件行不咬鬼影，保序是洞族唯一已验杀手**
   （与 hole_close/mon2 先例一致）。若 agent-2 的鬼影点计数快检发现洞点违反某计数条件，
   与本实验 0/20 矛盾——建议对拍（本实验的洞点清单 p2_holes_big.jsonl m≤20 段）。
