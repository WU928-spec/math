# razor 带 LP 极值点分层钉死核验（agent-4，2026-09-23）

代码 `code/a4_razor_rigidity.py`；数据 `code/a4_razor_points.jsonl`（90 个可行点，逐点结构字段）。
背景：E-nec-v2 判 razor 带残留=(W'')/刚性义务区；本块提取两类 LP 极值点核验钉死结构，
为挤压引理+交换级联预算的刚性证明供数据。

## 点列与方法

- **ghost 序列**（14 点可行/28 试）：鬼影洞 m=12..16 + m=18 razor 族，
  build_fixed（含固定分组行、无 mon2），t 钉 {0.28,0.30,0.32,1/3}（鬼影只在 t≥0.32 存活）。
- **resid 序列**（76 点可行/80 试）：E-nec-v2  razor 残留代表
  （(1,m−3,0,1,0,0)@k∈{2,m−1}、(2,m−5,0,1,1,0)@k∈{4,m−1}，m=8..16），
  v2a 变体 LP（mon2+X 必要条件行、无固定身份装箱行）。

## 核验结果（对照挤压引理 Σℓ≤m−1−t 与值带结构）

| 签名 | ghost（14 点） | resid（76 点） |
|---|---|---|
| mon2 序违反 | **14/14 全违反** | 0/76 |
| Σℓ 超挤压预算 m−1−t | 0/14 | **50/76** |
| Σ(ℓ−p) 超预算 (m−1)(t−1/4)−t | 0/14 | **50/76** |

### 逐序列解读

**ghost（鬼影洞点）**：挤压预算与值带结构**全部满足**（s 三层 [0.50,0.583,0.626/0.667]、
j 两层 [1/3,0.417] 与 t=1/3 顶窗精确吻合 ✓ 复现主代理 m=12 实测）；
唯一违反 = **mon2 序**（14/14）——鬼影=非真角落的签名确认。
但注意：SS 配对不唯一（s0 度 3..8）、2a 外并非全孤立（5/14 有跨外连边）——
**在 mon2 缺席的 LP 里 razor 配对结构不钉死**；这不是刚性反例（这些点已非真角落）。

**resid（razor 残留点）**：mon2 全满足（76/76），但**挤压预算 50/76 超限**、
s_max≤1−t 42/76 违反、大 senior 无伴侣 66/76——**全部违反至少一条已证合法必要条件**
（挤压引理/值带结构）。特别地 k=2 段：s0 唯一伴侣=s1（SS 配对强制成立，钉死结构 ✓），
但 Σℓ 超 m−1−t ⟹ 挤压引理判其不可装箱。

## 结论（给刚性证明）

1. **未发现钉死结构反例**：90 个 LP 极值点中，凡 mon2 满足的（resid 76 点）全部违反
   挤压引理或值带必要条件 ⟹ 没有"满足全部已证合法条件且可装箱"的假想角落点浮出——
   razor 带残留是 LP 松弛 artifact，挤压引理已把它们从可装箱性中排除。
2. 刚性证明的义务可以精确化为：**razor 带窗口内 ⟹ 挤压预算+值带计数 已经把
   LP 见证全部压出可装箱域**；剩余只需把"挤压+值带 ⟹ 不可装箱"的组合论证闭合
   （交换级联预算路线，主代理在攻）。
3. 数据落盘 a4_razor_points.jsonl（每点：分层/间隙/配对图度/计数平衡/预算实测），
   可供级联分析直接引用。
