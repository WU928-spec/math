## 1. 恒等式（望远镜形式，每括号 ≥0）

记：D = p+t−5/4−MG（danger）；P_i = s_i+j_i−p−MG（pair）；
SRT_i = s_{i+1}−s_i ≥ 0（senior 机器标号排序）；
X(a) = 1−s₀−s_{2a−1} ≥ 0（最小 2a senior 极端配对首对 ≤1，S1 支配合法）；
T = 1−t−j₀−j₁（XTRI，见 §3）。

对 razor 带任意 cnt（a≥1）与任意 k∈[2,m−1]：

$$2(j_1-t) + 6D + 4P_0 + 2P_1 + \mathrm{SRT}_0 + 3\!\!\sum_{i=1}^{2a-2}\!\mathrm{SRT}_i + 3X(a) + 4T \;=\; -\tfrac12 - 12\,\mathrm{MG}$$

变量逐项消去（与 a 无关）：
- p：6−4−2 = 0；
- t：6（D）−2（j₁−t）−4（T）= 0；
- s₀：4（P₀）−1（SRT₀）−3（X(a)）= 0；
- s₁：2（P₁）+1（SRT₀）−3（SRT₁，a≥2 时；a=1 时 −3X(a)）= 0；
- s_i（2≤i≤2a−2）：+3（SRT_{i−1}）−3（SRT_i）= 0；
- s_{2a−1}：+3（SRT_{2a−2}）−3（X(a)）= 0；
- j₀：4（P₀）−4（T）= 0；j₁：2（P₁）+2（j₁−t）−4（T）= 0；
- 常数：6(−5/4−MG)+4(−MG)+2(−MG)+3·1+4·1 = −15/2+7−12MG = −1/2−12MG < 0。∎

**口头版**：pair+danger 给 j₀+j₁ ≥ 2p−(s₀+s₁) ≥ 3/2−2t（下链），
极端配对+srt 望远镜把 s₀+s₁（一般形 s₀+s_{2a−1}）压到 ≤1，
XTRI 给 j₀+j₁ ≤ 1−t；3/2−2t > 1−t ⟺ t<1/2 ⟹ 矛盾，覆盖整个 razor 窗口 t≤1/3。

## 3. 行合法性与 XTRI 边界（诚实登记）

| 行 | 状态 | 依据 |
|---|---|---|
| D, P_i, SRT_i, j₁−t | 合法（角落约束/标号） | §1 审计表 |
| X(a) = 1−s₀−s_{2a−1} | 合法（支配） | ∃a 对 senior 对和≤1 ⟹ 最小 2a 极端配对首对 s₀+s_{2a−1}≤1（重排） |
| T = 1−t−j₀−j₁（XTRI） | **实证成立、证明待补** | 见下 |

**XTRI 的两层合法性**：
- (A) j₀,j₁（两台最小 senior 机的 junior）是全局最小两件 ⟹ T=最小三元组 ≤1
  （JJJ 箱存在性 d=1+c+f≥1 支配）。**未过滤仿真已大量否定 (A)**（hi 区 junior 经常更小；
  a4_fuzz_tri.py，窗口外实例）——"最小三元组"索引论证不可用。
- (B) razor 窗口真角落（OPT≤1 精确装箱过滤 + t≤1/3 + danger）中直接 t+j₀+j₁≤1。
  实证：`code/a4_fuzz_tri2.py`（装箱箱数笔误 m+1→m 已修正重跑）——结果见 BOARD 更新。
  (B) 与主代理"junior 离散度引理/小 junior 供给"卡点同位：(B) 成立 ⟹ razor 带收官。
- **机制夹逼（§1 口头版的精确化）**：danger+pair+X(a) ⟹ j₀+j₁ ≥ 3/2−2t（机器侧下界，
  razor 窗口 ≥5/6）；XTRI 给 j₀+j₁ ≤ 1−t（≤2/3）；t<1/2 即矛盾。
  ⟹ **XTRI 合法性 ≡ razor 定理本身**（打包侧的同义反复不可用，必须由装箱结构直接证）。
- **分散度缺口的动力学定位（供方向 1/4）**：hi 区 junior j_H < j₁ 的唯一可能机制 =
  junior q 落入带 (K−s_H, q₁] 时去低端机、更小的后至件 ≤ K−s_H 落 hi 区——
  要求 ∃hi 区 senior s_H > K−j₁。razor 挤压（senior 近等、junior 窄带）使该带极薄，
  鬼影结构 (s_H=2/3, K−s_H≈0.416 < j₁≈0.417) 恰好踩线——**分散度在 razor 顶窗是临界现象**。
- **XTRI 松弛容忍度**：恒等式 rhs 余量 ⟹ j₀+j₁ ≤ 1−t+ε（ε<0.1253）同样闭合。
- **若 (B) 被反例击中**：U(a) 的 XTRI 项需换合法替代（候选：挤压缩放版
  j₀+j₁ ≤ (Σℓ−(m−3)p)/2 或 SS 伴侣带 [t,1−s₁]∩排序供给——缺口会精确记录在此）。
