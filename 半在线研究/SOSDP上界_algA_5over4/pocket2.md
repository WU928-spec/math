## 勘误与新事实（2026-09-19 会话 6，k3 max）

- **勘误**：此前"s 台单子机 ⟹ S ≤ m−s−t"错误——其余单子机自身也计入 S，正确界恒为 S ≤ m−1−t。
  由此唯一有效的静态链：p_i ≤ (m−1−t)/(m−1) ⟹ C_A ≤ 1 + t(m−2)/(m−1) ≤ 5/4 ⟺ t ≤ (m−1)/(4(m−2))。
  （m=4: t≤3/8；m=5: t≤1/3；m=6: t≤5/16；m=10: t≤9/32；m→∞: t→1/4。残留窗口随 m 增宽。）
- **新事实 A（比值平凡区）**：若 p_i + t ≤ OPT，则 C_A = p_i + t ≤ OPT ⟹ 比值 ≤ 1，直接收工。
  故危险 ⟺ p_i + t > OPT（从而 p_i 独占箱——与之前"危险 ⟹ 独占"一致，互为印证）。
- **新事实 B（封死的精确刻画）**：单子机未被触碰 ⟺ 每个后至任务 q 满足 p_i + q > K（放不下）或当时存在更满的合法机。
  若 p_i + t > K（t 时刻放不下）——由于任务递减、负载单调，任意 q ≥ t 且当时负载 ≥ p_i……
  注意 cap K 固定：p_i + q > K 对 q = p_{m+1} 起全部成立 ⟺ p_i + p_{m+1} > K（最强一步）。
  **故两种纯静态死法**：(a) p_i > K（永久封死）；(b) p_i + p_{m+1} > K（从第一个后至任务起就放不下）。
  真正的动态残留只有 (c)：p_i + p_{m+1} ≤ K 但 best-fit 每次都被更满机器抢先。
- **残留 LP 诊断**：静态封顶 1.26–1.33 的极值点全部把 OPT 归一化当自由量——核查发现对应实际 OPT > 1
  （p_i + t > 1 的装箱不可行），即极值点违反"OPT 恰为 1"的联合约束。这印证残留 = 纯动态问题。

## 会话 12（k3 max）：亏体积框架——引理 T 的证明载体成型

**新框架（deficit-waste）**：口袋 2 fallback 于 t，则 t 时刻所有他机负载 > p_i（严格，
平局走对抗解读）。定义：
- U = {j≠i : p_j < p_i}（初始低于单子机的机器）；
- 亏体积 D = Σ_{j∈U} (p_i − p_j)（这些机器必须被填过 p_i）；
- 填缝总量 F = Σ_{k=m+1}^{n−1} p_k（t 落到 M₀，不填他机）。
- **体积必要条件：F > D**（严格）。
- **浪费引理**：若存在非 U 机（p_j ≥ p_i）能容纳 p_{m+1}（即 p_j ≤ K − p_{m+1}），
  则 best-fit 最满优先 ⟹ 第一个填缝任务 p_{m+1} 落在非 U 机上 ⟹ 纯浪费 ≥ p_{m+1}
  ⟹ **F ≥ D + p_{m+1}**（更强）。
- m=11 极值实测：D = F = 4.5333 完全顶死——任何浪费都杀死覆盖，而 best-fit 的
  顶满优先**必然浪费**（M₂/M₃ 各超填 0.15）⟹ 动态不可达。这就是保护机制的本体。

## 引理 T 的证明义务（精确化）
证明：F > D 与 F ≤ D + (不可避免的浪费下限) 矛盾，其中浪费下限来自 best-fit 序——

## 会话 20 续（k3 max）：松箱计数引理——角落收窄的决定性静态工具

## 会话 26（2026-09-21）：口袋2角落 2件形态 LP 严谨证明完成

**核心突破：常数 Farkas 证书消灭连续 t 障碍。**
观察：firststep LP 里 t 只出现在右端（A 为 t 无关常数矩阵），b(t)=bc+t·bt。
故 **t 无关的常数证书 y** 只需解  A^T y=0, bt^T y=0, bc^T y=-1, y>=0。
若存在，则 b(t)^T y = -1 + t*0 = -1 对整个 t 窗口恒成立 —— 一份证书覆盖全部连续 t。

**流程（code/farkas_constant.py）**：Fraction 精确构造 LP -> 浮点 LP 定位 -> 有理化
-> Fraction 精确验证（A^T y==0, bt^T y==0, bc^T y==-1, y>=0 精确成立）。

**结果**：全部 (m,k) 有精确常数证书，m=4..9 × k=1..m-1 全覆盖，每证书覆盖全 t 窗口。
证书 = 8-10 条约束的组合（danger + firststep 配对 + 机器对和 + 装箱容量），权重为简单分数。

**口袋2角落整体闭合（LP 严谨版）**：2件形态 = LP 证书；3件 = 符号体积（负载>1）；
4+件 = 符号（负载>5/4>=K）。无需符号化 2 件 LP（证书自证）。
