# m=2 半在线（递减到达）调度：紧竞争比 7/6 的完整证明

**定理**（下界：Seiden–Sgall–Woeginger 1998/2000, Thm 3.1；上界：Graham 1969 的 LPT 分析）
两台机器、任务按不增顺序到达、即时不可反悔分配、对手可随时停止的模型下，任何确定性算法的最优竞争比恰为 **7/6 ≈ 1.16667**，且 **LPT（每个任务放当前较轻机器）达到此界——LPT 是 m=2 的最优算法**。

---

## 第一部分：下界 —— 任何算法 ≥ 7/6（SSW 对抗论证）

对手依次发出任务 **3, 3**：

- **若算法把两个 3 放同一台机器**：对手立即收手。算法 makespan = 6，而 OPT = 3（分放两台）。比值 = 2 > 7/6。
- **否则**（两个 3 分放两台，负载 (3,3)）：对手续发 **2, 2, 2**。

此时全实例 {3,3,2,2,2} 的最优解为 OPT = 6（划分 {3,3} 与 {2,2,2}，总量 12/2 = 6 且可达）。而算法这边：三个 2 分到两台已有 3 的机器上，由抽屉原理必有一台至少分到两个，负载 ≥ 3+2+2 = **7**。比值 ≥ 7/6。∎

无论算法怎么走，比值都 ≥ 7/6。

## 第二部分：上界 —— LPT ≤ 7/6·OPT（自包含直接证明）

设输入 p1 ≥ p2 ≥ … ≥ pn。取**最小反例**：任务数最少、使 LPT > (7/6)·OPT 的实例。

**关键观察**：递减输入下，LPT 在前 k 个任务上的调度就是完整调度的前 k 步（LPT 本身是在线算法）。因此最小反例中**最后一个任务 pn 必落在满载机器上**（否则删去 pn，LPT 的 makespan 不变而 OPT 不增，得到更小反例）。

记 LPT 完工负载 L1 ≥ L2，总量 T = L1 + L2，满载机器为 M1。

**情形 1：pn ≤ OPT/3。**
LPT 把 pn 放在当时较轻的机器上，故 L1 − pn ≤ L2，于是
$$L_1 \le \frac{T + p_n}{2} \le \frac{2\,\mathrm{OPT} + \mathrm{OPT}/3}{2} = \frac76\,\mathrm{OPT},$$
矛盾。（用了 OPT ≥ T/2。）

**情形 2：pn > OPT/3。**
由递减性所有任务 > OPT/3，OPT 的每台机器至多装 2 个任务（3 个即超过 OPT），故 n ≤ 4。逐一检查：

- **n ≤ 2**：LPT = OPT，平凡。
- **n = 3**：3 任务 2 机器，OPT 中两个最小的 p2, p3 必有同机者 ⇒ OPT ≥ p2 + p3。而 LPT 恰好把 p3 与 p2 放一起（p1 ≥ p2），M2 = p2 + p3 ≤ OPT，M1 = p1 ≤ OPT。LPT = OPT。
- **n = 4**：OPT 的最佳配对必为 {p1,p4} 与 {p2,p3}，即 OPT = max(p1+p4, p2+p3)。LPT：p1→A，p2→B，p3→B（因 p1 ≥ p2）。
  - 若 p1 ≤ p2+p3：p4→A，LPT = max(p1+p4, p2+p3) = **OPT 恰好相等**；
  - 若 p1 > p2+p3：p4→B，LPT = max(p1, p2+p3+p4)。由 p1 > p2+p3 得 OPT ≥ p1+p4 > p2+p3+p4，且 OPT ≥ p1，故 LPT ≤ OPT。

两种情形都与"LPT > 7/6·OPT"矛盾，故最小反例不存在，即**对所有递减实例 LPT ≤ (7/6)·OPT**。∎

（备注：此上界也是 Graham 1969 一般定理 LPT ≤ 4/3 − 1/(3m) 在 m=2 的特例；上面的直接证明不依赖该一般机器。）

## 第三部分：两头相遇

下界构造 (3,3,2,2,2) 恰好就是 Graham 的 LPT 紧例（m=2 时的 2m−1, 2m−1, m, m, m）：LPT 在其上恰打出 7（OPT=6）。于是

$$\underbrace{\text{任何算法} \ge 7/6}_{\text{SSW 下界}} \;=\; \underbrace{\text{LPT} \le 7/6}_{\text{Graham 上界}}$$

——下界与上界在**同一个实例**上同时取等，7/6 是精确的博弈值，LPT 是 m=2 的最优算法。

**数值验证**：博弈值求解器在 (3,3,2,2,2) 上算出精确值 7/6；3000 个随机递减实例上 LPT 最坏比值 1.139 < 7/6（紧例只能靠对抗构造逼近）。

**对照 m≥3**：m=3 起 LPT 不再最优（其最坏比 11/9 > (1+√37)/6），贪心时代在 m=2 结束。
