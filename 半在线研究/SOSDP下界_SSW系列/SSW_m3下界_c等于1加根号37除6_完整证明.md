# SSW m=3 下界完整证明：c = (1+√37)/6 ≈ 1.18046

**定理（Seiden–Sgall–Woeginger, 1998 技术报告 KAM Series No. 410 / Oper. Res. Lett. 27(5):215–221, 2000, §3）**
对 m = 3 台机器、任务按不增顺序到达的半在线调度问题，任何确定性在线算法的竞争比都不小于

$$c=\frac{1+\sqrt{37}}{6}\approx 1.18046,$$

其中 c 是方程 **3c² − c − 3 = 0** 的正根。

> 注：该界小于 Graham 的 LPT 界 4/3 − 1/9 = 11/9 ≈ 1.2222，故 m=3 时 LPT 不是最优；12 年后 Cheng–Kellerer–Kotov (ORL 40(5), 2012) 给出匹配的算法，此界为紧。

---

## 1. 对抗序列

设

$$x=\frac{7-3c}{6}=\frac{13-\sqrt{37}}{12}\approx 0.57643.$$

对手按如下**递减**顺序最多放出 **7 个任务**（并保留随时停止的权利）：

$$x,\;x,\;1-x,\;1-x,\;\tfrac13,\;\tfrac13,\;\tfrac13.$$

递减性：x ≈ 0.57643 ≥ 1−x ≈ 0.42356 ≥ 1/3 ≈ 0.33333 ✓。

## 2. 前三步：三个任务必须分占三台机器

前三个任务为 x, x, 1−x。前缀 {x, x, 1−x} 的最优 makespan 为 x（两个 x 分开放，1−x 放第三台机器）。若算法把某两个任务放在同一台机器上，对手立即停止：

- **两个 x 同机**：makespan ≥ 2x，比值 ≥ 2x/x = 2 > c；
- **x 与 1−x 同机**：该机负载为 x + (1−x) = 1，比值 ≥ 1/x = 6/(7−3c) = (13+√37)/11 ≈ 1.7348 > c。

因此任何比值 < c 的算法必须把前三个任务放在**两两不同的三台机器**上，三台机器负载为 (x, x, 1−x)。

## 3. 第四步：对第四个任务落点的情形分析

第四个任务大小为 1−x。只有 3 台机器，它必与某个先到任务同机，分两种主情形。

### 情形 A：与前两个任务（某个 x）同机

该机器负载恰为 x + (1−x) = **1**。对手**停止**。

此时全列表 {x, x, 1−x, 1−x} 的最优 makespan 为 2(1−x)：把两个 1−x 配对放一台机器（负载 2(1−x) ≈ 0.847），两个 x 各占一台；注意 2(1−x) > x，且任何更优分法都会迫使某台机器负载 ≥ 2x 或 1。于是

$$\text{比值}\;\ge\;\frac{1}{2(1-x)}=\frac{1}{2-2x}=\frac{3}{3c-1}=c,$$

最后一步等号正是定义方程 3c² − c − 3 = 0 的改写。

### 情形 B：与第三个任务（1−x）同机

该机器负载为 2(1−x)。对手**继续**放出三个大小为 1/3 的任务。

- 若某个 1/3 被放到这台负载 2(1−x) 的机器上，则 makespan ≥

$$2(1-x)+\frac13=\frac73-2x=c.$$

- 否则三个 1/3 全部落在两台负载为 x 的机器上，由抽屉原理，其中一台至少分到两个：

$$\text{makespan}\;\ge\;x+\frac23=\frac{11-3c}{6}\;\ge\; c,$$

此处等号当且仅当 c = 11/9 —— 恰是 Graham LPT 在 m=3 的最坏比值；由于 c < 11/9，该子情形严格优于 c（它是整个构造中唯一留有间隙的分支）。

而整个 7 任务列表的最优 makespan 恰为 **1**：总负载 2x + 2(1−x) + 1 = 3 给出下界 OPT ≥ 1，划分 {x, 1−x}, {x, 1−x}, {1/3, 1/3, 1/3} 达到 1。故此情形比值 ≥ c。

综上，无论算法如何行动，竞争比 ≥ c。∎

## 4. c 从何而来：两个比值函数的均衡

两个主情形的比值是 x 的两个函数：

$$f_1(x)=\frac{1}{2-2x}\ (\text{随 }x\text{ 递增}),\qquad f_2(x)=\frac73-2x\ (\text{随 }x\text{ 递减}).$$

对手选 x 使算法面临的最坏情形最小化，即令两者相等：

$$\frac{1}{2-2x}=\frac73-2x\;\Longrightarrow\;(2-2x)\Big(\frac73-2x\Big)=1\;\Longrightarrow\;12x^2-26x+11=0,$$

解得 x = (13 ± √37)/12，取可行根（须 ≤ 1 且 ≥ 1−x）：

$$x=\frac{13-\sqrt{37}}{12}\approx 0.57643,\qquad c=\frac73-2x=\frac{1+\sqrt{37}}{6}\approx 1.18046.$$

一致性检验（均严格成立）：

| 约束 | 数值 | 结论 |
|---|---|---|
| 递减性 x ≥ 1−x ≥ 1/3 | 0.5764 ≥ 0.4236 ≥ 0.3333 | ✓ |
| 前三步惩罚 1/x > c | 1.7348 > 1.1805 | ✓ |
| 抽屉分支 x + 2/3 = (11−3c)/6 与 c 之差 | (11−9c)/6 ≈ 0.103 > 0，即该分支比值 ≥ 1.2833 > c | ✓ |
| 情形 A 的 OPT：2(1−x) ≥ x | 0.8471 > 0.5764 | ✓ |
