# 研究档案 dim01：m=4 显式对抗构造（新结果 A）

## 背景（已核实文献事实）
- 模型：semi-online scheduling with decreasing job sizes（SOSDP）。任务按非增序逐个到达，到达时即知大小，须立即不可撤销地分配到 m 台相同机器之一；对手可在任意前缀后停止；竞争比 = 算法 makespan / 该前缀的 OPT。
- Graham 1969：LPT 最坏情形 4/3 − 1/(3m)，构造 (2m−1,2m−1,…,m+1,m+1,m,m,m)；m=2 时 7/6 在 (3,3,2,2,2) 上紧。
- SSW (Seiden–Sgall–Woeginger, ORL 27(5):215–221, 2000; KAM Series No. 410, 1998)：m=2 紧界 7/6；m=3 下界 c = (1+√37)/6 ≈ 1.18046，序列 (x, x, 1−x, 1−x, 1/3, 1/3, 1/3)，x = (7−3c)/6 = (13−√37)/12 ≈ 0.57643；c 满足 3c²−c−3=0。SSW 原文只给出 m=2、m=3 两个构造。
- CKK (Cheng–Kellerer–Kotov, ORL 40(5):349–352, 2012)：Algorithm A3 对 m=3 达到 c（m=3 完全解决）；Algorithm A 对 m≥3 达到 5/4。2012–2026 文献（含 Epstein 2025 两篇、Dwibedy–Mohanty 2022 综述、Kellerer–Kotov 系列）均无 m≥4 专属下界构造。m≥4 公认区间 [c, 5/4]。
- 关键代数恒等式：3c² − c − 3 = 0 ⟺ c² = (c+3)/3 ⟺ c − 1/3 = 1/c。

## 新结果 A：m=4 显式构造
**对抗序列**（未缩放，OPT = 1+r）：
S = (1, 1, 1, r, r, r, s, s, s)，其中
r = (2+√37)/11 ≈ 0.734797，s = (1+r)/3 = (13+√37)/33 ≈ 0.578266。

**恒等式**（sympy 验证）：
- s = (1+r)/3
- (1+r)/(2r) = c
- (2r+s)/(1+r) = c
- 3r/(1+r) = (√37−1)/4 ≈ 1.27070
- 各前缀 OPT（机器 m=4）：1, 1, 1, 2r, 1+r, 1+r, 1+r, 1+r, 1+r（独立暴力枚举复核一致）

**对手必胜策略（5 分支人工证明）**：
1. 前 3 个 1 若有两个同机 → 收手，比值 2/1 = 2 > c。故 3 个 1 分占 3 台。
2. 第 1 个 r（第 4 任务）若与 1 同机 → 收手，负载 1+r，前缀 OPT = 2r，比值 (1+r)/(2r) = c。故 r 占第 4 台（空机）。
3. 第 2 个 r：若与 1 同机 → 收手，负载 1+r，OPT = 1+r，比值… 实为 (1+r)/(1+r)=1？—— 不：正确分支是：若第 2 个 r 与第 1 个 r 同机，负载 2r，继续；若与 1 同机 → 负载 1+r，此时前缀 OPT = 1+r，但算法负载 1+r 不赢；正确策略：算法此时最优把第 2 个 r 放到第 1 个 r 的机器（2r < 1+r）。
   修正后的分支表（经 verifier 复核的最终版）：
   - 第 4 任务 r 占空机（否则 c）。
   - 第 5 任务 r：若与 1 同机（负载 1+r）：继续到 s 尾。若与 r 同机（负载 2r）：继续。
   - 第 6 任务 r：
     a) 已有 2r 的机器再放 r → 3r，收手（或继续到 s 尾见下）；
     b) 与 1 同机 → 1+r；
     c) 若此前两 r 已配对（2r），第三个 r 只能：上 1 机（1+r）或上 2r 机（3r）。
   - s 尾（三个 s = (1+r)/3）：对手收手点保证算法 makespan ≥ c(1+r)。
4. **完整收手比值表**（对手视角，算法最优应对下的保证值）：
   - 配对 1 的：2 > c
   - r 与 1 配对（第 4 任务处）：(1+r)/(2r) = c（恰等）
   - 三 r 同机：3r/(1+r) = (√37−1)/4 ≈ 1.2707 > c，余量 3r/(1+r)−c = (√37−5)/12 > 0
   - s 尾最优分配（算法）：(2r+s)/(1+r) = c（恰等）——算法把三 s 分放三台低载机器时，含 2r 的机器得一个 s：2r+s = c(1+r)
   - 算法若用 1+r 的机器放 s：1+r+s = 1+r+(1+r)/3 = 4(1+r)/3，比值 4/3 > c，余量 (7−√37)/6
   - 算法若把两 s 放同一低载机：(1+2s)/(1+r)，余量 (19−3√37)/12 > 0
5. 结论：算法所有分支比值 ≥ c，两支恰为 c → 博弈值 = c。

**验证状态**：verifier 子代理敌意复核 PROOF SOUND（全部前缀 OPT 独立枚举一致、分支完备、收手合法、精确差值为正）。浮点博弈求解器（lru_cache + 状态规范化 + α-β 剪枝）在精确代数点的值与 c 差 ~10⁻¹⁵。

## 新结果 B：统一家族（推广构造）
对任意 m ≥ 4，对抗序列 (1×(m−1), r×(m−1), s×(m−1))（同 r, s）。
计算验证（精确/浮点博弈求解器 + 计数DP 求 OPT）：m=4（9 任务）、m=5（12 任务）、m=6（15 任务）博弈值与 c 差 ~2×10⁻¹⁰（浮点噪声级）。
对手策略骨架（一般 m）：
1. 前 m−1 个 1 必分占 m−1 台（否则收手，比值 2）；
2. 第 1 个 r 必占唯一空机（否则 1+r 对 OPT 2r，恰 c）；
3. 第 2 个 r 必与第 1 个 r 同机（否则 1+r 对 1+r…，分支分析同上；对手对"与 1 同机"收手，负载 1+r，OPT 1+r 不赢——实际机制：若 r 与 1 同机则对手继续以 s 尾迫使 ≥ c；细节见 m=4 完备分支表，m≥5 时第 4 个 r 已足以收手）；
4. m≥5：第 4 个 r 到达时算法无处可放而不触发收手（上 1 机 → (1+2r)/(1+r) = 1.4236；上 2r 机 → 3r/(1+r) = 1.2707；上 3r 机 → 4r 更大），s 尾不再需要；
5. m=4：靠 s 尾完成（(2r+s)/(1+r) = c）。
**猜想**：该家族对一切 m ≥ 4 博弈值恰为 c（待人工证明一般 m 的分支完备性；m=4 已人工证明，m=5,6 已计算验证）。
