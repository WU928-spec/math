# m=4 半在线（递减到达）下界：30 分钟试点搜索报告

日期：2026-09-14 ・ 模型：任务按不增顺序到达、即时不可反悔分配、对手可随时停止（SSW 2000 模型）
工具：精确/浮点博弈值求解器 V(seq) = min_算法 max_对手（含逐前缀收手），m=2 复现 7/6、m=3 复现 c=(1+√37)/6，基准校准通过。

## 一、两条结论

### 结论 1（负面，证据强）：未找到超过 c 的 m=4 对抗序列
共测试 **25,000+ 个实例**（20,126 个随机结构化序列 + 6 个参数家族的系统网格扫描），m=4 博弈值无一超过 c ≈ 1.18046。所有家族的峰值都收敛到 c 附近或以下（见第三节全景表）。

### 结论 2（正面，精确）：SSW 下界到 m=4 的显式推广——9 任务构造，博弈值恰好 = c

$$\text{序列：}\; 1,\,1,\,1,\;\underbrace{r,\,r,\,r}_{r=\frac{2+\sqrt{37}}{11}\approx0.7348},\;\underbrace{s,\,s,\,s}_{s=\frac{13+\sqrt{37}}{33}\approx0.5783}$$

浮点博弈值 = 1.18046042171637 与 c 到 15 位小数一致；关键恒等式经符号代数验证（s 换成 4 或 5 个结果不变）：

$$s=\frac{1+r}{3},\qquad \frac{1+r}{2r}=c,\qquad \frac{2r+s}{1+r}=c.$$

**新颖性声明（经系统文献查重修正后的精确表述）**：文献中不存在任何 m≥4 的显式对抗构造（高置信：SSW 原文、CKK 全文、Epstein 2025 两篇、Dwibedy–Mohanty 综述等逐一核查），本构造是第一个。但两点必须诚实说明：(i) 下界的**数值** c 对 m≥3 成立是学界的 folklore——CKK 2012 直接转述为 "SSW give a lower bound of (1+√37)/6 for m≥3"，尽管 SSW 只证了 m=3；(ii) 存在一个未发表但正确的**填充转移论证**（往 OPT=1 的 m 机实例前插一个大小恰为 1 的任务：算法若让它与任何后续任务同机，负载 ≥ 1+1/3 = 4/3 > c，否则它独占一台机器、剩余 m 台机器重演原对抗）——所以"c 是 m≥4 的下界"本身并非悬案，本构造的贡献是**第一个不依赖未写明的填充引理的自包含直接证明**。

**完整人工证明**（每一支 ≥ c，关键两支恰好 = c）：

1. 前三个 1 必分占三台机器：否则对手收手，OPT=1，比值 2 > c。
2. 第 4 个任务 r 必占第 4 台（空）机器：若与某个 1 同机，对手收手，OPT(1,1,1,r)=1，比值 1+r ≈ 1.7348 > c。局面变为 (1,1,1,r)。
3. 第 5 个任务 r：OPT(1×3, r×2) = 2r（两 r 配对）。若与某个 1 同机，对手收手，比值 (1+r)/(2r) = **c**。故只能与 r 同机 → (1,1,1,2r)。
4. 第 6 个任务 r：OPT(1×3, r×3) = 1+r（划分 {1,r}×3 + 空机；下界论证：若 makespan < 1+r 则两个 1 不能同机、1 不能与 r 同机，三个 r 只能全挤一台 = 3r > 1+r，矛盾）。若与 2r 同机，对手收手，比值 3r/(1+r) = (√37−1)/4 ≈ 1.2707 > c。故只能与某个 1 同机 → (1+r, 1, 1, 2r)。
5. 三个任务 s（OPT(全序列) = 1+r，划分 {1,r}×3 + {s,s,s}，因 3s = 1+r）：
   - 任一 s 落在 1+r 上 → 比值 (1+r+s)/(1+r) = 4/3 > c；
   - 某台 1 背两个 s → 比值 (1+2s)/(1+r) ≈ 1.2431 > c；
   - 算法最佳应对：三台轻机器各分一个 s → 最大负载 2r+s，比值 (2r+s)/(1+r) = **c**。

∎ 任何 m=4 算法的竞争比 ≥ c。

### 结论 3（方向判断）：m=4 的真值很可能就是 c
下界端最强的自然家族恰好顶到 c 而无法超越，提示缝隙 [c, 5/4] 应从**上界端**收——即为 m≥4 设计达到 c 的算法（正是 CKK 2012 结论中留下的开问题）。

## 五、推广到所有 m ≥ 3：两条独立证明

### 5a. 统一显式构造（新结果）

**猜想并经计算验证的构造**：对任意 m ≥ 4，对抗序列

$$\underbrace{1,\dots,1}_{m-1},\;\underbrace{r,\dots,r}_{m-1},\;\underbrace{s,\dots,s}_{m-1},\qquad r=\frac{2+\sqrt{37}}{11},\;s=\frac{1+r}{3}=\frac{13+\sqrt{37}}{33}$$

的博弈值**恰好等于 c**。计算验证：m=4（9 任务）、m=5（12 任务）、m=6（15 任务）的博弈值与 c 的差均 ~2×10⁻¹⁰（浮点噪声级）。对手的必胜策略（一般 m 的人工证明骨架）：

1. 前 m−1 个 1 必分占 m−1 台机器（否则收手，比值 2）；第 1 个 r 必占唯一空机（否则收手，比值 1+r > c）。
2. 第 2 个 r：OPT(1^{m−1}, r^2) = 2r（m ≥ 4），与 1 同机则收手、比值 (1+r)/(2r) = c；故只能与 r 同机 → (1^{m−1}, 2r)。
3. 第 3 个 r：OPT(1^{m−1}, r^3) = 1+r，与 2r 同机则收手、比值 3r/(1+r) = (√37−1)/4 > c；只能与 1 同机 → (1+r, 1^{m−2}, 2r)。
4. 第 4 个 r 起（m ≥ 5）：OPT(1^{m−1}, r^4) = 2r（两个 r 对两对），此时与 1 同机 → (1+r)/(2r) = c，与 1+r 同机 → (1+2r)/(2r) ≈ 1.68 > c，与 2r 同机 → 3r/(2r) = 3/2 > c——**所有走法都立即输，s 尾巴甚至用不上**。
5. m = 4 时无第 4 个 r，进入三个 s 的收尾（正文第 5 步），最佳应对恰好 c。

即：**机器越多，对手的统一构造越早锁死算法**。

### 5b. 填充归纳（独立证明，修复文献中从未写明的 folklore 论证）

**引理**：若 m 台机器存在递减、OPT = 1 的对抗实例保证比值 ≥ c，则 m+1 台也存在（OPT 仍 = 1）。
**证明**：将实例缩放至 OPT = 1，序列最前插入一个大小为 1 的任务（保持递减）。新实例 OPT = 1。算法若把该任务与任何后续任务同机，则负载 ≥ 1 + p_min = 1 + 1/3 = 4/3 > c（本构造与 SSW m=3 构造缩放后的最小任务都恰好是 1/3——前者因恒等式 s = (1+r)/3，后者任务即含 1/3），对手收手；否则它独占一台机器，剩余 m 台重演原对抗，由假设比值 ≥ c。∎

基例：m=3（SSW）或 m=4（本文 5a）。归纳得：**对所有 m ≥ 3，任何确定性算法竞争比 ≥ c**。据文献查重，此转移论证此前从未被写出发表，CKK 仅以 "for m≥3" 一语默认。
